### High

**H1. Regression against main: go/printer's work grows with nesting and is mostly uncharged.** `internal/accept/integrity_cases.go:385-389` (`canonTo`), called from `:492` (`testPrint`), `:343` (`rows`) and `:508` (`control`).

- **Input:** a test whose one assertion's argument nests n function literals, each asserting:
  - `t.Error(func() int { t.Error(func() int { … }()); return 0 }())`.
  - Main accepts it.

| Nesting n (file size) | This head | Main |
|---|---|---|
| 200 (7 KB) | 11.7 s, 365 MB allocated | 0.12 s |
| 400 (14 KB) | 2 min 40 s, 51 GB allocated | 0.15 s |
| 800 (29 KB) | 17 min 50 s, 493 GB allocated, then blocks `unverifiable: the guard failed (a type check over the guard's deadline …)` | 0.29 s |

- **What the bound saw:** about 268M units charged at n = 800, under 13% of `maxCaseWork` (2³¹). So the bound never fired; the run stopped only at the deadline.
- **Cause:**
  - `testPrint` canonicalizes every assertion call. Each canonical text contains every literal nested inside it.
  - A single `printer.Fprint` of a nesting of depth d costs about O(d²) time. Measured standalone: depth 50 → 6 ms, 100 → 29 ms, 200 → 119 ms (67 KB of output).
  - So the time per charged byte grows with nesting: about 4 µs here, against about 13 ns for plain ASTs. The bound counts output bytes only.
- **How far it reaches:** [INFERENCE] each `canon` of a row element, or of an `if` condition, that nests literals has the same per-call cost. That covers `rows` and `control`.
- **Why it matters:** the bound is the promise of item 3. Here a few tens of KB stall the guard's CPU and memory, and end in a false block where main accepts.
- **Fix:**
  - Replace `printer.Fprint` in `canonTo` with a linear canonical form that gofmt cannot change: the node's source span through `go/scanner`, comments dropped, newline-inserted semicolons skipped, each token and literal written once.
  - Charge the bytes scanned.
  - Add a row that compares charged work and bytes allocated at n and 2n for this nested-literal input. `TestIntegrityCasesAllocs` already has the shape to copy.

### Medium

**M1. Not stated: an early `return` or `break` silently drops a subtest or row.** Main is equally silent, so this is not a regression. `internal/accept/integrity_cases.go:85-89`

- **Inputs:**
  - `if Add(1, 1) == 2 { return }` before `t.Run("c", checkOne)`, in the test or inside a subtest's literal callback before `t.Run("inner", …)`;
  - `if tc.name == "a" { break }` after a `runs` loop's `t.Run`;
  - `if tc.name == "zero" { return }` in a checking loop.
- **What happens:** the identities and counts are unchanged. The print is also unchanged, because the exit is a sibling of the assertion, not a control around it.
- **Context:** this is the same class as the stated `continue` residual, but `return` and `break` are wider: a `return` drops every later subtest in the test.
- **Fix:** do one of these.
  - Add `ReturnStmt` and `BranchStmt` (with their control hash) to the print events. Adding an exit then warns when counts are equal.
  - Or widen the residual line to "an early `return`, `break`, `continue` or `goto` before a subtest or row".
