1. **High — A cut candidate run can still pass.** `internal/gate/gate.go:230`, `internal/gate/gate.go:260`  
   **Input:** Measure a baseline using `sh ./gate.sh`, where the base script emits complete green results and exits. At the candidate, keep the command unchanged but append `exec sleep 30`; set `Limits.Timeout` to one second. All baseline tests are reported before the timeout.

4. **Medium — The controller reads `go.mod` outside filesystem confinement.** `internal/gate/gate.go:429`  
   **Input:** Call `Measure` on a base tree whose `go.mod` is a symlink to `/dev/zero`. Checkout preserves the symlink; `modulePath` follows it with unbounded `os.ReadFile` before starting the sandbox. This can exhaust controller memory, outside the sandbox timeout and memory limit. An absolute symlink to a controller file likewise causes a host-side read.  
   Acceptance rejects newly introduced candidate symlinks, but baseline measurement has no preceding acceptance check.  
   **Fix:** Read the module file through a confined root, require a regular file, and enforce a byte bound—or read its bounded Git blob directly.
