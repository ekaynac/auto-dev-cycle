1. **High — `clean_exec` still passes names outside its allowlist.** `scripts/lib/secrets.sh:101`

   **Input:** Launch the installed driver with an environment entry whose name is literally `HOME\nPATH` and whose value is private caller data. Here `\n` denotes an actual newline, supplied through an environment API such as `execve`.

   Bash preserves this invalid shell identifier in its child environment, as with Opus’s `ADC-SECRET` case. The new check reads its NUL-delimited entry correctly, but then prints the name with newline delimiters. It becomes two lines, `HOME` and `PATH`; both are already allowed by `scripts/installed-cycle.sh:200`. `sort -u` removes the duplicates, the comparison passes, and `exec` passes the original extra entry—including its value—to adcd.

   This affects both starts through `scripts/installed-cycle.sh:310`. Main’s `env -i` removed the entry. **H2 remains open, and stub isolation regresses.**

   **Fix:** Compare each complete NUL-delimited name against exact allowlist entries. Alternatively, reject non-identifier names before any newline serialization. Propagate inspection failures and keep values out of diagnostics and argv. Add the newline-name case beside the existing invalid-name cases.
