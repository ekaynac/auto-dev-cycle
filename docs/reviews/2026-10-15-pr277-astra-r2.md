**High H2 — A compiled package can defeat the source-identity check.**

Location: `internal/accept/integrity_pyreach.go:191`.

Concrete base:

```python
# feature/__init__.py
from redirect import *

# redirect.py — decoy
X = 1

# feature/flags.py — decoy
SKIP = False

# redirect/flags.py
from cfg import SKIP

# cfg.py
SKIP = False

# tests/test_x.py
import pytest
import feature.flags

@pytest.mark.skipif(feature.flags.SKIP, reason="r")
def test_x():
    assert False
```

Also present: `redirect/__init__.pyc`, valid CPython 3.12 bytecode compiled from `__all__ = ["__path__"]`, with no corresponding `__init__.py`.

Candidate changes only `cfg.py` to `SKIP = True`.

`pb.mods["redirect"]` selects `redirect.py`; `alts` counts only `.py` files. `compiled("redirect.py")` searches for paths beginning `redirect.`, so it misses `redirect/__init__.pyc`. The guard accepts the decoy as the inert star source and retains `feature/flags.py`.

CPython instead checks package initializers before module files, including sourceless initializers. It loads the compiled package, exports its implicit `__path__`, and reaches `redirect/flags.py`. The candidate skips the failing test. This ordering is explicit in [CPython’s `FileFinder.find_spec`](https://github.com/python/cpython/blob/3.12/Lib/importlib/_bootstrap_external.py#L1483-L1531).

**Fix:** check all competing module and package forms for the import name, including `name/__init__.pyc` and extension-package initializers beside `name.py`. Add a must-block row for this package-versus-module combination.

**High H3 — A dotted star source bypasses its parent package’s plainness check.**

Its exported path redirects `feature.flags` to `real/redirect/flags.py`, while the guard follows the decoy. This follows Python’s [parent-package and submodule lookup rules](https://docs.python.org/3.12/reference/import.html#searching).

**Fix:** validate every ancestor of a dotted star source before accepting the selected file, including plainness, ambiguity and shadow-only resolution. Bound recursive star checks and fail closed on cycles. Add this input as a must-block row.
