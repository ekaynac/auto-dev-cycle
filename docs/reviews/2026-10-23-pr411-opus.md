## Opus review of #411, A-pre (2026-10-23)

Verdict: GO. Nothing is BLOCKING. Two Mediums and two Lows are OBLIGATIONS. M1 must be fixed before `launch` activates, or before any production `Query.Usage` lands.

The driver uses only the Reconciler's existing rules, and it cannot release a liability. Here is why:
- **No zero settlement:** with no usage query, an uncertain call records nothing new and keeps its liability. The row checks `capacity.Liable` before and after.
- **No double settle:** the Reconciler's per-call lock and the store's expectations prevent it.
- **Only ended calls:** `Unsettled` keeps calls whose attempt is sealed, completed or superseded.
- **No race with the runner's end:** the gateway is unbound before the seal (`run.go:346` ends the gateway before `record`). So by the time the driver can see a call, the runner's own `Ended` has run.

A4 runs through `newEgress`'s own Recorder and Reconciler. While `launch` is inactive, the per-pass cost is one read transaction and one indexed query that returns nothing.

### Medium: OBLIGATION

**M1. A panic in the settlement driver kills adcd. The pass's own recover does not cover it.** `internal/daemon/egress.go:173-195`
- **Cause:** `Settle` runs `settleEnded` in a goroutine with no `recover`. The pass recovers panics in the observation and in each action (`reconcile.go:1021`), but this work runs outside both. The runner already recovers in its goroutines (`run.go:215`, `accept.go:111`, `gate.go:91`), so this is also a second, weaker form of an existing pattern.
- **Probe:** a usage query that panics, then one `Pass`. The test process exits with status 2, with the panic's stack in `(*egress).Settle.func1` (`egress.go:183`).
- **Reachability:** none today. `Queries` is empty, and while `launch` is inactive no `model_call` effect exists, so no Reconciler code runs. It becomes a crash on the production loop as soon as either changes.
- **Fix:**
  - Recover in the goroutine, as `runner.start` does.
  - Log it once per cause, and set the call's retry with backoff, so one bad call cannot crash adcd or spin.
  - Add the probe above as a row.

**M2. Each pass reloads every live, ended `model_call` effect, and in this build those never leave the list.** `internal/modelcall/modelcall.go:359-381`; `internal/daemon/egress.go:213-243`
- **Cause:** `Unsettled` loads, for every live effect, its effect row plus `Of` plus `AttemptOf`. That happens before the retry filter (`due`), on every pass: every 5 s and on every nudge.
- **Why the list only grows:** with no usage query, a call whose final the gateway's count did not bear out stays `uncertain` for good. So the per-pass reads grow with history, not with work.
- **Effect:** it does not block the pass (it runs in a goroutine), and it is visible as load only.
- **Related:** a single unbound live effect makes `Unsettled` fail as a whole. Then no call is settled, with one log line and no visible state. Store damage is the only way in, because the binding is folded with the intent (#226 entry 70's start check).
- **Fix:**
  - Filter by the in-memory `retries` first: list the live effect ids, skip those not due, and load only the due ones.
  - Skip an unbound effect, and log it, instead of failing the whole listing.

### Low: OBLIGATION

**L1. The start-time settlement is synchronous, before the listeners, with no overall bound.** `internal/daemon/daemon.go:261`
- **Today:** cheap, since `Reconcile` without a query returns at once.
- **With a production query:** each call can take up to `settleBound` (1 min), one after another, before adcd serves anything.
- **Fix:** bound the start run (for example `settleBound` in total) and leave the rest to the passes. Or start it as `Settle` does, without waiting.

**L2. "A store fault holds anything visibly": no.** A listing failure and per-call failures are log lines only. No state is shown on the board or the task card. The accounting stays conservative (the liabilities are kept), so this is bounded.
- **Fix:** if a visible state is wanted, give the operator a count of calls unsettled past their backoff cap (`adc task show`'s charge already lists the outstanding calls), or state that it is log-only.

### The six questions
1. **The production loop today:** `Settle` never blocks a pass. Its work is one `View`, with `LiveEffects` using the `effects_state` index (`SELECT id … WHERE kind = ? AND state IN …`); it returns nothing while `launch` is inactive, and it writes nothing. On a large store the cost scales with the number of live effects, not the store size, which becomes M2 once calls exist. **Shutdown:** `eg.wait()` runs after the loop has stopped. The goroutine's context is the pass's (cancelled by `stopPurge`), and every store, lock and query call honours it, so there is no hang. **Crash:** see M1.
2. **Release, zero settlement, double settle, or a running or unsealed call:** none.
   - `Ended` and `Reconcile` keep the liability unless the standing settles.
   - The per-call lock serialises the driver and the runner.
   - A lost attempt that is not sealed is excluded (the row "a pending call of an ended attempt" checks it).
3. **Races and one rule:** there is one rule, the Reconciler's.
   - **The runner's end:** it runs `Ended` before the seal, so the driver sees the call only afterwards. If both ever overlap, `Ended` waits on the lock, and `Reconcile` returns `ErrRunning`, which is left alone.
   - **The start sweep:** it runs before `settleEnded`.
4. **Backoff and logging:** `retryAfter`, capped and never ending, one log line per cause per call (the row counts the tries). `ErrRunning` is retried at the pass rate, which is bounded. A store fault is logged only (L2).
5. **Reuse:**
   - **A4:** through `newEgress`, yes.
   - **`Tx.LiveEffects`:** a new list query beside `LiveEffect` (one target) and `MarkPendingUncertain`'s pending scan (`effects.go:371`). It reuses `loadEffect`, and no existing reader lists by kind and live state. Acceptable.
   - **Shared helpers:** `endRetry`, `retryAfter` and `ids.Redact` are shared.
   - **The recover pattern:** not shared (M1).
6. **Regression against main:** none found. Every row and package above passes. `reconciler`'s new `eg` parameter keeps `creds = eg.gw`, and the `authority` change is only an `errors.Join` of one error, with the same message.
