## Opus pre-review of #275 (2026-10-15)

Verdict: NO-GO

**Method.** The reviewer read head f65cca5 against main f6dcf12, and ran probe rows through `newFixtureWith`, `f.guarded` and `pyOwn` on both trees. The results leave out P14b's blanket block. The scratch worktrees are removed.

**The core problem.** The PR uses each added root for two jobs:
- **shadow names:** here an extra root only adds blocks, so over-approximating is safe;
- **resolution** (`pb.mods`, `prefix`, `resolve`, `across`, holders, `binding`): here a wrong or merely assumed root can replace main's binding, or main's third-party proxy route, with a decoy file.

Three of the High findings follow from this.

### High

**H1. `prefix` checks for two roots only at the final prefix, so a decoy package with the same name as a package in another root passes. Regression against main.**
- **Where:** integrity_pyreach.go:226-239. The `k < i` loop never checks `pb.alts[parts[:k]]`.
- **Probe P1d** (no install key):
  - base: `src/util/__init__.py` empty; `src/util/flags.py` with `SKIP = False`; `util/__init__.py` with `import cfg as flags`; `cfg.py`; `helper.py` with `V = util.flags.SKIP`; a test with `skipif(V)`;
  - candidate: changes `cfg.py`.
  - Main blocks; the PR passes.
- **The same through the other roots:** P1e (a setup.cfg `where = a`) and P1f (a `sys.path.insert` and `append`). Main gives unread for both, and the PR passes.
- **Fix:** in `prefix`, return unread when any `k <= i` with `pb.mods[parts[:k]] != ""` has `pb.alts[parts[:k]] > 1`. Rows: P1d, P1e and P1f.

**H2. An assumed root resolves into a file where main used the third-party proxy rule. Regression against main.**
- **Where:** integrity_pyreach.go:45 (the `src/` rule), integrity_pyguard.go:83, integrity_pyshadow.go:136.
- **Probe P2:**
  - base: `src/feature/flags.py`, a scripts directory that is not installed; `cfg.py`; a test that reads `feature.flags.SKIP`, where `feature` is third-party;
  - candidate: changes `cfg.py`.
  - Main blocks through the proxy rule; the PR passes, because `feature.flags` now resolves into the decoy.
- **Also:** P2h (a conftest that parks `cfg.SKIP` on `feature.flags`) and P4 (a sourceless `util.pyc` beside `src/util/`).
- **Fix:**
  - Use the added roots ONLY to name modules for `pyShadow`.
  - Keep resolution (`pb.mods`, `prefix`, `resolve`, `across`, holders, `binding`) on main's entries.
  - Count `alts` over the full root set, so that a collision is unread.

**H3. The install readers accept roots that setuptools does not use.**
- **Probes:**
  - P2b: `tox.ini` with `[options.packages.find]`;
  - P2c: an upper-case section name;
  - P2d: a nested `sub/setup.cfg`;
  - P2f: `where` without `packages = find:`;
  - P2g: a TOML `Where` key;
  - P9: an indented continuation line read as a key;
  - P12: `where = a b`.
- P2e: a join relative to the conftest directory is a second root that Python never uses.
- **Fix:** the H2 fix makes these harmless, because extra shadow roots only add false blocks. If H2 is not taken, tighten the readers:
  - the root `setup.cfg`/`pyproject.toml` only;
  - exact case for section names and TOML keys;
  - no indented key lines;
  - a single `where` word;
  - `where` only with `find:`;
  - no conftest-relative join.

**H4. The build-backend check is weaker than main's (a fail-open on a shadow).**
- **Where:** integrity_pyreach.go:70, `HasPrefix(…, "setuptools")`.
- **Probe P10:** `build-backend = "setuptools_x"` with `backend-path = ["_build"]`, and a candidate that adds `vendor/yaml.py`. Main gives unread; the PR passes.
- **Fix:** accept only `setuptools.build_meta` and `setuptools.build_meta:__legacy__` exactly, and treat any `backend-path` as unread. This also closes P10b, which passes on main too.
