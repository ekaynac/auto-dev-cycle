1. **High — Computation keys are mistaken for artifact identities.** [13:23](/home/mega/auto-dev-cycle/docs/design/m0/13-artifact-graph.md:23), [13:43](/home/mega/auto-dev-cycle/docs/design/m0/13-artifact-graph.md:43). The key hashes the computation’s inputs, not its output. Explicitly invalidating a non-pure model node can produce different output under the same key; downstream keys then remain unchanged or immutable artifacts must be overwritten. **Change:** separate computation/cache keys from immutable result identities; persist invalidation generations and result selection. Retain exact refs for manifests; use explicitly typed conclusions projections only for reuse decisions, preserving subject, demand, instrument and restriction constraints.

2. **High — Memoization can permanently cache temporary failure.** [13:46](/home/mega/auto-dev-cycle/docs/design/m0/13-artifact-graph.md:46), [12:49](/home/mega/auto-dev-cycle/docs/design/m0/12-evidence-jobs.md:49). Same-input reruns require operator invalidation or version changes, yet precondition recovery, exhausted credit and expired receipts require automatic retry. A cached `could_not_run` either blocks forever or repeatedly resolves to unusable evidence. **Change:** distinguish attempt records from reusable completed results. Define bounded automatic retries and freshness renewal without resetting demand counters. Test recovery with unchanged semantic inputs.

3. **High — Diff-only outcomes reintroduce false `empty`.** [13:84](/home/mega/auto-dev-cycle/docs/design/m0/13-artifact-graph.md:84), [02:11](/home/mega/auto-dev-cycle/docs/design/m0/02-vocabulary.md:11). A 402 before the first edit, cancelled run or failed startup has an empty diff but did not complete. D40 now calls it `empty`, contradicting the vocabulary and weakening the earlier exit mapping. **Change:** derive results from both observed execution completion and observed changes. Preserve partial patches separately; no changes plus incomplete execution remains `could_not_run`. Add the zero-edit failure fixture alongside the partial-edit fixture.

4. **High — Cached effects are not current external state.** [13:37](/home/mega/auto-dev-cycle/docs/design/m0/13-artifact-graph.md:37), [13:54](/home/mega/auto-dev-cycle/docs/design/m0/13-artifact-graph.md:54). After deploying A, then B, a new request for A can hit the old deploy artifact and leave B running. Conversely, a crash before artifact publication must resume the existing effect, not allocate another. Checking inputs only when resolved also leaves an expiry/revocation window before execution. **Change:** keep effect execution under 03’s durable operation identities and reconciliation. A cached receipt records history; it does not satisfy a new operation automatically. Revalidate mutable eligibility at admission/commit through 04 and 06, with explicit exceptions to the “inputs only” rule.

5. **High — Restore gating was removed before being expressed in lease transitions.** [13:96](/home/mega/auto-dev-cycle/docs/design/m0/13-artifact-graph.md:96), [05:54](/home/mega/auto-dev-cycle/docs/design/m0/05-leases-attempts-fencing.md:54). The supposedly complete lease machine permits `settling → settled` with usage/liabilities alone. It contains no persisted restore-verification transition, recovery owner or publication guard. Restart also closes attempt publication, leaving recovery publication unspecified. The former evidence lifecycle covered these cases explicitly. **Change:** encode restore obligation and verification in the lease contract; atomically guard settlement/publication, retain exclusion across restart, and distinguish controller publication of an accepted draft from late executor submissions. Test crashes, failed restore and replacement nodes on the same target.

6. **High — Merge-queue carry-over has no graph representation.** [13:54](/home/mega/auto-dev-cycle/docs/design/m0/13-artifact-graph.md:54), [plan:306](/home/mega/auto-dev-cycle/docs/plan/01-first-release-plan.md:306). The graph demands exact-tree applicable inputs, while the queue carries review/closure evidence across a changed tree. No rebinding derivation connects those contracts; simply reusing the old receipt violates 06, while rejecting it defeats carry-over. **Change:** specify queue generations with pinned base, prospective tree, refreshed evidence and either a controller-produced carry-over attestation or delta review. Serialize per branch; retain expected-base CAS, and instantiate another generation when the base moves.

7. **Medium — “Only the manifest” exceeds the adapter contract.** [13:75](/home/mega/auto-dev-cycle/docs/design/m0/13-artifact-graph.md:75), [10:56](/home/mega/auto-dev-cycle/docs/design/m0/10-context-manifest-and-knowledge-spec.md:56). Note 10 and adapter 09 explicitly allow unobservable harness instructions, internal tools and compaction. Rendering the initial prompt from inputs does not eliminate those channels or account for later tool results. **Change:** either require complete mediation for graph model nodes, including versioned harness instructions and tool deliveries, or narrow the guarantee to controller-supplied context and preserve partial/unknown coverage. A Go function signature likewise does not enforce controller-node purity.

8. **Medium — A deployment tree cannot universally replace the test workspace.** [13:109](/home/mega/auto-dev-cycle/docs/design/m0/13-artifact-graph.md:109), [07:32](/home/mega/auto-dev-cycle/docs/design/m0/07-project-profile.md:32). The export default is language-neutral, but not universally deployable or testable. TS build/test tools may be omitted with development dependencies ([npm](https://docs.npmjs.com/cli/v11/commands/npm-ci/)); Go deployment may contain only binaries, and removing repository metadata changes automatic VCS stamping ([Go](https://pkg.go.dev/cmd/go)); PHP production installs can omit test dependencies and development autoloading ([Composer](https://getcomposer.org/doc/03-cli.md)). **Change:** distinguish source-test workspace, package artifact and runtime verification fixture. Hash the actual package output and deploy those exact bytes. Separate build-time from runtime facts; declarations alone cannot guarantee environment parity.

9. **Medium — Producer labels do not prove producibility.** [13:117](/home/mega/auto-dev-cycle/docs/design/m0/13-artifact-graph.md:117). Keep semantic acceptance review; narrow the construction claim to what validation actually proves.

Keep v1 to the fixed template and existing scheduler/effect machines; cut generic memoization across arbitrary node kinds and arbitrary conclusions-only edges. Add atomic producer claiming and duplicate-demand fixtures.
