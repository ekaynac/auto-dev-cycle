### High

**H1. A loop that ran a subtest per row can drop those subtests silently if it gains any check.** `internal/accept/integrity_cases.go:325`, `:673-675`
- **Input:**
  - Base: `for _, tc := range []struct{name string; fn func(*testing.T)}{{"a", checkOne}, {"b", checkOne}} { t.Run(tc.name, tc.fn) }`.
  - Candidate: replace `t.Run(tc.name, tc.fn)` with `if tc.name == "" { t.Fatal(tc.name) }`.
- **What happens:**
  - The loop's identity goes from `row "a" @1 runs` to `row "a" @1 checks`, and the transition accepts that.
  - A subtest named by a row records no `run` identity.
  - Main's assertion count rises from 0 to 1, so the print is not compared.
- **Probe result:** no blocks, no warnings. Main gives the same.
- **Why it is in scope:** this is the nearest variant of Astra r2 2. A loop that no longer runs subtests is not a strengthening.
- **Fix:**
  - Label a loop by both bits: `runs`, `checks`, or `runs checks`.
  - Accept a base `runs` only against a candidate `runs checks` at the same position.
  - Add this input as a row.

**H2. A function literal's cases count where it is written, not where it runs.** `internal/accept/integrity_cases.go:295-296`, `:211-216`
- **Inputs:**
  - (a) In `TestSub` of `casesBase`, wrap `t.Run("other", …)` in `_ = func() { … }`.
  - (b) In `TestInline`, replace `sub()` with `_ = sub`.
- **What happens:**
  - Any literal not in `w.defs` is walked in place.
  - A closure with a non-call use is removed from `closures`, so its literal is then walked in place as well.
  - `run outer/other` and `run c` are kept although they never run. Counts and print are unchanged.
- **Probe result:** both are silent. Main is also silent.
- **Why it is in scope:** this is the closure promise (r2 8 and H3). The PR already blocks the `if false` form of the same removal (`subDeadKeep`).
- **Fix:**
  - Read a literal in place only when it is:
    - called on the spot (also under `defer` or `go`);
    - a callback of a testing value's `Run` or `Cleanup`;
    - an argument to a helper the guard follows.
  - Any other literal, and an unfollowed closure's literal, adds no identities and marks the summary opaque.
  - Add rows (a) and (b).

**H3. A table loop driven through a helper whose subtest has a named callback is not a driving loop.** `internal/accept/integrity_cases.go:476-477`
- **Input:**
  - `func runNamed(t *testing.T, n string) { t.Run(n, checkOne) }`
  - `for _, n := range []string{"a", "b"} { runNamed(t, n) }`
  - Remove `"b"`.
- **What happens:**
  - The subtest name is not a constant, so `helperSum(runNamed).ids` is empty.
  - `drives(runs)` is therefore false, and the loop's rows are never identities.
  - `runNamed` does not count as asserting, because `checkOne` is not a literal.
- **Probe result:** silent. Main is also silent.
- **Why it is in scope:** the file comment at `:31-32` promises loops that run subtests "through … a helper's subtests".
- **Fix:**
  - Add a `runs` bit to `caseSum`, set by any `t.Run` whatever its name.
  - In `drives`, use `h.runs || len(h.ids) > 0`.
  - Add this input as a row.

**H4. A literal subtest in a helper declared in several files (race and !race) is removed silently.** `internal/accept/integrity_cases.go:405-406`
- **Input:**
  - `raceHelper` is declared in a `//go:build race` file and a `//go:build !race` file. Each declaration runs subtests `"a"` and `"b"`, each with an assertion.
  - `TestH` calls `raceHelper(t)`.
  - Remove `"b"` from the race file, or from both files.
- **What happens:**
  - `helperSum` returns `{opaque: true}` with no identities, so the base has nothing to compare.
  - Main's count does not change, because every declaration still asserts.
- **Probe result:** both inputs are silent. Main is also silent.
- **Why it is in scope:**

  - The PR's Residual narrows that without a lead decision.

- **Fix:** either one of these, or obtain a lead decision accepting the residual.

**H5. Identity and row text are not charged, and grow quadratically.** `internal/accept/integrity_cases.go:347-349`, `:361`, `:365`, `:439`, `:445`
- **Measurements:** the probes ran the whole guard and read `runtime.MemStats.TotalAlloc`.

| Input | Size | Allocated | Charged | Growth |
|---|---|---|---|---|
| Rows sharing one name (`{"same", i}`) | 4,000 / 8,000 / 16,000 rows (70–290 KB file) | 285 / 1,026 / 3,914 MB | 0.25M / 0.51M / 1.04M | ×3.6–3.8 per doubling |
| The same rows, distinct names | 4,000 / 8,000 / 16,000 rows | 47 / 77 / 139 MB | about the same | linear |
| A 1 MiB name built from 8 bytes by 17 `const nI = nJ + nJ` lines, over a table | 932 B file, 100 rows / 1,432 B file, 200 rows | 252 / 450 MB (main: 43 MB both) | 2,672 / 4,872 | about 2 MB per row |
| Nested `t.Run(name, …)`, 4 KiB name | depth 100 / 200 / 300 (8–15 KB file) | 99 / 339 / 736 MB | 8K / 16K / 23K | quadratic in depth |

- **Rows sharing a name:** `rows[k] += …` copies the text built so far on every row. This is Astra's r2 3 pattern in another place.
- **Long names:** the rows of the doubled-name table are live identities kept in `pkgFacts`. By extrapolation, about 20,000 rows is about 40 GB, which kills the guard by OOM. The case code also never checks `ctx`.
- **Fix:**
  - Keep a running hash per identity instead of concatenated row text.
  - Charge `len(id)` (the prefix included) wherever an identity is built, in `rows`, `run` and `compose`.
  - Alternatively, key prefixes by a fixed-size digest.
  - Add a row that counts work against size for a repeated row name and for a long constant prefix.

**H6. Main regression: the case code spends the run-wide budget, so a broad change to this repository blocks.** `internal/accept/integrity_cases.go:111-115`, `:131`; `internal/accept/integrity.go:37`, `:227-233`
- **Why:** `charge` adds to `r.work`, which is never reset across directories, versions or layers. On main, Go spends that budget only on tag evaluations.
- **Measured case work per version (both platforms):**

| Directory | Case work |
|---|---|
| `internal/accept` | 2.25M |
| `internal/graph` | 1.11M |
| `internal/authority` | 0.89M |
| `internal/daemon` | 0.82M |
| All 65 directories with tests | 9.67M |

  - Both versions together come to **19.35M**, which is more than `maxWork` = 16,777,216.
- **Effect:** a change touching a Go file in every package (a header, an import or a rename) blocks the remaining directories "past the guard's work bound". Main accepts that change.
  - #315 adds its own body charges to the same counter.
  - The PR does not state this. Its replay never covers a change across the whole tree.
- **Fix:**
  - Give the case layer its own bound per package scan, as `r.out` has its own work, kept apart from `r.work`.
  - State the bound.
  - Replay one change that touches every package.
