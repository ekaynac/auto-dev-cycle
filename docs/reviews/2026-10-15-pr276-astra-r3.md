6. **High — H4 still hashes the full declaration name once per reference.**  
   `internal/accept/integrity_types.go:686`; `internal/accept/integrity_go.go:709`

   Concrete input: an added function has a 1 MiB identifier, obtains a FlagSet through unchanged `util.Flags()`, and contains 50,000 repetitions of `_ = w.Parse`. This fits below the file limit.

   Each types-layer reference calls `bound(where)` again. `bound` hashes the entire megabyte name before returning its short result: approximately **50 GiB of hashing per platform**. The charge uses the already-bounded `uses` string, so it does not account for that work. The text-layer loop likewise repeats `bound(where)` for newly-S references.

   Object-name caching fixes the earlier receiver example, but does not cache declaration names. Separately, `bound(o.FullName())` still constructs the full method text before bounding it.

   **Fix:** compute and cache bounded declaration identities once, outside reference loops. Charge original bytes when hashing/rendering names, and construct method identities from bounded components.
