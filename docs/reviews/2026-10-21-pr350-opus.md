**M1. A parameter declared through a type alias or a parenthesized type is not a testing parameter.** `internal/accept/integrity_skips.go:90-94`
- **Cause:** `testingParams` unwraps one `*` and calls `s.qual`, which recognises only a `pkg.Name` selector.
- **Inputs:** each base form below, with the test edit shown, is accepted on head and on main:
  - `type TT = testing.T` and `func needAlias(t *TT) { t.Skip("x") }`, used as `needAlias(t)`;
  - `type TBA = testing.TB` and `func needAliasTB(tb TBA) { tb.SkipNow() }`, used as `needAliasTB(t)`;
  - `func needParen(t (*testing.T)) { t.Skip("x") }`, used as `needParen(t)`.
- **Why it matters:** the promise says "its own parameters declared of a testing type". These are testing types, and the residual's "aliases" reads as variable aliases.
- **Fix:**
  - Run `ast.Unparen` before and after the `*` unwrap.
  - Resolve the type through the scan's own `s.alias` (`TT` → `testing.T`) before `qual`, as main's `mentions` already does.
  - Add both as rows. Or, if this is P14d-a2, state "a parameter declared through a type alias" in the residual.

**M2. A helper rewritten from a form that is not followed to the direct form blocks its callers. This is a new false block against main, not stated.** `internal/accept/integrity_skips.go:63-84`, and the comparison at `internal/accept/integrity.go:399`
