### Medium

**M1. gofmt can change a canonical text. On an integer-keyed map table this is an unstated false block.** `internal/accept/integrity_cases.go:375`, `:432-458`
- gofmt lowercases number prefixes and exponents (`0X1F` → `0x1F`, `1E3` → `1e3`). It also drops a trailing comma on a single-line composite literal.
- A map key with no string literal is identified by `canon(key)`. So in `for k, v := range map[int]int{0X1F: 31, 2: 2}`, running gofmt blocks `1 test cases removed (row 0X1F @1 checks)`. Main accepts it.
- Elsewhere the change only warns: a trailing comma dropped in a row warns through its row hash, and in a condition through the print.
- The comment says "gofmt changes none", and that claim is false.
- **Fix:** in `canonTo`, lowercase the prefix letter (`X`/`B`/`O`) and the exponent letter (`E`/`P`) of `INT`/`FLOAT`/`IMAG` tokens, as gofmt does. Drop a comma that comes directly before `}`, `)` or `]`. Add both inputs to `TestIntegrityCasesCanon`.

### Low

**L1. Asserting literals nested inside one another still charge quadratically. It is bounded, but at the bound it is an unstated false block.** `internal/accept/integrity_cases.go:570`
- Each assertion's canonical text contains every literal nested inside it.
- The charge grows as n²: 92M units at n = 1,600, 369M at 3,200, 1.48G at 6,400 (230 KB, 27 s; main takes about 3 s).
- By extrapolation, the 2³¹ bound is reached at about n = 7,700, a file of about 280 KB. That file would block "past the guard's work bound", and main accepts it.
- **Fix:** when building an assertion's print text, skip the bodies of function literals nested in it, and keep a marker in their place. Those literals' assertions are separate print events already. Each byte is then read once.
- Otherwise, add this input to the stated false blocks.

**L2. An early exit added together with an assertion is silent, as on main.**
- Input: `if Add(1, 1) != 2 { t.Error("more") }` and `if … { return }`, both added before `t.Run("c", …)`.
- The counts change, so the print is not compared, and the exit is missed.
- **Fix:** compare the exit events whatever the counts, or name this in the residual.
