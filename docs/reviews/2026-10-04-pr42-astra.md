   [schemas/records/approval.json:82](/tmp/claude-1000/-home-mega-auto-dev-cycle/d7e41cde-3883-4e5c-8d98-04b890c5f4c4/scratchpad/wt-au/schemas/records/approval.json:82) and `:92`: both `ObjectRef` and `ExpectedState` accept `{"version":null,"digest":null}`.    **Fix:** require at least one non-null value in both definitions. Preserve version-only, digest-only, and both-present forms. Use the existing version-zero convention for an absent object. Add rejection tests covering all three consuming records.

2. **Medium — Human confirmation can record no confirmation evidence.**  
   [schemas/records/approval.json:34](/tmp/claude-1000/-home-mega-auto-dev-cycle/d7e41cde-3883-4e5c-8d98-04b890c5f4c4/scratchpad/wt-au/schemas/records/approval.json:34): `{"policy":"human","challenge":null,"satisfied_by":[]}` validates. Independent-review confirmation also accepts an empty event list. These are structurally incomplete approval records, even before checking whether the referenced evidence is applicable.

   **Fix:** add conditional constraints requiring a non-null challenge for `human` and nonempty `satisfied_by` for either confirmation policy. Add negative fixtures. Evidence verification remains authority’s responsibility.
