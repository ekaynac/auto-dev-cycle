# PR #79 (fake adapter): Opus review

## Review of #79 (Opus, 2026-10-05)

Verdict: GO with changes (one High)

- **High H1: cancel during a tool call ended the run with a JSON-RPC error, not a stopped result.**
  - `await tools.response(request)` rejects on abort, and the fake did not catch it.
  - 09 lists "cancel during a tool call" as a conformance case, so the reference fake would only pass that case by
    treating a protocol error as a cancel response.
  - The hang test hid this class of bug by accepting either a result or an error.
- **Medium M1: the tests did not prove several promises.** Eight mutations survived:
  - text returning a patch;
  - a turn or upstream naming the wrong sub-call;
  - errors with no partial work;
  - errors with no usage events, but an invented final;
  - output tokens not summed;
  - coverage removed;
  - the usage `sub_call` wrong;
  - `tool.result.bytes` set to 0.
- **Medium M2: coverage contradicted 09.** Edit turns declared `complete`, although 09 says a turn with harness tools is
  `partial`. There was no compaction scenario, and no non-mediated `tool.result`.
- **Medium M3: error runs reported a final usage the adapter cannot know.** `run-result.json` says an interrupted run's
  final is null, never invented.
- **Medium M4: bad `ADC_FAKE_GAP_MS` values were accepted silently.** `abc`, `-5`, `""` and an overflow each ran
  with a gap of about 1 ms.
- **Medium M5: `broken-event` is the SDK's red-proof, not the kit's.** The kit needs violations that pass the schema:
  - a skipped sequence number;
  - an unannounced sub-call;
  - a patch that is not cumulative.
- **Low:**
  - L1: casts hid type errors.
  - L2: the second turn had no upstream event, and its usage ignored `no-usage`.
  - L3: the tool request came before the tool-call delta, and the tool policy was ignored.
  - L4: cheap scenarios were missing.
  - L5: the deferred modes are listed correctly.
  - L6: the gap test's margin was small, and a missing second delta made it pass vacuously.
  - L7: `bin` had no shebang.

### Lead notes (applied)

- **H1:**
  - The tool scenario catches the rejection. When the run is aborted it returns `could_not_run/attempt_stopped`, with
    no result and no final.
  - A test cancels at `tool.request`.
  - The hang test now requires exactly that stopped result.
- **M1:**
  - `usage_final` is compared with a field-wise sum the test computes itself, apart from the fake's `sum`.
  - Every `turn.start`, `upstream` and `turn.end` names its sub-call, and each sub-call is announced before use.
  - Each error scenario shows a `delta.tool_call` and a usage event before the error.
  - The text kind, one coverage per completed turn, and `tool.result.bytes` are asserted.
- **M2:**
  - Edit turns stream a `delta.tool_call`, then the harness's own `tool.result`
    (`mediated_by_controller: false, delivered: null`), and declare `partial` with `harness_tool`.
  - Text-only turns stay `complete`.
  - A `compaction` scenario declares `compaction`.
- **M3:** every error scenario returns `usage_final: null`. Its usage deltas stand, and the call stays uncertain until
  reconciliation (05).
- **M4:**
  - `main.ts` accepts only 1–10 decimal digits.
  - The constructor requires an integer from 0 to 2^31−1.
  - A test spawns `main.ts` for five bad environments, each exiting 2.
- **M5:**
  - `broken-event` is relabelled the SDK's red-proof.
  - `bad-sequence`, `unannounced-sub-call` and `non-cumulative` are the kit's: they pass the schema and break the other
    rules, and tests show each break.
- **L1:** the casts are gone, except the one deliberate off-contract event. Hints are typed as the `class_hint`
  union.
- **L2:** every turn has its upstream event, and every usage event is guarded.
- **L3:** the tool-call delta precedes `tool.request`, and a policy that does not mediate the tool gives
  `could_not_run/executor_incomplete` without a request.
- **L4:** added `no-change` (empty, not found), `other-error` (`executor_incomplete`) and `two-errors` (5xx, then
  credit, giving `broker_credit_exhausted` by the exit map's precedence). A refused `prepare` waits for a reason
  decision.
- **L5:** the handles name files the fake does not write. That stays deferred until the contract carries an exchange
  root.
- **L6:** the gap is 600 ms against 50 ms beats, and the test requires a second delta.
- **L7:** `main.ts` has a shebang.
- **Mutation:** 20 points, all killed, including the reviewer's eight survivors.
