Observe: `EndingOf` returns `ErrEnding{Lease: false, Entry: att_…}`; `Decide` puts `Ending` first; `End` runs, `endEntry` calls `leftAt`, which refuses `lost`, returns nil, the re-read finds the same entry, `errNothingEnded`, backoff, the card `ending_blocked {unit, "the attempt's seal did not land"}`. ### Judged

1. **H1 closed per shape.** An attempt: running and stopping while the runner runs it: the node is live, `start` refuses, no try (main's silence, unchanged); finishing: `leftAt` + `endOne`, the fixture; lost or stopping left unsealed: not closed (H1′). A lease: active or settling with an attempt (the only way to be active or settling: `ApplyLease` sets `Attempt` on `attempt.started` alone): `leftAt(*l.Attempt)` + `endOne`, the fixture's first row (the run's own `lease.completed` fails, End's first try fails, the second ends it); granted with no attempt: `endLease` refuses and releases, the fixture's second row (`noRuns`); releasing: `endLease` releases; requested or waiting: not adcd's (only `fakesched` writes `waiting`, and `RequestGranted` grants in the same command). No shape nudges every pass: `errEndRetried` never nudges, and `start` holds `live[node]` until `next` is set. The tries that issue no command are H1′'s.
2. **The `endLease` deviation.** Right. `endActive(Revoked)` moves only an active or settling lease, and a granted or releasing lease has no attempt by construction. It cannot release a lease whose attempt runs: `endEntry` takes the branch only when `l.Attempt == nil` at the read, and `endLease`'s command re-reads and acts only on `granted` or `releasing`; an attempt start moves the lease to `active` in its own transaction under the lease's expected revision, so a race leaves the lease as it is. Nothing can start one anyway: `Decide` returns `Ending` alone, so no `Run` is decided while a unit still runs. No hold is raised (`cause` nil).
3. **M1, L1 to L4.** M1: `retryAfter(n)` gives the old values at both sites (`run_test.go:1123` pins them); one site left. L1: `DoneTask` checks `decided` in its own transaction after `endable`; one rule, `decided`, shared with `EndingOf`. L2: `EndingOf(tx, task)` reads the nodes itself; the board keeps `CandidateGo` for its column only, which is the column's rule, not the end's. L3: `Redact` compiles the schema's own `TypeID` pattern (`^[a-z]{2,3}_…$`, unanchored with `\b`); the Go copy of the alphabet is gone, `redact_test.go` covers fresh ids and near-misses. L4: one task's unreadable record lists that task `damaged_record` in the board and the task list, the board's own rule; the other errors of `endingOf` (`ErrNotEndable`, nil) are unchanged.
4. **New or regressed.** No regression against main in admission order, the board's columns, the repair path, the launch's retry hold or the start sweep. The fix delta adds no second implementation: `endEntry` is a dispatcher over `leftAt`, `endOne` and `endLease`; `decided` replaces three callers' copies; `retryAfter` replaces two shifts; `Redact` replaces one regexp. H1′ is not new to this PR, but it is the half of H1's class the fix leaves open.
