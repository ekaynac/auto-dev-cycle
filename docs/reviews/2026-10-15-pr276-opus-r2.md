### Isolation (design claim): holds

- **Main's stream is byte-identical** on every row, including Astra r3 #1 (669/669 warnings), r3 #2 (main's `~p:p` block, non-Additive, reported), r3 #3 (main's `zzz/out.go` warning in the verdict and the report), a mixed row (main 2 blocks and 3 warnings, plus layer 1 block and 5 warnings) and all 16 tag and literal rows. On every row, the head's `Report()` lists begin with main's report lists exactly.
- **The changes to main's files are inert.**
  - The `Block` literals' fourth value is always `false`.
  - `Listed.Standard` is read only by the layer. go list adds the field only for std packages (omitempty), which is a few KB against `maxList` (16 MiB). The cache key and failure paths do not change.
  - The hook runs after the package loop. Every early return (`list`, `goMod`, `python`, `pkg` errors) comes before it, so the layer never runs on a path where main returned.
  - `own()`'s `t.typer` and the layer's `r.file` touch `r.blobs`, `r.budget` and `t.typers` only after main is done. Main's counters are not read again.
  - `Result.Detail` and `Reason()` iterate `v.Blocks` in order, with main first.

### High

**H1. Negated unmodelled tags hide every promised signal: a parser and build-constraint differential.** `internal/accept/integrity_out.go:89-106`. `outBuilt` puts every tag it does not model into `BuildTags` as set. That is fail-closed for `race`, but fail-open for `!race`. The gate platforms' own GOARCH names (`amd64`, `arm64`) are not in `otherPlatforms`, so they are set on *both* platforms. As a result, `!arm64` and `!amd64` files read as never built. The gate builds all of these files by default; the lister itself runs with `CGO_ENABLED=0`.
- Probes (candidate file; head / main):
  - A1 `//go:build !race` + `libc.X_Exit` in tested `pkg`: accepted, silent / accepted, silent.
  - The same for A2 `!arm64`, A3 `!cgo`, A4 `!purego` and A5 `// +build !race`: silent / silent.
  - A7 `!race` `flag.Parse` untested: silent / silent.
  - A8 `!race` new import of `example.org/lib`: silent / silent.
  - A9 `!amd64` `import . "flag"` in tested `pkg`: silent / silent.
  - A10 `pkg/x_test.go` `!race` with `flag.NewFlagSet(…, ExitOnError).Parse([]string{"-h"})`: silent / silent. This is the slice row's own failure probe.
  - Controls: A0 untagged and A6 `//go:build race` both block at the head.
- Main's `goOn`/`holds` evaluates every assignment of the free tags (result 1, "maybe built"), so the layer's file view differs from main's and from go's.
- **Fix:** the file counts as built on a platform if *some* assignment of the unmodelled tags holds. Treat the platform's GOOS, GOARCH, `unix` and `gc` as known, as `holds` does. Enumerate up to 12 free tags and treat more as built. Charge `r.out.work`, not `r.work`. Add rows A1–A3, A9 and A10.

**H2. The layer's work bound blocks ordinary large changes that main accepts: a verdict regression.** `integrity_out.go:59, 63-69, 113, 146`. `maxOutWork = maxWork` (1<<24) was sized for tag evaluations and Python tokens. The layer charges it with every byte of every Go file in every touched directory, once per version (unchanged files twice), plus one per AST node. The total is global across directories. Past it, an Additive block blocks the verdict. Main's own read bound is 64 MiB.
- Probe C1: the base has `tool/gen1.go` and `tool/gen2.go` (3 MiB of generated `[]int{0,0,…}` each). The candidate adds a 1-line `tool/x.go`.
  - head: **blocked**, "unverifiable: decision A's outside-initialization check is over its work bound".
  - main: accepted.
- Typical source reaches the bound at about 7 MB of Go in the touched directories in total, so a rename that touches many packages of a large repository blocks too.
- **Fix:**
  - Do not charge bytes again: `r.budget` already bounds them. Alternatively, give the layer a byte bound of `maxRead` per version.
  - Charge nodes against `maxWork`.
  - Parse each blob once (cache by blob id, not by version).
  - Add C1 as a row that must be accepted.

### Medium

**M1. New S references in a function literal assigned inside `init` are silent.** `integrity_out.go:140-141`. The layer skips the whole `init` declaration. Main's initialization walk does not enter deferred literals. The literal's body runs outside initialization, from code the tests call.
- Probe S2: base `pkg/hold.go` has `var parse func()`. The candidate adds `func init() { parse = func() { fs := flag.NewFlagSet("x", flag.ExitOnError); _ = fs.Parse([]string{"-h"}) } }` to tested `pkg`. head: accepted, silent. main: the same.
- Probe S1: the same with `libc.X_Exit(nil, 0)`, class 2. head: accepted, with only the import-edge warning. With libc already imported in the directory, nothing at all. main: silent.
- The moved residual names "#4 a deferred literal in init", which is a *changed* body. A *new* reference is not stated.
- **Fix:** inside skipped `init`/`TestMain` declarations, inspect `*ast.FuncLit` bodies with `where = "init literal"`, or state this form in the residual.

**M2. A cancelled context during the layer becomes a candidate-attributed block, not an error.** `integrity_out.go:64`. `charge` turns `r.ctx.Err()` into the Additive "over its work bound" block, and `check` returns nil. `accept.go:105-106` says an error is the controller's fault and a verdict is the candidate's.
- Probe B2: the guard's context is cancelled while the layer reads `tool/README.md`.
  - head: `err == nil`, verdict **blocked** "over its work bound".
  - main: never reads that blob; accepted.
- **Fix:** on `ctx.Err()`, stop the layer without a block and return `ctx.Err()` from `check`, as main's `goOn` and `need` do.

**M3. The layer reads every non-Go blob in the touched directories.** `integrity_out.go:112-113`. `r.file` runs before the `.go` test, so the bytes are read, kept in `r.blobs` and charged to `r.budget`, but not to `r.out.work`.
- Probe B1: `tool/x.go` changed beside a 3 MiB `README.md`. Bytes read: head 3,146,381, main 639.
- **Fix:** test `path.Ext(p) == ".go"` before `r.file`.

**M4. A new use through an existing dot import of a newly-S package is silent, and the residual does not say so.** `integrity_out.go:128-129, 200-206`. Only a new dot import signals, and unqualified uses are never references.
- Probe S3: the base `pkg/hold.go` already has `import . "flag"`. The candidate adds `func P() { fs := NewFlagSet("x", ExitOnError); _ = fs.Parse([]string{"-h"}) }` in tested `pkg`. head: silent. main: silent.
- **Fix:** while a file has a dot import of an outS package, treat any change to that file as one Additive warning ("references through a dot import of flag may have changed"), or state it in the residual.

### Checked, no issue (parser differential)

- **Parse errors:** the layer skips the file silently. Main parses the same bytes with the same go/parser, and the mode flags (`ParseComments`, `SkipObjectResolution`) change no acceptance, so main's "unverifiable: not parsed" block always covers it.
- **Reads:** a read error stops main. A read over the bound is main's `bad` block. The layer reads no `.go` file that main does not.
- **BOM and NUL:** go/parser and go/build both skip a leading BOM. NUL is a parse error, covered by main.
- **File names and suffixes:** `_`/`.` prefixes, `_GOOS`/`_GOARCH` suffixes and `_test.go` are go/build's own `MatchFile`.
- **Other constraint cases:** `ignore` matches the residual. Duplicate or unparsable `//go:build` lines fail go itself. `gccgo` is in `otherPlatforms`. cgo files are a main block.
- **Object resolution:** a local declared after its use is still counted. A package-level redeclaration of an import name does not compile.
- **The only differential that hides signals is H1.**

### Budget and cost

- **Name bounding:**
  - `bound(fn.Name)` is charged once per declaration.
  - `bound(sel.Sel.Name)` hashes per reference, but each call charges its length, so total hashing stays within the bound.
  - The changed keys are charged.
- **Uncharged input-sized work:**
  - M3's non-Go reads.
  - `outBuilt`'s header and `MatchFile` per file, per platform, per version. Probe C2 (20,000 `+build` lines) took 1.13 s at the head against 0.86 s on main.
  - `own()`'s two `local()` walks per new import, which have the same shape as main's loader.
  - Sorting the keys.
- **Time:** the layer has no wall-clock bound besides the context (`listEnd` is not applied). The r3 #3 input took 4.8 s at the head against 4.6 s on main.
