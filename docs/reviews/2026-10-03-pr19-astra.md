# PR #19 (Go type generator): Astra reviews

Reviews of the generator PR. Each section is the review as returned; file links are relative to the repository root.

## Review of #19 (Astra, 2026-10-03)

Verdict: NO-GO

**High**

1. **Keyed unions silently discard envelope fields.** `internal/schemagen/unions.go:115,170` checks only each branch’s local `properties` and `required`, then emits only that property. A branch embedding an envelope with required `e`, alongside local required `a`, is accepted. A schema-valid `{"e":"envelope","a":"value"}` then fails strict decoding with `unknown field "e"`; ordinary decoding/re-encoding drops `e`.

   **Fix:** classify keyed branches using their complete effective shape. Refuse envelope-bearing branches that do not meet the single-key grammar, or represent their complete contents. Add a schema-validation-plus-generated-decoding regression.

2. **Nullable aliases bypass “nullable implies required” and lose explicit nulls.** `internal/schemagen/gen.go:76,597` records nullability only for direct `$defs` unions. With `N = oneOf[null,string]`, `Alias = $ref N`, and optional `p = $ref Alias`, generation succeeds and emits an optional pointer to an already nullable alias. Confirmed: `{"p":null}` decodes successfully and re-encodes as `{}`.

   **Fix:** resolve nullability transitively, including named root schemas, before checking optional fields, nested nullables and keyed branches. Add alias-chain and cross-file regression cases.

**Medium**

3. **Accepted property names can change their wire names.** `internal/schemagen/gen.go:613` inserts schema keys directly into JSON tags. A required property named `a,b` becomes `json:"a,b"`: strict decoding rejects the schema-valid key, while encoding emits `"a"`.

   **Fix:** check whether each key is representable by Go’s JSON-tag rules; preserve unsupported keys through custom encoding or explicitly refuse and document them. Test commas, quotes and other tag-sensitive characters.

4. **Cross-file traversal loses the reference’s source context.** `internal/schemagen/gen.go:246` discards the resolved file, and `internal/schemagen/unions.go:45,170` processes referenced keyed-branch properties relative to the union’s file. A valid cross-file keyed branch containing a local `$ref` is therefore rejected. This also bypasses the new string-target check: a cross-file alias chain ending in an integer accepts a sibling `pattern`, because `deref` returns nil and line 352 skips the check.

   **Fix:** carry the originating file through reference traversal and branch processing; fail closed when the refinement target cannot be established. Add multi-hop, cross-file tests.

5. **Several schema positions bypass the promised grammar checks.**
   
   - `internal/schemagen/unions.go:44`: union-branch `$ref` siblings are discarded; a sibling `anyOf` is accepted.
   - `internal/schemagen/unions.go:364`: `not` is checked only one level deep; `not → not → anyOf` is accepted.
   - `internal/schemagen/unions.go:170`: inline keyed branches bypass condition validation, accepting conditions on undeclared properties.
   - `internal/schemagen/gen.go:431`: `propertyNames` is allowed without checking its schema.

   **Fix:** validate every schema-bearing position recursively before emission. Extend refusal tests to these placements and depths. Disabling the existing checks proves those checks are exercised, but does not establish complete traversal.

6. **Optional collections are refused despite the documented grammar.** `internal/schemagen/gen.go:599` rejects optional arrays and maps. The spike specifies optional non-null fields as pointers with `omitempty`; `*[]T` and `*map[string]T` can distinguish absence from present empty collections.

   **Fix:** generate pointer fields and test absent/empty/populated round trips. Otherwise, explicitly amend the grammar to exclude these forms; the current refusal tests encode an undocumented restriction.

7. **Generated methods are missing from field-collision checks.** `internal/schemagen/unions.go:187` reserves `List`, but not `MarshalJSON` or `UnmarshalJSON`. An array-or-literal union with literal `"marshalJSON"` returns generated source successfully, then fails compilation with “field and method with the same name MarshalJSON.”

   **Fix:** reserve generated method names when claiming fields and add compile/refusal regressions.

8. **Output filenames can collide silently.** `internal/schemagen/gen.go:105,111` maps both `a/b.json` and `a_b.json` to `a_b.gen.go`; the latter overwrites the former. `helpers.json` also collides with the generated helper file.

   **Fix:** claim output filenames explicitly, including the helper filename, and refuse collisions before returning output.

The two validation-only forms are shape-preserving **in principle**: they intersect existing constraints rather than widen the underlying types. Go values violating refinements remain possible by design and belong to runtime validation. The enforcement gaps above nevertheless break the “exactly this grammar” contract.

`make ci` passed locally; shellcheck was unavailable and skipped. Additional sandboxed probes reproduced the findings. Normal union/accessor paths use strict decoding, but the current tests do not cover these compositions and collision cases. The two High findings block approval.
## Second review of #19 (Astra, 2026-10-03)

Verdict: NO-GO

First-review findings:

1. **Keyed unions dropping envelope fields — Fixed.** Envelope-bearing and conditional branches are refused.
2. **Nullable aliases — Partially fixed.** Short and cross-file chains work; long chains still lose explicit nulls.
3. **Tag-unsafe property names — Fixed.** Unsupported JSON tag names are refused.
4. **Cross-file resolution context — Fixed.** Traversal preserves the source file; unresolved refinements fail closed.
5. **Unchecked schema positions — Partially fixed.** All reported examples are addressed, but additional bypasses remain below.
6. **Optional collections refused — Fixed.** Pointer fields preserve absent, empty and populated values.
7. **Generated-method field collisions — Fixed.** Array-or-literal fields reserve both JSON method names.
8. **Output filename collisions — Fixed.** Flattened filenames and the helper filename are checked.

**High — Discriminator decoding can silently select another branch and discard data.**

[internal/schemagen/unions.go:162](internal/schemagen/unions.go)

The discriminator is decoded into a single-field struct using `encoding/json`, which matches property names case-insensitively. Consider two closed branches: branch `a` requires `kind: const "a"` and `KIND: string`; branch `b` requires only `kind: const "b"`. Both branches generate successfully.

Confirmed with generated code: schema-valid `{"kind":"a","KIND":"b"}` decodes successfully into branch `b` and re-encodes as `{"kind":"b"}`. The output also validates against the original schema, so output validation cannot catch the loss.

**Fix:** extract the discriminator by exact JSON key, for example through `map[string]json.RawMessage`, then strictly decode the selected branch. Add round-trip regressions with case-related keys in both property orders.

**High — Reference-depth exhaustion bypasses nullability checks.**

[internal/schemagen/gen.go:275](internal/schemagen/gen.go)

`derefFrom` returns nil after its 16-iteration limit; `isNullable` interprets that as non-nullable. With `N = oneOf[null,string]`, sixteen aliases leading to `N`, and optional property `p` referencing the last alias, generation succeeds.

Confirmed: `{"p":null}` decodes and re-encodes as `{}`. Both documents validate, reproducing the original High finding beyond the traversal limit.

**Fix:** traverse alias chains with cycle detection and propagate unresolved/depth errors instead of treating them as non-nullable. Test the traversal boundary for optional fields, nested nullable unions and keyed branches.

**Medium — Schema-position checks still accept shapes outside the grammar.**

[internal/schemagen/gen.go:256](internal/schemagen/gen.go), `internal/schemagen/unions.go:34,359,386`

`only` checks keyword names without requiring an object schema. Consequently, conditions accept `if:false, then:false`, and property constraints accept `not:false`, despite boolean schemas being outside the declared grammar.

Separately, an array-or-literal branch accepts `{"const":"x","type":"integer"}` because it checks allowed keywords but skips the string-const type check enforced by `typeOf`. All these examples were accepted in probes.

**Fix:** enforce schema node kinds at every schema-bearing position and reuse the full string-const validation for literal branches. Add refusal tests for these placements.

**Medium — Recursive collections generate invalid Go aliases.**

[internal/schemagen/gen.go:390](internal/schemagen/gen.go)

For `$defs.A = {"type":"array","items":{"$ref":"#/$defs/A"}}`, generation succeeds with `type A = []A`. Compilation fails with `invalid recursive type: A refers to itself`, although `[]` validates against the schema.

**Fix:** emit a defined recursive collection type such as `type A []A`; detect and explicitly refuse reference cycles that cannot be represented. Add a generated-code compilation regression.

`make ci` passed locally; shellcheck was unavailable and skipped. Additional probes ran inside the repository’s test sandbox, validated the input documents, and compiled/exercised generated code. The working tree remains clean. The two High findings block approval.
