### Findings
- **B1** (BLOCKING under entry 202: data loss outside the run's own directories, an operator-environment input that fails OPEN). It is H1(a)'s namespace trigger, still open.
  - **Where:** `stale` (`scripts/lib/sandbox-root.sh:141-145`) reads a pid that is absent from the sweeper's `/proc` as "gone" (`:143`). It compares start times across namespaces (`:144-145`).
  - **Effect:** shown above in both directions. A live run's work directory, sandbox root and `runs/` are removed while its owner runs.
  - **Fix:** put the PID namespace in the owner record. `owner_of` then prints `PID START NS`, with `ns="$(readlink "/proc/$1/ns/pid")" || return 1` and `[[ "$ns" =~ ^pid:\[[0-9]+\]$ ]] || return 1`. `stale` accepts only `^([0-9]+)\ [0-9]+\ (pid:\[[0-9]+\])$`, reads `here="$(readlink /proc/self/ns/pid)" || return 1`, and returns 1 (keep) unless the two match. Only then come the `/proc/$pid` and start-time tests. `.pids`' comparison in `work_dirs_stale` follows, since it compares `owner_of`'s whole line.
  - **Rows:** the two bwrap probes above, a live owner kept in each direction, skipped only when bwrap cannot make a PID namespace. Also a record of another namespace that is kept.
- **B2** (BLOCKING under entry 202: a scan that passes without searching all it promises).
  - **Where:** `forms` (`scripts/lib/secrets.sh:59`), the `|| hex=""` fallback.
  - **Effect:** a dying `od`, `tr` or `base64 -d` drops the hex form with status 0, so `scan`, `root_secret_scan` and `known`'s redaction all miss it. Probe above: `scan` exits 0 over a file holding the hex form.
  - **Fix:** decide "is base64" without a producer, then check the pipeline: `hex=""; if [[ "$pad" =~ ^[A-Za-z0-9+/]*={0,2}$ ]]; then hex="$(base64 -d <<<"$pad" | od -An -tx1 | tr -d ' \n')" || return 1; fi`. Probed:
    - a base64url secret: 7 forms;
    - a `tok_x.` token: 7;
    - a non-base64 credential: 6;
    - `A`: 6;
    - a dying `od`: `forms` fails.
  - **Rows:** `od() { return 1; }` (and a killed one) for `known` and for `scan` in `TestProducersThatFailRefuse`.
- **O1** (OBLIGATION, Low: fails closed).
  - **Where:** `record_pid`'s new `return 1` ends the driver, exit 1, with no message, at `scripts/installed-cycle.sh:330` and `:363` and `scripts/lib/cycle-case.sh:98`.
  - **Effect:** a host fault is recorded as a failed case.
  - **Fix:** at each call, `record_pid "$work" "$stub" || cannot "the stub provider's start time cannot be read (its sweep record)"`, and the same for adcd and the event reader.
- **O2** (OBLIGATION, Low).
  - **Where:** the static row's test pattern, `test/installcheck/cycle_classes_test.go:72`. It misses `sandbox-root.sh:240`, a substitution in a test.
  - **Fix:** use `\[\[([^]]|\][^]])*\$\([^(]`, add a sample with a bracket expression before the `$(`, and either list `:240` with its reason (a start time that cannot be read is "not that process", never killed) or acquire it first: `now="$(owner_of "$pid")" || now=""`, which is then listed.
- **O3** (OBLIGATION, Low).
  - **Where:** L1's change to `scripts/installed-cycle-set.sh:27-28` has no row; the `BASH_SOURCE` mutant there survives the suite.
  - **Fix:** add the set to the inherited-`BASH_SOURCE` row: a stand-in driver, with `BASH_SOURCE=/nonexistent/x` in the set's environment, still reaches its preflight.
