1. **High — Labeled fallthrough hides a live default, weakening main’s verdict.** `internal/accept/integrity_cases.go:280`, `internal/accept/integrity_cases.go:300`

   **Input:** In a `_test.go` file, with `check` containing an assertion:
   ```go
   func TestFall(t *testing.T) {
       switch true {
       case true:
           goto next
       next:
           fallthrough
       default:
           t.Run("check", check)
       }
   }
   ```
   At head, delete only `t.Run("check", check)`.

   Go permits a labeled fallthrough as the clause’s last non-empty statement. [Go specification](https://go.dev/ref/spec#Expression_switches)

   `isFallthrough` accepts only a bare `*ast.BranchStmt`; the last statement here is an `*ast.LabeledStmt`. Consequently, the new default rule marks this **executed** default dead in both versions. Its subtest disappears from the base’s case facts, so removal passes. Main retains that default’s case and blocks its removal. The unchanged named callback contributes no direct assertions to `TestFall`.

   This is outside the stated residual for defaults that never execute. Trailing explicit empty statements after a fallthrough cause the same misclassification.

   **Fix:** Find the last non-empty statement, unwrap labels, and then recognize fallthrough. Preserve the reached clause and warning.

   Thus a promised direct assertion disappears without a block or warning. The PR’s reliance on main for outright assertion removal does not cover the newly recognized forms.

   **Fix:** Compare tests’ own direct live counts for decreases as well, retaining main’s existing checks. Suppress duplicate diagnostics rather than skipping this comparison.

3. **High — Composed pointer aliases silently lose field assertions.** `internal/accept/integrity_go.go:617`

   **Input:**
   ```go
   type TT = testing.T
   type TP = *TT
   type suite struct{ t TP }

   func (s suite) check() {
       if Add(1, 2) != 3 {
           s.t.Fatal("bad")
       }
   }

   func TestAlias(t *testing.T) { suite{t}.check() }
   ```
   Replace `s.t.Fatal("bad")` with `_ = s`.

   `s.alias(TP)` returns `*TT`: alias traversal stops at the pointer expression. The field classifier strips that pointer, then calls `qual(TT)` without resolving `TT`. Consequently, it never records the field in `fieldT`, and `check` has zero counted assertions in both versions. The test stays unchanged, producing no block or warning.

   This uses local aliases expressly included in the promise; the deeper-embedding residual does not cover it.

   **Fix:** Resolve aliases, parentheses, and pointer structure together using a memoized, charged resolver. An exhausted resolution must become unverifiable rather than silently unrecognized.

4. **Medium — Embedded-field detection adds uncharged quadratic work.** `internal/accept/integrity_helpers.go:181`

5. **Medium — Distinct overlapping referrer sets still make rename comparison quadratic.** `internal/accept/integrity_helpers.go:276`
