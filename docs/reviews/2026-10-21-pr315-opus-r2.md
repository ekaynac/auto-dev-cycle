### High

**H1. `direct`'s copy search is quadratic and uncharged, a regression against main.** `internal/accept/integrity_skips.go:117-135`
- **Cause:** the search memoizes only its start variable (`s.directs[o] = ok`, `:135`). Each `Skip` selector on a copy walks the whole copy chain again, and none of it is charged to `skipWork`.
  - `ctx` is checked only between items (`:211`), so a deadline cannot stop it inside one body.
  - `r.direct` stops the search only after a yes. A chain whose answer is no is searched again at every `Skip`.
- **Input:** a base test file in `pkg` with one helper, and a candidate that only adds a comment to `pkg/calc.go`. The helper is:
  - `u0 := t; u0 = nil`;
  - then `u1 := u0` … `un := u(n-1)`;
  - then `un.Skip()` … `u1.Skip()`.
- **Measured:** one guarded run:

| n | File size | Head | Main |
|---|---|---|---|
| 2,500 | 72 KB | 3.6 s | 0.41 s |
| 5,000 | 147 KB | 14.0 s | 0.42 s |
| 10,000 | 297 KB | 71.4 s | 1.0 s |

  The cost grows about five times per doubling, and no block results. [INFERENCE] A file near `maxFile` (4 MiB, n ≈ 140,000) would take hours per run.
- **Why it is in scope:** it is the bounded-work promise (Astra #292 r2 6), and the same shape as round 1's H3.
- **Fix:** compute the "not direct" set once per scan.
  - Seed it with every variable that is `indirect` or has no testing type.
  - Run one reverse BFS over the inverted `copies` edges.
  - `direct(o)` then becomes a map lookup. Charge the BFS steps to `skipWork`.
  - Add a row with this input at n = 2000 against n = 8000, with a deterministic counter (as in L1).

### Medium

**M1. A variable holding a skipping helper's result becomes skipping: a new false block against main, not stated.** `internal/accept/integrity_skips.go:65-72`, `:173-178`, `:206`
- **Cause:** `held` records every value assigned to a package variable. `skipRead` then counts every function referenced in that value, including a function called only for its result.
- **Input (base):**
  - `func requireServer(t *testing.T) *S { t.Skip("no server"); return &S{} }`
  - `var shared *S`
  - `func setup(t *testing.T) { shared = requireServer(t) }`
  - `func url() string { if shared == nil { return "" }; return shared.URL }`
  - `var client *S`, `func connect(t *testing.T) { client = requireServer(t) }`, `func closeClient() { client = nil }`
- **Candidate edits that block:** each one, added to an existing test, gives "a test skipped (a skipping helper used)" on head and is accepted on main:
  - `_ = url()`;
  - `if shared != nil { t.Log(shared.URL) }`;
  - `defer closeClient()`.
- **Why it is unstated:** none of these runs or names a skipping helper. The residual's "a use in a test that never runs it" does not cover them.
- **Fix:** in a value, do not count a function that appears only as the callee of a call outside a function literal. The call's result is held, not the function. Keep counting it when the call's result type is a function, or can hold one (`pick()`). Or state this class in the residual.

**M2. Three nearest variants of H2 are still missed, and the residual does not name them.** `internal/accept/integrity_skips.go:65-72`
- **Inputs:** each base form below, used in a test as shown, is accepted:
  - **through a function argument:** `func register(f func(*testing.T)) { registry2 = append(registry2, f) }` and `func init() { register(requireDocker) }`, used as `registry2[0](t)`;
  - **through a local pointer:** `func init() { p := &holder2; p.f = requireDocker }`, used as `holder2.f(t)`;
  - **through a range variable:** `func init() { for _, f := range []func(*testing.T){requireDocker} { registry4 = append(registry4, f) } }`, used as `registry4[0](t)`.
- **Cause:** `held` records only package variables, and `skipRead` follows only package-scope variables. So a parameter, a local or a range variable carrying the helper breaks the chain.
- **Fix:** either:
  - record values for local variables too: call arguments as values of the callee's parameters, a range's `X` as the value of its variables, and `p := &v` as an alias that `held` resolves to `v`; or
  - add "a helper passed to a function, a range variable, or a local pointer before it reaches a package variable" to the residual.

### Low

**L1. `TestIntegritySkipsVarLinear` catches the quadratic shape only by a small margin.** `internal/accept/integrity_skips_test.go:296-299`
- **Measured:** the mutated ratio is 11.2–11.6 against a threshold of 10, and unmutated it is about 3.6. Fixed per-run overhead dilutes the ratio, so a loaded machine or a faster scan could let the mutation pass.
- **A deterministic count that would catch it:**
  - Charge every unit of skip-layer work to `skipWork`: each `varVals` element examined in `skipUse` (or in any later per-use check), and each step of `direct`'s search.
  - Expose it as a counter, like `skipReads`.
  - Assert that the count for n = 8000 stays under a small constant times the file's bytes, or under 4 × (n = 2000's count) + slack.
- **Effect:** round 1's scan examines n² = 64 million elements at n = 8000, against tens of thousands when linear, so it fails by orders of magnitude, not by timing. The same counter would cover H1's input.

**L2. The skip bound is per run, not per package, and the residual says "a package".** `internal/accept/integrity_skips.go:42`, `:150`
- **Measured:** `skipWork` is about 0.74 × source bytes per version and platform. Four scans therefore exhaust 64 MiB at about 21.6 MiB of touched-package source per version. `maxRead` (64 MiB over both versions) allows up to 32 MiB.
- **Effect:** a change touching packages totalling between about 22 and 32 MiB per version makes the later packages unverifiable, where main accepts.
- **Fix:** either:
  - set `maxSkipWork` to at least 2 × `len(platforms)` × `maxRead`, with headroom for values read twice, so the read bound always binds first; or
  - restate the residual as run-wide.
