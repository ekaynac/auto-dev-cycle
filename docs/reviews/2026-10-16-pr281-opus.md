## Opus pre-review of #281 (2026-10-16)

Verdict: NO-GO

**Method.** I read head 2d5ba30 against main e79f7d5, together with `gh pr view 281`, Opus #277 (A02–A02d, G01, G02) and the #279 records (Opus M1, Astra M2). I ran 121 probe rows on both trees through `newFixtureWith`, `guarded` and `pyOwn`, from a temporary probe test file that I then deleted. The results leave out P14b's blanket block. Most rows use this base: an empty `feature/__init__.py`, `feature/flags.py` = `SKIP = False`, `cfg.py` = `SKIP = False`, and `tests/test_x.py` with `skipif(feature.flags.SKIP)`, plus one writer module (a conftest unless stated). The candidate changes only `cfg.py` to `SKIP = True`. The A02 rows also ran with the install gate on and Astra r3's `setup.cfg`. CPython 3.12.3 (`-I`, with a pytest stub that records the skipif condition) confirmed every fail-open row below: on the base the condition is `False`, and after the change it is `True`. I also ran main's `integrity_pyguard_test.go` on the PR's code, the PR's own suite, `go vet`, and 7 extra mutations. The scratch worktrees are removed.

**Summary.** The closure itself is sound: it handles cycles, relative imports, packages along the path, imports in `try`/`if`/`def`, and shadow-only roots. Strict additivity holds. But the write recognizer and the import recognizer read only a narrow token shape. They miss plain CPython assignment statements and constant imports that the PR text says are covered. This is the "parser differential" the background review flagged in `integrity_pyshadow.go`. Also, the link rule leaves #279 M1's own probe passing the whole guard, P14b included.

### High

**H1. The write scan takes only the first name of each target, and it does not split a one-line compound statement. Ordinary assignments onto a base module are silent.**
- **Where:** `integrity_pyshadow.go:227-253`.
  - `:246` builds a chain only from the first name token of a target, and only when the next token is `.`, `[` or `,`.
  - `:227` splits a line only at `;`, so `if True: X.y = v` has the target `if True : X . y`, whose first name is `if`.
- **Probes** (conftest = `import cfg` / `import feature.flags` / the form). PR: no own block. Main: no own block. CPython: `False -> True` for each.
  - w02 `_, feature.flags.SKIP = 0, cfg.SKIP` (tuple target)
  - w03 `[_, feature.flags.SKIP] = [0, cfg.SKIP]`
  - w04 `if True: feature.flags.SKIP = cfg.SKIP`, and the same after `try:` (w04b), `class K:` (w04c) and `while True:` (w04d)
  - w27b `(feature).flags.SKIP = cfg.SKIP`
  - w50 `[feature][0].flags.SKIP = …`
  - w51 `(m := feature.flags).SKIP = …`
  - w10 `globals()[k].flags.SKIP = …`
  - w29 `getattr(feature, 'flags').SKIP = …`
  - w11 `importlib.import_module('feature.flags').SKIP = …`
  - w12 `__import__('feature.flags').flags.SKIP = …`
  - A02 form, gate on and off: a04 `(feature).__path__.insert(0, 'lib/impl')`.
  - `del x, feature.flags.SKIP` takes the same path (only `x` is recorded).
  - The candidate side uses the same scan: k04, a changed `helper.py` with `_, feature.flags.SKIP = 0, True`, gets no own block on either tree.
- **Not covered by the stated residual.** The residual lists aliases, `vars(M)`, and `for`/`with` targets. These forms are assignments, and the PR text says "a write is an assignment".
- **What holds:** a plain, chained, annotated, augmented, starred, `;`-separated or continued target is caught, and so are a parenthesized object, a multi-line `if`/`match`, a def body, a decorator body, `global`, a class body with a local import, `import … as`, `from … import`, `__class__ =` and `M.__dict__[k] =`.
- **Fix:**
  - split a logical line after a compound header's top-level `:`, as the import scan already does at `:290`;
  - record a chain for every name token in a target that is not preceded by `.`, not only for the first one;
  - when a target's head is not a name (it starts with `(`, `[`, a call or a subscript and then has `.` or `[`), treat the file as writing every base module it imports.
- **Rows:** w02, w04, w27b, w11, a04, k04. Each must block or be unread.

**H2. Writes made by a call, and code run from a string, are not modelled.**
- **Where:** `integrity_pyshadow.go:232-244`. Only a `setattr(` token and `.__path__`/`.__spec__`/`.__loader__` attribute tokens count.
- **Probes.** Both trees: no own block. CPython: `False -> True`.
  - w05 `feature.flags.__setattr__('SKIP', cfg.SKIP)`
  - w06 `object.__setattr__(feature.flags, 'SKIP', cfg.SKIP)`
  - w07 `feature.flags.__dict__.update(SKIP=cfg.SKIP)`
  - w46 `feature.flags.__dict__.__setitem__('SKIP', …)`
  - w15 `operator.setitem(feature.flags.__dict__, 'SKIP', …)`
  - w17 `def f(x=feature.flags.__setattr__('SKIP', cfg.SKIP)): pass` (a default that runs at import)
  - w16 `exec('feature.flags.SKIP = cfg.SKIP')`
  - A02 forms, gate on and off:
    - a02 `getattr(feature, '__path__').insert(0, 'lib/impl')`
    - a03 `feature.__dict__['__path__'].insert(…)`
    - a07 `feature.__setattr__('__path__', ['lib/impl'])`
- **Main has no base-side rule for `exec`/`eval`.** Main's decision-A vocabulary (`pyBare` and `pyClass` 'f': `__dict__`, `__setattr__`, `__setitem__`, `setattr`, `vars`, `globals`, `exec`, `eval`, `compile`, `__import__`, `importlib`, `modules`) applies only to changed candidate files. k05 shows that it blocks a candidate `__setattr__` on both trees.
- **Residual:** only `vars(M)[…]` is listed. `__dict__`, `__setattr__`, `operator.setitem` and `exec` are not.
- **Fix:** in a closure module, any token from that same vocabulary (or a string passed to `exec`, `eval` or `compile`) marks every base module the file imports as written. If that is not possible, leave the base unread. Decision A accepts the false blocks.
- **Rows:** w05, w07, w16, a02.

**H3. Constant dynamic imports are followed only in the form `NAME('str'`, so a constant import in another form leaves its writer out of the closure.**
- **Where:** `integrity_pyshadow.go:282-283`. The string must be the token right after `(`, there is no `fromlist`, a relative name loses its package, and an aliased callee is not matched.
- **Probes.** Conftest = the form. `helper.py` (or `feature/_park.py`) is G01's writer. Both trees: no own block. CPython: `False -> True`.
  - i02 `importlib.import_module(name='helper')`
  - i03 `from importlib import import_module as im` / `im('helper')`
  - i04 `importlib.import_module('._park', 'feature')`
  - i05 `__import__(name='helper')`
  - i06 `importlib.import_module(('helper'))`
  - i21 `__import__('feature', fromlist=['_park'])`
  - i07 `runpy.run_module('helper')`
  - a08, gate on and off: `importlib.import_module(name='feature').__path__.insert(…)`
- **Residual:** it names only a *non-constant* `import_module` or `__import__`. All of these are constant.
- **Fix:**
  - record `fromlist` items as `X.item`;
  - resolve a relative constant against its package argument;
  - in a closure module, a call to `import_module`, `__import__`, `run_module` or `run_path`, or a name bound from them, whose arguments are not exactly one leading string leaves the base unread.
- **Rows:** i02, i04, i21.

**H4. The link rule does not close #279 M1. A base symlink's target can change with no block at all, and a symlinked judged file or a deep closure module is still read as its link text.**

  - `integrity_pyshadow.go:207-212`: `file` never marks a path in `r.links` unread.
  - `integrity_pyguard.go:129`: a change with no `.py` extension skips the Python rules.
- **Probes.** CPython: `False -> True` for each.

  - s04: base `conftest.py` → `real_conf.txt` (G01's writer). Both trees: no own block.
  - c08: conftest `import helper0`, `helper0.py` = `import helper`, and `helper.py` → `real_helper.txt` (the writer). Both trees: no own block. The one-hop form c09 is unread on the PR.

- **What holds:** a directory symlink package (s01), a symlinked `__init__.py` (s02) and a symlinked holder in a test directory (s06) are unread on the PR. A symlinked test directory (s05) is read through its real path. A candidate symlink blocks on both trees (s07, "a symlink").
