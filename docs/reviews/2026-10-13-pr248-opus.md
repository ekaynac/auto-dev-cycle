## Opus pre-review of #248

Verdict: NO-GO

One High blocks this PR. The upstream's response body is streamed to the adapter without any check, so a credential the upstream echoes reaches the sandbox. Everything else holds up under attack:
- **Egress binding holds.** Redirects are refused before the target is contacted. There is no proxy. The dial guard checks the exact `host:port`. The target URL is built only from the registry's endpoint and a fixed path, and TLS verification is the default. DNS rebinding of a direct-API hostname fails at TLS, and local endpoints must be IP literals.
- **Lease and attempt fencing holds.**
- **Duplicate-key smuggling is closed** by the re-encoding.
- **Nothing in adcd constructs the gateway.** No non-test Go file outside `internal/gateway` imports it; the only mentions are the two dispatch doc comments.

I reran M1, M3, M4 and M6, plus five mutations of my own (lease state, credential-in-body, userinfo, the Unbind delete, the zone check, the 4in6 unmap). M1, M3, M4 and M6 fail their named tests, and so do the state, credential-in-body, userinfo and Unbind mutations. The zone and unmap mutations survive; see L3. Probes were run in a scratch copy with fake values only.

### High

**H1. A credential the upstream echoes reaches the sandbox.** (`internal/gateway/gateway.go:151-156`; the package doc at `gateway.go:16` claims it is "never ... returned")
- `ServeHTTP` copies `resp.Body` to the adapter verbatim through `flushing`. The value is never scanned.
- **Failure scenario.** Probe: the upstream answers 401 with `{"error":"bad key Bearer <value>"}`. The adapter received the full fake credential (`strings.Contains(body, fakeKey) == true`).
  - Some providers and local servers echo the key on auth errors, and a hostile upstream (D43) can always do it.
  - From there the value lands in the builder's sandbox (transcript, workspace, possibly the candidate and a push). That breaks the P11 row's "never in the sandbox" and I17.
  - No test checks the response direction.
- **Fix.** Wrap the response writer in a scanner that holds back the last `len(value)-1` bytes.
  - Write a chunk only once it cannot be the start of a match. On a match, stop the stream: write nothing further and drop the connection, or replace the value with the placeholder.
  - Flush the held-back tail at EOF. This keeps streaming working (about 20 lines).
  - Add a test with an upstream that echoes `Authorization` in a 401 body and in an SSE chunk split across two writes.

### Medium

**M1. The registry does not bind a credential reference to one origin, so checking only the reference rests on a false premise.** (`gateway.go:122-131`, and the PR's "Holds keys on the credential reference" note)
- `registry.accounts` keys on `origin + "\x00" + ref`. It refuses one key in two groups, but not one ref at two origins.
- **Failure scenario.** Probe: the stub registry with the reviewer moved to `destination "other"`, `https://other.example/v1`, `credential_ref "stub"`, in its own group. `registry.New` returned `nil`.
  - The gateway then injects the `stub` account's key into requests to `other.example`.
  - `Holds(destination, ref)` ignores `destination` and reports ready for both.
  - This is operator configuration, outside the attacker's reach, which is why it is not High. But the registry should refuse it, and the PR text says it already does.
- **Fix.** Pick one:
  - in P7, refuse a `credential_ref` that appears on two origins (a follow-up in #226);
  - or have `New` build `ref → origin` from the registry and make `Holds`/`forward` refuse a mismatch.

  Either way, correct the PR's "Holds" note.

**M2. Model-selecting keys besides an exact `"model"` are forwarded.** (`internal/gateway/egress.go:106-117`)
- **Failure scenario.** Probe: `{"model":"stub-builder-1","Model":"other","models":["x"],...}` returned 200. The upstream received all three keys.
  - Go-struct upstreams (Ollama's OpenAI-compatible route, for example) match keys case-insensitively. They are safe today only by accident: the map re-encoding sorts every case variant of "model" before `"model"`, and the last key wins.
  - Upstreams with fallback arrays (`models`, `fallbacks`, `route`) select another model despite D48. `kind` is the operator's label, and the gateway does not verify it.
  - The test's "case variant" case covers the value's case, not the key's.
- **Fix.** In `pinned`, refuse any top-level key other than `"model"` that `strings.EqualFold`s to `"model"`. Also refuse a small denylist (`models`, `fallbacks`, `route`), or move to a top-level allowlist for the chat-completions shape. Add both cases to `TestAModelSwitchIsRefusedBeforeEgress`.

**M3. `EnvName` maps two distinct references to one variable.** (`internal/gateway/secrets.go:59-62`)
- `Slug` is `^[a-z0-9][a-z0-9_-]{0,62}$`, so `openai-prod` and `openai_prod` both read `ADC_CREDENTIAL_OPENAI_PROD`.
- **Failure scenario.** Two accounts registered under those refs silently share one key, and `Holds` reports both held.
  - The `.` replacement is dead code, because `.` is not in `Slug`.
- **Fix.** Make the mapping injective (for example, `-` → `_` and `_` → `__`), or refuse a ref containing `_`. Drop the `.` replacement. Add a collision test.

### Low

- **L1. A nil `Secrets` panics instead of refusing.** (`gateway.go:204-205`)
  - Probe: `Config{Secrets: nil}` with a credentialed executor gives a nil-pointer panic in `ServeHTTP`. net/http recovers it and drops the connection, so it fails closed, but by accident. A nil `Leases` or `Capture` misuse is similar.
  - **Fix.** `New` validates `Registry`, `Leases` and `Secrets` and returns an error. `forward` refuses `credential_not_held` when `Secrets == nil`.
- **L2. The "proxy-form target" test does not test proxy form.** (`gateway_test.go:241`)
  - The case uses path `/elsewhere` and is refused by the path check.
  - Probe: a real absolute-form `POST http://evil.example/chat/completions` is forwarded, harmlessly, to the registered upstream, since the target never comes from the request.
  - **Fix.** Rename the case, or add a true absolute-form case that asserts the registered origin received it and `evil.example` was never dialled.
- **L3. Two transport-check mutations survive.** (`egress.go:91-92`)
  - Removing `ip.Zone() == ""` survives, because the only zoned case (`gateway_test.go:337`) is `fe80::`, which `IsPrivate` refuses anyway.
  - Removing `Unmap()` survives, which makes the check stricter.
  - **Fix.** Add `http://[fd00::1%25eth0]/v1` (refused) and `http://[::ffff:10.0.0.1]/v1` (admitted, as the registry's `origin` unmaps).
- **L4. A late status recreates an entry after `Unbind`, so it is lost and leaks.** (`gateway.go:245-256` vs `106-120`)
  - An `observe` from an in-flight request that lands after `Unbind` recreates `observed[attempt]`. That status is lost from the exit map, and the entry is never freed.
  - **Fix.** Have `observe` drop when no binding for the attempt remains, or key `observed` by token hash.
- **L5. "Restricted" lives only on the `Captured` record.** (`capture.go:48-58`)
  - The blob goes into the shared, content-addressed store with no class.
  - Nothing serves blobs by digest today, so this is acceptable. Record in #226 that P24's purge must not delete a digest another record also references.
  - Size per capture is bounded by `maxBody` (8 MiB), and the P7D expiry matches §8 item 4.
- **L6. The body is read before the lease check.** (`gateway.go:180-184`)
  - Any bound token can make the gateway buffer up to 8 MiB per concurrent request before the lease is checked.
  - **Fix.** Check the lease first, or note the bound for P22a's listener.

### Size

527 hand-written lines, over the ~450 budget but inside the ~650 ceiling. Every piece maps to the P11 row (injection point, capture, observed statuses, launch readiness), so there is nothing material to cut beyond the dead `.` replacement. H1's scanner and M2/M3 add roughly 30 to 40 lines, still under the ceiling.

### Holds and fail-closed

`Holds` fails closed: an empty destination or ref, or a nil `Secrets`, gives `false`. An `EnvSecrets` lookup never errors and never quotes a value. Checking only the reference is sound only once M1 is fixed.

### Credential surfaces checked and clean

- `String`, `GoString`, `Format` and `MarshalJSON`;
- refusal bodies (fixed codes);
- `url.Error` text (userinfo is refused, so no URL carries a value);
- upstream response headers (only `Content-Type` is copied);
- the redirect `Location` (never followed or returned);
- the capture (taken before injection).

The worktree has been removed.
