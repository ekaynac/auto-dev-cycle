**High — H1. A damaged task-node index exposes another project’s benchmark facts.** `internal/api/tasks.go:127`, `internal/api/tasks.go:148`

- **Concrete input:** while the daemon is running, task A’s `graph_task_nodes` index contains `A/nodeB`, where nodeB belongs to task B in another project. The caller has board, attempt and model-call reads for A’s project only.
- **Trace:** `graph.TaskNodes` resolves index keys without checking the returned node’s task (`internal/graph/history.go:185`). `boardCard` notices the foreign project and produces an unplaced card (`internal/api/board.go:211`), but `taskRead` continues. It authorizes attempts and benchmark facts against **A’s** project, then follows nodeB’s attempts, leases, calls, measurements and liabilities (`internal/api/taskbench.go:68`, `:90`). Those facts reach the response without authorization for B.
- **Fix:** verify every returned node’s task and project against the authorized task before reading attempts or benchmark facts. Refuse a mismatched index; an unplaced card must not permit continued traversal of foreign records.

**High — H2. Missing timing facts become successful benchmark metrics.** `internal/graph/times.go:33`, `internal/cli/bench.go:267`

- **Concrete input:** a completed candidate whose accept or gate node’s `graph_node_times` row disappears after startup. Its node, claim and selected result remain intact.
- **Trace:** `TimesOf` ignores the row’s presence flag and returns zero times. `benchOf` emits `state: completed` with null timestamps (`internal/api/taskbench.go:65`). `benchInputs` discards that state and skips null timestamps. Because controller-only accept/gate nodes have no attempts, `bench.Record` accepts them and counts them as pending, with zero wall time and no claimed round (`internal/bench/bench.go:299`, `:373`). The command writes the file successfully.
- **Fix:** cross-check timing presence against the node’s claim and selection evidence, distinguishing legitimate reuse from missing facts. Refuse missing expected timestamps before converting to `bench.Node`.

**High — H3. A closing review bypasses an explicit damaged-record refusal.** `internal/cli/bench.go:324`
