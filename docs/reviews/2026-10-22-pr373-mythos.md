### Medium

**M1. The label pins the build context, not the image's content.** `scripts/prepare-go-image.sh:217`
- **Cause:** `context` digests `adapter/linux-ARCH/` and the dist, and `build` checks that Node starts in each image (L6). Nothing digests `/opt/adc/lib` inside the built images. The label's `adapter` is therefore what went into `COPY`, and `CheckAdapter` (and 5d-3 after it) compares only that label with the installed release.
- **Input:** a buildah that resolves a source symlink on `COPY` (the two `@adc` links become directory copies), drops an execute bit, or honours an ignore file for the context. The image holds a closure whose `AdapterDigest` differs from the label, Node still answers `v22.23.3 arm64`, and `CheckAdapter` passes on every host because label and installed release agree.
- **Exposure:** not adversarial (the image is immutable and pinned), but the promise "CheckAdapter refuses a skew" rests on COPY's fidelity, which no check in the repository shows.
- **Fix:** after the Node run, per platform: `c=$(podman create --pull=never --platform="$p" "$name" true)`, `podman cp "$c:/opt/adc/lib" "$tmp/$p"` (links and modes kept), `podman rm "$c"`, then `[[ "$("$adc" dev adapter-digest "$tmp/$p")" == "<the label's digest for $p>" ]] || die`. Keep the per-platform digests in an array in `context` so `build` can read them back. Add a `TestPrepareBuild` row where the fake podman's `cp` writes a different tree.

### Low

**L1. The pushes tag `latest`, not the dated tag the README documents.** `scripts/prepare-go-image.sh:46`
- `docker://ghcr.io/ekaynac/adc-prepared-go-mini` pushes to `latest`. `fixtures/m1/stub/go-mini/README.md:16` names tag `go1.27.1-2026-10-21`. The next rebuild overwrites `latest` and leaves the previous index untagged on GHCR, where an untagged version is what a cleanup policy deletes first, while hosts still pin it by digest.
- **Fix:** push to `docker://NAME:go1.27.1-<date>`; the index digest in `--digestfile` is the same whatever the tag.

**L2. The `.digest` files dirty the checkout.** `scripts/prepare-go-image.sh:46`
- `--digestfile go-mini.digest` writes into the checkout's cwd. Any `build` after the first push is refused with "uncommitted changes" until the file is removed. The header's order avoids it only on a clean first pass.
- **Fix:** `--digestfile `, or list `*.digest` in `.gitignore`.

**L3. `pin`'s refusal inside `$(…)` is reported twice, under the wrong text.** `scripts/prepare-go-image.sh:142`
- With two pin lines for a platform, `pin` dies inside the command substitution, the right side of `[[ … == … ]]` is empty, and the script then dies with "is not the Node … pins for". It fails closed; the message is misleading.
- **Fix:** `want="$(pin "$p" 5)" || exit 1` before the compare, as line 218 already does by `set -e`.
