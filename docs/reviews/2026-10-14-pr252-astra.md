4. **High — I18’s closure is incomplete when an intermediate ref is absent from the immediate context.**

Add a summary-only case with a valid size and require `ErrAcceptanceInput`. 5. **Medium — A refused gitlink can become a controller error during integrity inspection.**

Missing-object or wrong-type failure returns a controller error despite the established candidate refusal.

   **Fix:** exclude gitlinks and other unsuitable modes from blob inspection, or return the structural refusal before running the integrity guard. Test this through controller-generated `Diff`, requiring an unsafe-output verdict and no controller error.

6. **Medium — The diff size limit is enforced after buffering, and its refusal is untyped.**  
   `internal/accept/build.go:65`; `internal/accept/accept.go:240`

   `cmd.Output()` accumulates the entire patch before checking `maxPatch`. The documented output-tree bound does not bound deletion hunks from the base: an empty copied output can delete a very large tracked text file. This can consume substantial controller memory. If buffering succeeds, the oversized candidate returns a plain error rather than `ErrUnsafeTree`, retaining the hold/page misclassification Round 2 intended to close.

   **Fix:** enforce the byte limit while collecting stdout, terminate and reap git on overflow, and return a typed candidate refusal. Cover deletion-heavy diffs, not only large additions.

7. **Medium — Existing exit and collection hooks can be weakened without a warning.**

   **Fix:** warn when relevant hook bodies or exit expressions change, rather than only when marker totals increase. Likewise, assertion-expression weakening such as replacing a condition with `True` merits heuristic scrutiny; unchanged marker counts prove nothing about preserved coverage.
