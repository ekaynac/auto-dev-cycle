**H1. Retiring "reflect on a mention" is a regression against main, and it passes end to end.**
- **The cause:**

  - The types layer's `factReflect` (`integrity_types.go:811`) needs the argument's static type to hold a testing type.
  - `factMakes` (`:723-724`) lists the makers, `Set*` and `Call`, but not the methods that hand out raw pointers.
- **Input P2c:**
  - A test does `var x any = t; defer unfail(reflect.ValueOf(x))`.
  - `unfail` walks `common` and `parent` and clears `failed` through `FieldByName("failed").Addr().UnsafePointer()`. This needs no `unsafe` import.
  - Main: "unverifiable: reflection on a testing value". PR: accepted, with two warnings.
- **Input P2d, accepted on both:** the same forgery behind one function boundary (`func unfail(x any) { … reflect.ValueOf(x) … }`). It reopens entry 82 (b)'s class.
- **Also accepted by the PR and blocked by main:** `UnsafeAddr()` written through `/proc/self/mem`.
- **Fix:**
  - Add `UnsafePointer`, `UnsafeAddr`, `Pointer` (and possibly `Addr`) to `valueMakes`.
  - Add a types fact for a conversion whose operand is `unsafe.Pointer`, with or without an `unsafe` import.
  - At minimum, restore the 3-line text rule.
  - Rows: P2c, P2d and the `UnsafeAddr` variant.

### Medium

**M1. 82 (d) is closed only for a literal read into a local. It is not a regression.**
- **Input:** a literal passed to an own function, `fill(holder{util.S})` from `init`. It passes end to end on both trees. Also accepted on both:
  - a map key `map[chan any]bool{util.Ch: true}`, then a range over it;
  - `for _, s := range [][]any{util.S}`;
  - `range []*any{…}`.
- **Fix:** add one helper that returns the other-package roots inside composite literals: keys and values, recursively, also through `&`. Use it in `call()` for own-function arguments and in `read()` for map keys, and read-check `RangeStmt.X`.

**M2. A cgo preamble in an untested helper that the tests import forges end to end, with one warning. On main too.**
- **The input:** `__attribute__((constructor))` writes framed PASS lines, then `_exit(0)`.
- **The cause:** "an import of C" blocks only in tested packages, and `typer.parse` skips cgo files.
- **Fix:** treat a new or changed `import "C"` file, and new `.c`, `.cc`, `.cpp`, `.m` and `.h` files, like `.s`. As an alternative, confirm that the gate runs with `CGO_ENABLED=0`, and record that.

### Low

- **L1. 82 (c) does not cover interface method calls.** `st.Set(os.Args)` is not counted as "os.Args assigned". It is harmless after flag parsing, and it blocks from `init`. Fix: treat an interface `MethodVal` like a function value.
- **L2. go.work is not modelled.**
  - In workspace mode, Go ignores the module's `vendor/`. It also ignores it when `modules.txt` carries `## workspace`.
  - `use` redirects imports.
  - A candidate can add a `go.work` file, and the guard never looks at it.
  - Fix: block a change to `go.work` or `go.work.sum`, or treat a `go.work` file as unverifiable for vendor mode.
