- **Fix (follow-up, not required for #279):** keep the mode in `r.list` and treat a base `.py` symlink or gitlink as unread in `pyBase.file`. Or block any change to a path that a base `.py` symlink resolves to. Name an owner, for example P14c-2a-widen.

### Low

**L1: a non-`.py` competing form skips the star-source check.** `integrity_pyguard.go:122` (the `.py` `continue`) runs before `:139` (the `pb.starSrcs` check).
- **Probe:** on the inert-star base, the candidate adds `feature/redirect.pyw`.
- **PR head:** no block. **Main:** no block.
- **On Linux:** `.pyw` is not a loader suffix (`SOURCE_SUFFIXES == ['.py']`), and `.so`, `.pyc`, `.pyd` and `.pyo` are blocked anyway by `pyLoaded`. I confirmed that adding `redirect.abi3.so`, `redirect/__init__.cpython-312-x86_64-linux-gnu.so` and `__pycache__/redirect.cpython-312.pyc` blocks, and so does deleting `redirect/__init__.pyc`.
- **On Windows:** `.pyw` is a source suffix. The base side already counts `x.pyw` as a competing form (`pyStarForm` matches `x.*`), so the two sides disagree.
- **Fix:** move the `pb.starSrcs` check above the `.py` `continue`, so that any `x.*`, `x/__init__.*` or `__pycache__/x.*` change blocks whatever its extension. This also makes the rule match its own doc comment.

**L2: the stated residual (the candidate `__init__.py`'s non-star plainness) is real, but the star does not widen it.** `integrity_pyreach.go:191-206` (`starCandidate` judges only `badStar` and `starSrc`).
- **Probe:** on a base where `feature/__init__.py` is empty and `redirect.py` is plain, the candidate writes `from .redirect import *\nY = len('a')\n`.
- **PR head:** no block of the guard's own.
- **Control:** the same change without the star (`Y = len('a')\n`) passes on both trees.
- **Effect:** the star adds no power that the non-plain statement lacks alone. The known forms are caught by other rules: a mention of `__path__`, `__spec__` or `__loader__` blocks in every file, and `setattr`, `importlib` or `exec` at module level blocks by class. What remains is P14c-2a-plain's residual (an imported module changing `__path__` at run time), owned by P14c-2a-widen.
- **Fix (optional, cheap):** in `starCandidate`, also block when `len(f.starSrc) > 0 && !f.plain`. This would only add blocks.

**L3: false blocks and cost.**
- **(a) Reading every base `__init__.py`:** `load()` now reads every base `__init__.py` (`integrity_pyshadow.go:157-168`), not only those on a condition's path. In a large base this spends the read budget, and files read later become "over the guard's read bound". That fails closed, but it blocks more. Consider reading only `__init__.py` files that contain the bytes `import` and `*`, or charging `r.work`.
- **(b) A root `__init__.py` star:** with `__init__.py: from .x import *`, `d` is `"."`, so `src` becomes `./x.py`, which never exists. Probe: it blocks as "not one plain module file" on the PR head and does not block on main. Fail-closed, so it is acceptable, but it is worth a line in the residual list.
- **(c) A star followed by `;`:** `from .redirect import *;` blocks, although CPython accepts it. This follows from the five-token rule and is acceptable under decision A.
