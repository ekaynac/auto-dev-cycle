### Findings

**H1. The stalled case no longer checks that the stream ends promptly after the stall. Required.**
- **Where:** `internal/fixtures/stream.go:274-279`.
- **What changed:** before the PR, a stalled stream that stayed open more than 2 s after the case started was red. Now it can stay open up to 10 s. The stall branch has no timing check at all; spec 08 says "a client that stalls longer is cut off" (`docs/design/m0/08-controller-api-and-cli.md:58-60`).
- **Scratch demonstration:** I added a 3 s sleep before the return after a failed send (`internal/api/events.go:307-308`).
  - base: red ("outlived the client by 3.17s");
  - #288 head: green (5.04 s);
  - the fix below: red ("the stream ended 3.09s after the stall").
- **Fix:** time the stall from an event, not from the case start.
  - In `slowClient.Write`, record `stalledAt` when the stalled write begins (`:330-334`). This is after `before()`, so the revocation commit is not counted.
  - After `serve`, take `ended := time.Now()`.
  - In the stall branch, check `!cl.stalledAt.IsZero() && ended.Sub(cl.stalledAt) <= handler.Poll+frameSlack+lag`.
  - The measured window holds only a sleep to an absolute deadline and a return, with no store work, so the cause of entry 86 does not come back.

**H2. The `cut` check cannot see a write that has no deadline. Required, because the PR now rests the whole claim on `cut`.**
- **Where:** `internal/fixtures/stream.go:330-335`.
- **Cause:** the stalled write sleeps `time.Until(d)`. For a zero deadline that duration is negative, so the write fails immediately. A real stalled client with no deadline would hold the stream forever.
- **Scratch demonstration:** I made `bounded` set no deadline (`internal/api/events.go:240` → `time.Time{}`).
  - #288 head: green (2.18 s);
  - `go test ./internal/api -run 'Stall|Stream'`: also green;
  - with the fix below: red ("still open after 10s"; "ended 9.78s after the stall").
- **Fix:** give the client the request's end, so a write with no deadline stalls until the watchdog cuts it:
  ```go
  // slowClient
  done <-chan struct{} // a write with no deadline stalls until the request ends
  // Write, stall branch, before the sleep
  if d.IsZero() { <-c.done }
  // serve, before h.ServeHTTP
  c.done = ctx.Done()
  ```
