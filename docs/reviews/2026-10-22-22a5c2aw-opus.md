## Opus review of 22a-5c-2a-w (2026-10-22)

Verdict: GO with changes. H1 must be fixed before the PR opens. H2 and the Lows can follow.

With a normal `--adapter` path, the jail does what it promises. Probed, the adapter cannot reach:
- the host's `/etc`, `$HOME` or `/sys`;
- any other process: the fresh `/proc` shows 2 processes;
- a host abstract unix socket, or TCP on the host's loopback.

It does reach a bound gateway socket, so that socket is the only way out. But one config check is missing, and with an ordinary `--adapter` path that one gap reopens most of what M1 closed (H1). `TestTheJail` also misses a mutant that shares the whole host (H2).

**Checks run**, in a `/tmp` copy without `.git` and with `TMPDIR` unset (deleted afterwards):
- **One test at a time:** `TestTheJail`, `TestTheHostAdapterIsJailed` and `TestLoadConfig` pass under `-race`.
- **Whole packages:** `adapterhost/session`, `adapterhost`, `harness`, `fixtures`, `dispatch` and `daemon` pass under `-race`. In `daemon` I skipped `TestSandboxConfig`, which fails on this host whatever the change, as in earlier records: `/run/podman/podman.sock` is unreadable here.
- **Probes:** a stub run under bubblewrap 0.9.0, once with adcd's jail and once with an adapter directory of `/`.
- **Mutant:** one jail mutant, which survived (H2).

### High

**H1. Nothing limits the adapter's own directory, so an ordinary `--adapter` path brings the host back into the jail.** `internal/daemon/adapter.go:75`, `internal/daemon/config.go:201`
- **Cause:** `filepath.Dir(cfg.Adapter)` is bound read-only with no check. The read-only binds also come after `--proc /proc` and `--tmpfs /tmp` (`internal/adapterhost/session/process.go:138-141`), so a bind of `/` covers both.
- **Input (probed):** `--adapter /adapter` passes `absClean`, and the jail then binds `/` to `/`. Inside, the probe saw:
  - the host's `/proc` with 674 processes, which includes adcd's `/proc/<pid>/environ`, where the gateway's credentials come from (`EnvSecrets`);
  - `/etc/passwd`, `$HOME` and `/sys`;
  - every file under the state directory: the event store, the blobs, the secrets file and the clones' `.git`.
- **A more likely input:** `--adapter /home/adc/run-http-chat` with the state directory under `/home/adc`. That binds the whole home, the state directory included. The promise "nothing from the state directory" is then false.
- **Fix:**
  - In `Validate`, refuse an adapter whose directory is `/`, or overlaps the state directory, the sandbox root, the shared run directory, `/proc`, `/dev` or `/tmp`, in either direction. Compare the resolved paths (`EvalSymlinks`), the way `sandbox.overlaps` does.
  - In `contain`, put `--dev`, `--proc` and `--tmpfs` after the binds, so no bind can cover them.
  - Add `TestLoadConfig` rows for `/adapter`, `<state>/x` and an adapter in the state directory's parent.

**H2. `TestTheJail` misses a jail that shares the whole host.** `internal/adapterhost/session/process_test.go:544`
- **Cause:** the "state directory" is a `t.TempDir()` under `/tmp`, and the jail mounts a fresh tmpfs on `/tmp`. So the state files are hidden whatever else the jail binds.
- **Mutant (run):** in `contain`, replace `--dev /dev` with `--dev-bind / /`. That shares the host's whole filesystem, keeping only `--unshare-net` and the fresh `/tmp`. `TestTheJail` still passes.
- `TestTheHostAdapterIsJailed` only compares slices, so the promise "nothing of the host" rests on this one row.
- **Fix:**
  - Put the planted state directory outside `/tmp`, for example a test directory under the package's working directory, or `testguard`'s state directory if it is not under `/tmp`.
  - Also assert that `/etc/passwd`, `$HOME` and `/sys` are absent, and that `/proc` holds at most the probe's own processes.
  - Add the `--dev-bind / /` mutant to `muts-5c2aw.py`.

### Low

**L1. No row shows an adapter reaching its gateway socket through the jail.**
- `TestTheJail` binds no socket. My probe showed that a unix socket bound as a file is reachable. A regression there would fail closed, but every build would then fail.
- **Fix:** in `TestTheJail`, bind a listening socket file and dial it from inside. Better, run `hostAdapter{…}.Start(run)`'s `Config` through `session.Open` on the stub, so the literal two-variable environment is exercised too.

**L2. The jail shares more of the host than it needs.** `internal/adapterhost/session/process.go:138`
- **Missing:**
  - `--unshare-ipc`: the host's SysV IPC is shared.
  - `--new-session`: when adcd runs in a terminal, `/dev/tty` allows TIOCSTI on a kernel that still permits it.
  - `--unshare-uts` and `--unshare-cgroup-try`.
  - A size on `/tmp`: it is unbounded, and the host adapter is outside the sandbox's cgroup limits.
- **Fix:** `--unshare-all` (which includes the network), plus `--new-session`. Bound `/tmp` with `--size` where bubblewrap supports it (0.10 and later; this host has 0.9.0); otherwise document it as a residual.

**L3. A symlinked `--adapter` binds the link's directory, not the target's.**
- **Input:** `/usr/local/bin/adc-http-chat` is a link to `/opt/adc/lib/run`. Only `/usr/local/bin` is bound, so the exec fails.
- This fails closed, but nothing explains it.
- **Fix:** resolve the path at load and bind the resolved directory (which H1's check also needs), or refuse a symlink with a clear message.

**L4. Running http-chat needs a wrapper at the root of `lib/adc`, which binds all of `lib/adc`.**
- Node, `node_modules` and `gen/ts` all sit in `lib/adc`, so the adapter's directory must be `lib/adc` itself.
- That also exposes the shipped `fixtures/m1/cases` and `scripts/lib`. These are public test data, not acceptance blobs (those stay in the store).
- **Fix:** say so in the PR body under "Stated". Or let `--adapter` take the run command and bind exactly `sandbox.AdapterClosure`, as #373 defines it.

### The four questions
1. **Can the jailed adapter reach anything it must not?** Not with an adapter directory that stays apart from the state directory (fix H1 to enforce that):
   - The event store, the blob store, the secrets and the clones' `.git` are all under the state directory, which is not in the namespace.
   - Other attempts' workspaces are not bound: only this attempt's workspace, exchange and socket are.
   - `/proc` is fresh, in a PID namespace of its own.
   - The environment is the literal `PATH` plus `ADC_GATEWAY_SOCKET`. bubblewrap gets no other variables, and Go opens fds close-on-exec.
   - **Symlinks in the binds:** `/lib`, `/lib64`, `/bin` and `/sbin` are merged-`/usr` links. bubblewrap binds their targets inside `/usr`, so none of them leads out (probe: `/lib/ld-linux-aarch64.so.1` resolves, `/etc` is absent).
2. **Is the gateway socket the only egress?** Yes. `--unshare-net` leaves only a loopback that is down, and also cuts host abstract sockets (probed). The only path-based socket bound is the attempt's own. The socket exists before the spawn (`run.go:220` comes before `:234`), and the exchange is made before `session.Open`.
3. **Any regression for the harness and fixtures?** None. A nil `Jail` gives exactly the old arguments. `harness`, `fixtures`, `adapterhost` and `dispatch` pass. With no `--adapter` or no sandbox, `runnerOf` builds no runner, and the egress is inert.
4. **Do the rows prove it?** Partly:
   - `TestTheJail` has an unjailed control, which shows the probe can reach all three targets.
   - But its read control for the state directory is void, because `/tmp` hides it (H2).
   - The daemon row pins the jail's arguments, not what the adapter can actually reach.
   - `TestLoadConfig` covers relative and unclean paths only, not H1's paths.
