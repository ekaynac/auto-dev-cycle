### BLOCKING

**B1. A cgo test file whose import is a raw string is expected, but go never runs it.**
- **Input:** `import `` `C` `` in `p/h_test.go`.
- **What go does:** go/build unquotes import paths, so go treats the file as cgo. It fails: `use of cgo in test …/h_test.go not supported`.
- **Why the gate misses it:** `gosel.Cgo` compares the quoted literal (`is.Path.Value == "\"C\""`).
- **What the gate records:** the test is expected, the result is Missing, and the candidate gets `found/gate_test_failed`. This is N1(a) again, by a different spelling.
- **Fix:** `strconv.Unquote(is.Path.Value) == "C"` in `gosel.Cgo`, with a gosel row and a gate row.

**B2. `malformed` refuses `ExampleXxx` + a lower-case letter, but vet refuses it only when the identifier is unknown.** (`internal/gate/acceptance.go:173-174`)
- **Input:** `func Examplefoo() {}` beside `TestHidden`, where `foo` is declared in the acceptance file itself or in the base package.
- **What go does:** vet's `tests` analyzer finds `foo`, and go runs `TestHidden`. `Examplefoo` is not an example, only a function.
- **What the gate does:** it refuses the acceptance (`errSignature`).
- **Fix:** drop `Example` from `malformed`. "An example naming an unknown identifier" is already in the stated general class, and the `Test`/`Benchmark`/`Fuzz` forms are unaffected.

**B3. `importNames` guesses an import's name from its path, and refuses on the guess.** (`internal/gate/acceptance.go:313-325`)
- **Where the guess is wrong:** the guessed name differs from the package's real name, so the gate refuses on a collision the compiler never sees.
- **Inputs, each probed:**
  - `import "m/lib/foo"` where the package is `bar`, beside a base `func foo()`;
  - `import "m/api/core/v1"` where the package is `v1` (the Kubernetes API layout), beside a base `var core`. The vN rule guesses `core`.
- **What go does:** both compile and run `TestHidden`.
- **What the gate does:** it refuses both (`errRedeclared`).
- **The plan's stated residual** covers only the other direction, a collision the gate does not see.
- **Fix:** refuse only on a name the file block certainly holds:
  - an explicit import name;
  - a path the gate knows the name of (the standard library, whose names follow the last-element rule, `math/rand/v2` included).

  Treat every other import as unseen, as the residual already states.
