## Opus pre-review of #236

### High

**H1. A `local_endpoint` is never checked to be local, so a remote paid API can claim zero cost and the `own` trust class.** This widens Q8 and I10. File: `internal/registry/registry.go:158-180`, `check`.
- **What my probe got through:** a `local_endpoint` with `endpoint: https://api.openai.com/v1`, a `credential_ref`, `trust_class: own` and `cost_basis: local`. `New` admitted it.
- **Effect:**
  - P17 prices that route at zero, so the USD rail misses real spend. Q8 allows "local" to be zero cost only because the route really is local.
  - `Admits` lets it through a project with `floor: own`, so data leaves the host against the project's policy.
- **Why it counts:** this is the "widening route" in the F column, and I10's admission row says unsupported policies must be "refused, never approximated".
- **Fix:** for `local_endpoint`, require:
  - `credential_ref == nil`;
  - an endpoint host that is an IP literal, either loopback or (if LAN Ollama is wanted) private / `IsPrivate()`;
  - `trust_class` `own` only when that holds.

  Add `TestLocalEndpoint` cases "remote https as local" and "local with a credential", each refused.

### Medium

**M1. Q8 membership is not tied to the account or endpoint.** File: `registry.go:185-207`, `checkGroup`.
- Q8 says "executors on one account or endpoint share its group". Membership is only checked from each executor to the group it names.
- My probe put the stub builder and reviewer on the same destination and `credential_ref`, but in two separate `account_quota` groups. `New` admitted it, so one real quota is counted twice.
- **Fix:** in `New`, map `(destination.id, credential_ref)` to a group id and refuse (RuleGroup) when executors on the same account name different groups. The converse also holds: a group should not mix destinations. Add a test case.

**M2. A builder and a reviewer can share a family through aliasing.** File: `registry.go:136-154`, `distinct`.
- Family is an operator label. The schema `Name` pattern (`^[a-z0-9][a-z0-9._-]*$`) makes the comparison case- and whitespace-safe.
- But my probe gave the reviewer the builder's own `model` on the same destination, with a different family label. `New` admitted it.
- **Fix:** refuse a reviewer whose `(destination.id, model)` equals a builder's (RuleSameFamily). This is cheap and catches the obvious alias. Spellings like `gpt-4` vs `gpt.4` stay a labelling matter, which the operator owns.

### Low

These go into the backlog issue.

- **L1. `Admits` ignores `dp.Routing`** (`registry.go:249-265`). It is safe only because `New` admits `verified` alone. Fix: check `Routing` against `Verification` explicitly, so that admitting `reported` or `attested` in M2 cannot silently widen `Admits`.
- **L2. The floor lookup fails open** (`registry.go:255`). `floors[...]` returns 0 (`own`, the most trusted) for an unknown string. Fix: use the comma-ok form and refuse a missing key.
- **L3. Group members are only checked for executors that are registered** (`registry.go:187`). A group can list an `exe_` the registry does not hold. Fix: refuse any member not in `doc.Executors`.
- **L4. `endpointOK` limits** (`registry.go:212-222`).
  - It accepts a trailing space (`"http://127.0.0.1:1/v1 "`) and a backslash in the path.
  - A secret embedded in the path (`/sk-…/v1`) cannot be detected.
  - Redirects are outside P7's reach.
  - IPv6 handling is fine: `[::1]`, `[0:…:1]`, `[::ffff:127.0.0.1]` and `[::1%lo]` are accepted as loopback; `localhost` and `127.1` are refused.
  - Fix:
    - refuse whitespace and `\` in the endpoint;
    - P11/P13 must not follow redirects (a note on those items);
    - note in the schema description that the path must not carry a credential.
- **L5. `Load` opens with `O_NOFOLLOW` but does not require a regular file** (`registry.go:93`), so a FIFO blocks startup. The groups loader (`config.go:219`) does the same; fix both with an `fstat` `IsRegular` check.
- **L6. The fault evidence is hand mutations, not reproducible in CI.** It is acceptable under D46: the committed tests discriminate, and `TestUnknownFamilyIsNeverIndependent` goes through `graph.Roster`. Record the named-mutation follow-up against P24.

### Answers to the questions asked

1. **Q8.**
   - Correct: `http-chat` only; `direct_api` or `local_endpoint`; `verified` only; tokens with a known or estimated limit vs slots with a known limit; `on_settle`; membership in both directions for each executor; one group per executor; brokers and governed upstreams refused; `attested` refused; userinfo, query and fragment refused; plain http only to a loopback IP literal. `local` and `free` carry no price, and `local` is required on a local endpoint.
   - Gaps: H1 (local not checked to be local) and M1 (one account split over several groups).
2. **Families.**
   - An unknown family cannot be claimed independent: it is refused at start, and `Family` returns `unknown` for an unregistered executor, which `graph.Roster` refuses.
   - That default matches the `graph.Families` contract (`roster.go:40`). It is correct.
   - The comparison is case- and whitespace-safe through the schema pattern, and `New` re-validates against the schema.
   - The one aliasing hole is M2.
3. **Enums.** The refusal of `broker`, `governed_upstream`, `reported` and `attested` is unconditional: there is no flag or mutation hook in `check`.
4. **`Admits`.** Refusing an empty `allowed_destinations` is right. The profile schema says empty means "derived from usage profile", and M1 has none, so failing closed is correct. `py-mini.json` must set `["stub"]` (the PR notes this).
5. **Config refusals.** The texts are fixed `Rule` constants plus an index. Nothing is echoed from the file, and the path is not echoed (tested). `Config.Validate` runs at load (`config.go:166`) and again in `Start` (`daemon.go:61`, `daemon.go:187`).
6. **Fault evidence.** It discriminates for "an unknown family claimed independent". For "a widening route" it covers every enumerated kind, but has no case for H1's remote-labelled-as-local route.
7. **Deviations.** All three are acceptable:
   - the `config/executor-registry` name: record in the reconcile that M2 folds it into 07's `source-registry`;
   - plain http only to a loopback IP: a sound narrowing;
   - the I7/I10 rows not updated: acceptable if the reconcile marks P7's part done, with P8b/P16 remaining.
