1. **High — `malformed` rejects valid helpers beside a runnable test.** `internal/gate/acceptance.go:182`

   Attach `p/hidden_test.go` to a green base:
   ```go
   package p

   import "testing"

   func TestHidden(t *testing.T) {}
   func Testfoo(t *testing.T) int { return 1 }
   ```

   `malformed` sees the lowercase suffix and pointer parameter and returns true. However, vet’s `checkTest` excludes functions with results before checking their names. Go therefore runs `TestHidden`. The near variant `func Testfoo(a, b *testing.T) {}` also works: vet excludes multiple parameter names, while this predicate does not. The corresponding `Benchmarkfoo` and `Fuzzfoo` forms have the same discrepancy. [Go tests analyzer](https://raw.githubusercontent.com/golang/tools/master/go/analysis/passes/tests/tests.go)

   **Fix:** reproduce the analyzer’s complete eligibility predicate before rejecting the lowercase suffix: no results, exactly one parameter field, at most one parameter name, and the matching pointer type. Cover both helpers beside a real test.
