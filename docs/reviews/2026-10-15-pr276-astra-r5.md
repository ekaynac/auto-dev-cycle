3. **High — The replacement std check silently suppresses external edges for namespace-only directories.**  
   `internal/accept/integrity_out.go:119`; `internal/accept/integrity_out.go:474`

   Concrete input: an unchanged dotted root module has:
   ```go
   require archive v1.0.0
   replace archive => example.org/archive v1.0.0
   ```
   Supply the replacement and checksums in the offline cache; it exports `func F()`. Add:
   ```go
   package p
   import dep "archive"
   func f() { dep.F() }
   ```

   Go can resolve this versioned replacement: `$GOROOT/src/archive` is a namespace directory, without a package directly inside it. Go’s standard-package check requires a `.go` entry, whereas this layer requires only `IsDir()`. Thus `std("archive")` returns true and suppresses the promised new external-edge warning. This is a static trace based on [Go’s package-resolution code](https://go.dev/src/cmd/go/internal/modload/import.go#L304) and [standard-package predicate](https://go.dev/src/internal/goroot/gc.go#L19).

   **Fix:** require positive package evidence using the loader’s effective GOROOT, including the source-file check. An uncertain root or classification must warn. `build.Default.GOROOT` is not necessarily the root used by `LocalLister`: its supplied environment may override GOROOT, and the existing version check establishes release equality, not root identity.
