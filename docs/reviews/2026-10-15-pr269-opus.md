### High

**H1. The "declared twice" relaxation lets a helper split by platform hide a lost assertion.** This is a regression, and it passes end to end.

- **Where:** the relaxation is at `integrity_go.go:489-497`. It exposes `s.asserting[s.callee(call)]` (`:333-335`, `:295-305`).
- **The cause:** the P14b text layer type-checks all files of a package in one pass, without platforms. A name declared again resolves to its first declaration. On main, "declared twice" blocked every pair of files split by platform name, which kept this resolution sound.
- **Input:**
  - Base: `helper_test.go` holds `func check(t *testing.T, got, want int) { if got != want { t.Errorf(...) } }`, and `TestAdd` calls `check(t, Add(1, 2), 3)`.
  - Candidate:
    - deletes `helper_test.go`;
    - adds `a_amd64_test.go` with the asserting helper;
    - adds `b_arm64_test.go` with `func check(t *testing.T, got, want int) {}`;
    - makes `Add` return `a - b`.
- **Result:** the PR accepts the candidate, and the reverse file names are also accepted. Main blocks it. End to end, TestAdd passes.
- **Second input, same cause:** `a_arm64.go: const mark = 0` and `b_amd64.go: const mark = 22`, then `string(rune(mark))` in a test. The PR gives only a warning, and main blocks it. The 0x16 rule reads the first file's value. This disproves the stated reason for not comparing const values.
- **Fix:** run the text analysis once per gate platform, on that platform's files. As an alternative, exempt a pair only when the source of the two declarations is identical.

**H2. `fillable` stops at embedded unexported fields, but `encoding/json` and `encoding/xml` promote through them.** This is a regression from removing `carries`, and it passes end to end.

- **Where:** `integrity_types.go:752`.
- **Input:**
  - Base: `type env struct{ T *testing.T }` and `type suite struct{ env }`.
  - Candidate: `var s suite; _ = json.Unmarshal([]byte(`{"T":{}}`), &s); t = s.T; …`.
- **Result:** the PR accepts the candidate, and main blocks it. End to end, TestAdd passes.
- **Fix:** `(f.Exported() || f.Embedded()) && slot(f.Type(), seen)`.

**H3. `mentions` recurses without a bound: a generic alias cycle is a fatal stack overflow.** This is already on main.

- **Where:** `integrity_go.go:362-370`, with `alias` at `:320-327`.
- **Input:** `type A[P any] = B[P]` and `type B[P any] = A[P]`, or only `type A[P any] = A[P]`.
- **Result:** `fatal error: stack overflow` on both the PR head and main.
- **Fix:** add a visited set or a depth bound, or make `alias` return nil when the chain does not settle, so the caller blocks.

### Medium

**M1. A race/!race helper pair hides a lost assertion.** This is already on main.

- **Where:** `integrity_go.go:333-335` and `integrity_types.go:518-522`.
- **Input:** as H1, but split by `//go:build race` and `//go:build !race`.
- **Result:** accepted on both the PR and main. The const twin (0 vs 22) gets only a warning.
- **Fix:** a name declared in more than one file counts as asserting only when every declaration asserts. Evaluate the constant rules for each declaration.
