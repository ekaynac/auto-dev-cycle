4. **High — Full multi-name var bindings recreate r3 #6’s multiplicative work.**  
   `internal/accept/integrity_out2.go:67`; `internal/accept/integrity_out.go:306`

   Add a file importing `flag` with one var spec containing 100,000 blank names and 100,000 corresponding function literals:
   ```go

       func() { _ = flag.Parse },
       func() { _ = flag.Parse },

   ```
   The expanded source fits below the 4 MiB file limit.

   Each individual name is bounded, but their joined binding is approximately 300 KB. Every text reference then concatenates that entire binding into its map key: approximately **30 GB of key construction and hashing** for this one spec.

   The text pass charges `Parse` and AST visits, not those repeated binding bytes. The later typed-pass charge cannot prevent work already performed. Main’s `"package level"` key has constant length.

   **Fix:** compute a bounded identity for the complete name sequence once, charging its original bytes. Preserve every name and blank in the digest, and use the bounded identity in reference keys.

5. **Medium — Dropped-check accounting does not bound concurrent retained checks, and they retain main’s state.**  
   `internal/accept/integrity_out2.go:214`; `internal/accept/integrity_out2.go:250`; `internal/accept/integrity_out2.go:266`

   Concrete execution: start N concurrent guard runs whose layer checks remain active until their deadlines. All can observe `outRunning == 0`, because admission reserves nothing; the counter increases only after a check is dropped. All N workers can therefore survive their callers.

   Each worker also retains `im.ty`, which retains the original `run` and tree. The export lookup closure captures `r` as well. Thus the retained memory includes main’s blobs, typers, and package graphs—not merely the layer’s files and `Info`, as documented.

   **Fix:** reserve a bounded global worker slot atomically before starting a check and release it only when that worker actually exits. Pass a narrow importer snapshot and independent budget state instead of retaining the entire run. A deadline bounds caller waiting; it does not bound a surviving worker’s CPU cost.
