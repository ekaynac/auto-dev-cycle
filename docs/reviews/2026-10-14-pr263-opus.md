### Critical

**C1. A hook plugin is built and registered with no hook token and no listed reference. Every failing test reads as passed, and the guard raises no block and no warning.** (`integrity_pyguard.go:180-183` isHook; `:36` pyBare; `:47-55` pyClass)

The hook check reads only literal tokens. A computed name defeats it: `"PYTEST_X".lower()`, or `"pytest" "_x"` (each string token on its own holds no `pytest_`). `type(name, (), {computed: f})` then builds a plugin with no namespace token. To reach the plugin manager, `getattr` is enough (it is not listed; only `setattr`/`delattr` are). `inspect.stack()` with `inspect.getargvalues(fi.frame).locals` also works: only `_getframe`, `currentframe`, `f_locals` and `f_back` are listed.

- **Input A: one changed test module, nothing else.** `tests/test_money.py`:
  ```python
  import inspect
  from pytest import TestReport
  from money import add

  def _mk(item, call):
      return TestReport(item.nodeid, item.location, {}, "passed", None, call.when)

  _P = type("_P", (), {"PYTEST_RUNTEST_MAKEREPORT".lower(): staticmethod(_mk)})

  for _fi in inspect.stack():
      _pm = inspect.getargvalues(_fi.frame).locals.get("self")
      if type(_pm).__name__ == "PytestPluginManager":
          _pm.register(_P)
          break

  def test_add():
      assert add(1, 2) == 3

  def test_zero():
      assert add(0, 1) == 1
  ```
  - With `add` returning `a - b`, both tests fail. pytest prints `2 passed`, and the junit file has `failures="0"`.
  - 2a's own blocks: none. Warnings: none.
- **Input B: an allowlisted conftest.**
  - `tests/helpers.py`:
    ```python
    from pytest import TestReport

    def _mk(item, call):
        return TestReport(item.nodeid, item.location, {}, "passed", None, call.when)

    Plugin = type("Plugin", (), {"pytest" "_runtest_makereport": staticmethod(_mk)})
    ```
  - `tests/conftest.py`:
    ```python
    import pytest
    from helpers import Plugin

    @pytest.fixture(autouse=True, scope="session")
    def _setup(request):
        getattr(request.config, "plugin" "manager").register(Plugin)
    ```
  - Result end to end: `2 passed`, `failures="0"`. 2a raises nothing.
- This closes neither entry 84's "hook detection" flag nor its "forgery in fixtures" flag. This is not the stated residual: no attribute is written into a pytest object, and the forging code sits in a test module or conftest, not in code the tests call.
- **Fix:**
  - In test modules, conftests and at import, add these to the blocking set:
    - `getattr`, `operator.attrgetter`/`methodcaller`;
    - `inspect` frame access: `stack`, `getouterframes`, `getinnerframes`, `trace`, `getargvalues`, `currentframe`, `getframeinfo`;
    - `sys._current_frames`, `traceback.walk_stack`/`extract_stack`;
    - the pluggy `register` method;
    - a 3-argument `type(...)`.
  - Normalise string tokens before `isHook` and `pyKind`: fold case, join adjacent literals and `+` of literals. Read a string that spells an identifier in `pyClass` (for example `"pluginmanager"`) as that name.
  - Allow `request`, `pytestconfig`, `item`, `metafunc` and `session` only through a public allowlist (`param`, `getoption`, `getini`, `addfinalizer`, `node.name`, …). Block any other attribute chain.
  - Opus #255 C2's allowlist approach, applied to what test code may reach, is the robust form.

### High

**H1. `runpy` (and other code loaders) run a non-`.py` file that no guard reads. There is no block and no warning.** (`:36`, `:47-55`; a non-`.py` path is never scanned)

- **Input:** `tests/test_money.py` adds `import runpy` and, at the top level, `runpy.run_path("tests/data/forge.txt")`. The new `tests/data/forge.txt` holds `import _pytest.reports` and a class-level `outcome` descriptor (`__get__` returns `"passed"`).
- End to end: `2 passed`, `failures="0"` for two failing tests. 2a raises nothing, because `exec`, `compile` and `importlib` are listed but `runpy` is not. P14b's fail-closed rule does not cover `forge.txt` either.
- **Fix:** List these in class `f`: `runpy`, `run_path`, `run_module`, `pickle`/`marshal` `loads`, `code` (`InteractiveInterpreter`, `compile_command`), `types.FunctionType`/`CodeType`, `zipimport`, `pkgutil`, `load_module`, `exec_module`, `SourceFileLoader`.

**H2. The import-time rule is lexical and mis-scoped, so the "unnamed" flag is not closed.** (`:239-259`, `:253-255`)

- The `__main__` guard is matched by `t[1]=="__name__"` and `t[4]=="__main__"` only. Both `if __name__ != "__main__":` and `if __name__ == "__main__" or True:` qualify, and their bodies run on every import.
- Decorator tokens (`deco`, `:241`) and the whole `def` line (default arguments, annotations) are credited to the function. Python evaluates them at import.
- A function called at module level is not followed. P14b's Go guard follows reach from `init` (`maxReach`).
- Probes against `money.py` (base text plus the lines shown). Each gives only a warning, no block:
  - `if __name__ != "__main__":` + `import os` + `os._exit(0)` → warning "_exit in __main__";
  - `if __name__ == "__main__" or True:` + `sys.modules["money"].__dict__` → warnings only;
  - `def _f(x=os._exit(0)): pass` → warning "_exit in _f";
  - `@(lambda f: os._exit(0))` on a `def _g` → warning "_exit in _g";
  - `def _b(): import os; os._exit(0)` then `_b()` at the top level → warning only.
  - In a test module, `def test_add(_=threading.Thread(target=print).start()):` gives warnings only, though output and threads "block at a test module's import".
- **Fix:**
  - Accept only `if __name__ == "__main__":` or `if "__main__" == __name__:`, with nothing else on the line.
  - Credit decorator tokens and `def`-line tokens outside the body to the enclosing scope.
  - Follow module-level calls of same-file functions transitively: their bodies count as import code, bounded like `maxReach`.
  - Add rows: mutation MD (dropping the `"__main__"` test) and mutation ME (treating class bodies as a scope) both survive today.

**H3. A builtin fixture can be overridden through `name=` or an import. The block applies only to a `def` with that name in a tested file.** (`:269-271`)

- **Input 1:** a conftest with `@pytest.fixture(name="capsys")` on `def _c(): return None`. 2a raises nothing.
- **Input 2:** `tests/conftest.py` holds only `from helpers import capsys`. The new `tests/helpers.py` (not a test file, so `pyTested` is false) defines `@pytest.fixture def capsys(): return _C()`, where `_C.readouterr()` returns `out="hello\n"`.
  - End to end: `assert capsys.readouterr().out == "hello\n"` passes while the code prints `bye`.
  - Without the conftest, the test fails. 2a raises nothing.
- **Fix:**
  - Block a `pyFixtures` name that appears as a `name=` string in a fixture decorator, in any file.
  - Block a fixture definition with a `pyFixtures` name in any changed file, not only tested ones.
  - Block an import in a conftest or test module that binds a `pyFixtures` name.

**M3. The conftest's "fixture only from pytest" rule is bypassed by aliasing `pytest` itself.** (`:298-300`)

- **Fix:** In a conftest, `import pytest` must be unaliased, and no other import may bind `pytest` or `fixture`.
