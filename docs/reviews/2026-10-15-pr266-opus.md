Re-runs:

- **H1:** the original blocks. With `runpy.run_path(...)` moved into `g` behind a3, the guard shows nothing and pytest shows `2 passed`.

Bodies are 2a3's job, but here a def body runs at import. So the allowlist gives no more protection than the body set, and Opus #263 H2's "call followed at import" case is open again in judged files.

Fix:
1. In a judged file, block a dunder name that is bound at import in any way: an assignment or walrus target at any depth, an `import … as`, an imported name, or a def/class name. Block the same for `pytest`, `fixture`, `mock`, `patch`, `unittest`, and any callee a later widening allows.
2. Make a decorator exactly an allowlisted chain plus at most one balanced `( … )`, with nothing after it.
3. Block `*` and `**` in class headers.
4. Block `**` in constants unless a `{` follows it.

Add rows a1–a18.

**H2. A string condition in `pytest.mark.skipif`/`xfail` is code. pytest evaluates it with `config` in scope, and the allowlist accepts it as a constant.** (`integrity_pyimport.go:56-69`, `:71-84`)

### False blocks

Corpus: 2,128 judged files from inframedic, TransformerEngine tests, numpy, networkx, setuptools, pyarrow and sympy. **1,247 files (59%) hold at least one finding.** Because `a.bad` is not compared with the base, any edit to these files blocks.

Main classes, as a share of judged files:
- `__init__`/`__repr__`/`__str__`/`__post_init__`: 9.2%.
- `@classmethod`/`@staticmethod`/`@property`: 7.5%.
- `parametrize` arguments that call (`tuple(…)`, `sorted(…)`): about 8%.
- A top-level `if`: 4.4%.
- `Path(__file__)` and `os.path.dirname(__file__)`: 3.5%.
- `try`/`except ImportError`: 3.2%.
- `importorskip`: 2.4%.
- Attribute or subscript assignment: 2.2%.
- `__enter__`/`__exit__`: 1.4%.
- `getLogger`: 0.1%.

Proposed safe widenings, ranked by value. Each needs H1's binding rule first: the allowed callee or decorator names are never bound in the file.

1. **Judge only new findings against the base.** This is the largest gain. A finding statement that is unchanged from the base passes only if every name it calls is imported (not defined in the file) and the file's imports are unchanged. Must block: the base has `X = helper()`, and the candidate edits `def helper()`.
2. **`def __init__`, `__repr__`, `__str__`, `__post_init__`** (9.2%), only in a plain class. Plain means: bases empty, `object`, builtin exceptions, `unittest.TestCase`, or same-file plain classes, and no class keywords.
   - Never allow `__exit__`. A probe showed `__exit__` returning `True` hides a failing `assert`, and pytest showed `2 passed`.
   - Never allow `__eq__`/`__ne__`/`__bool__`/`__len__`/`__lt__`… or `__new__`, `__get__`, `__iter__`, `__getattr__`.
   - Must block: an `Enum` base with `__init__` (a probe showed it runs at import); `__init__ = g`; `class H(**{...})`.
3. **Bare `@staticmethod`, `@classmethod`, `@property`, and `@NAME.setter`/`.getter`/`.deleter`** (7.5%). NAME must be an `@property` def earlier in the same class. Must block: `def staticmethod(f): …` followed by `@staticmethod`; `@money.setter`.
4. **A top-level `if COND:`/`elif`/`else`** (4.4%) and **`try:`/`except ImportError|ModuleNotFoundError [as N]:`/`else:`/`finally:`** (3.2%). The condition must be pyConst; inner lines are still judged line by line. Must block: `try:` with `X = f()` inside; `except K as fixture:`.
5. **`Path(__file__)` chains** (3.5%): `Path`/`pathlib.Path`/`os.path.dirname|abspath|realpath(__file__)`. They may be followed only by `.parent`, `.parents[INT]`, `.resolve()`, `.absolute()`, `/ "lit"`, `.joinpath("lit")`, `.with_name`/`.with_suffix("lit")`, or by `os.path.join(<chain>, "lit")`. `Path` must be bound only by `from pathlib import Path`, and `__file__` must never be bound. Must block: `def Path(*a)`; `Path(K)`; `.write_text(…)`; `.glob(…)`.
6. **`pytest.importorskip("lit"[, minversion="lit", reason="lit"])`** (2.4%) as a statement or a constant's value. It is equal to an `import`. Must block: a variable argument; `exc_type=`.
7. **Builtin constructors on constants**: `tuple`, `list`, `set`, `frozenset`, `range`, `len`, `zip`, `enumerate`, `reversed`, and `sorted`/`min`/`max` with no `key=`. This removes most `parametrize` blocks. Never allow `dict(NAME)` or `**NAME` (they call `.keys()`, a18), `map`, `filter`, `type`, `getattr` or `vars`. Must block: `sorted(Y, key=g)`; `def sorted(…)`; `dict(K)`.
8. **`@dataclass`/`@dataclasses.dataclass` with constant arguments**, plus annotation-only lines (2.1% together). `field()` only with `default=CONST` or `default_factory=list|dict|set|tuple`, and never `compare=False`.
9. **`@functools.lru_cache[(CONST)]`** (0.5%) and **`logging.getLogger(__name__|"lit")`** (0.1%). These are safe but give little.

Keep blocked:
- `@contextmanager`: its generator can catch an `AssertionError`, the same risk as `__exit__`.
- `sys.path.insert`, `os.environ[...] = `, and attribute or subscript assignment.
- A top-level `for` or `with`.
