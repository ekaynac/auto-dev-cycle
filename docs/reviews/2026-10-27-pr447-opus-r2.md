### The new forgery class: runner shadowing (R1)
- **The patch adds only a root `pytest.py`** (22 lines). The item runs `python -m pytest`, so Python puts the working directory, `/workspace`, first on `sys.path`. The patch’s `pytest.py` therefore runs as `__main__` in place of pytest.
  - It drops `/workspace` from `sys.path`, imports the real pytest from `.deps`, and calls `pytest.main(argv, plugins=[Forge()])`. `Forge` holds the same `pytest_runtest_makereport` hookwrapper that turns failures into passes.
- **Result:** `accepted`, exit 0, `reasons []`, `protected_touched []`. C is 29/29, exit 0, while H still has 3 failing.
- **Why the globs miss it:** `pytest.py` matches none of py-mini’s protected globs. Adding `pytest.py`, `_pytest/**` and `pluggy/**` would close this file, but not the class. Python resolves every module the runner imports before site-packages from the working directory first (`iniconfig.py`, `packaging/`, `pluggy/`, and stdlib names such as `inspect.py`). Node, PHP and Go have their own equivalents.
- **This is not the documented residual.** No code under test runs here: the file never belongs to the project, and it replaces the harness.
- **What should close it:**
