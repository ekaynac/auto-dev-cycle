1. **High — Object-resolution failure silently removes all promised signals from a valid file.**  
   `internal/accept/integrity_out.go:156`

   Concrete input: using the existing vendored-libc fixture, add `pkg/out.go` containing:

   ```go
   package pkg

   import "modernc.org/libc"

   func quit() { libc.X_Exit(nil, 0) }

   func padding() {
       // 1,001 nested ordinary blocks, then their closing braces.
   }
   ```

   The pinned Go 1.27.1 resolver rejects nesting beyond 1,000 scopes. Main parses with `SkipObjectResolution`; the layer enables resolution. Consequently, main can parse and type-check this file, while the layer receives an error and returns `nil`, losing the libc block **and the import-edge warning**. The resolver bailout is recovered inside `ParseFile`, so `outRun`’s panic handler provides no protection. This directly contradicts the pre-review’s assertion that these parser modes accept the same inputs. [Go resolver source](https://go.dev/src/go/parser/resolver.go#L57)

   The same padding hides `flag` references or a newly added dot import. This is neither a body-fingerprint residual nor deferred types analysis.

   **Fix:** use main’s syntax-parser mode and perform bounded lexical shadow tracking separately. Do not discard an otherwise valid file because optional object resolution failed.

2. **High — The layer’s work bound still blocks inputs main accepts, including an impossible-to-build file.**  
   `internal/accept/integrity_out.go:130`; `internal/accept/integrity_out.go:192`

   Concrete input: add `tool/off.go` with **5,000 identical copies** of this legacy constraint, followed by a blank line and `package tool`:

   ```go
   // +build a,!a b,!b c,!c d,!d e,!e f,!f g,!g h,!h i,!i j,!j k,!k l,!l
   ```

   Every alternative is contradictory, so the file is never built. Main deduplicates identical constraint lines in `goOn`; evaluating its single expression on both platforms stays comfortably below `maxWork`.

   The layer retains all 5,000 expressions and charges `len(exprs)` before each assignment. With twelve free tags, it exhausts `1<<24` after 3,356 assignments—even though `ContainsFunc` rejects each assignment after evaluating just the **first** expression. Main accepts; the layer adds an over-bound block.

   The ordinary generated-code regression also remains. Extend C1 from two to **six** distinct files, each containing `3<<19` repetitions of `0,` in a generated slice, and add the same one-line neighbouring file. The unchanged generated source totals about 18 MiB, within main’s limits. The layer charges both nodes and `ast.Inspect`’s trailing `nil` callbacks: the literals alone consume 18,874,368 units, exceeding 16,777,216. Parsing each blob once does not fix that threshold. [AST traversal source](https://go.dev/src/go/ast/walk.go#L355)

   **Fix:** deduplicate constraints and charge actual tag visits. Separately, justify the AST allowance against main’s accepted input envelope, including filename-dependent cache misses, or make additive exhaustion nonblocking. Passing the smaller C1 fixture does not establish verdict isolation.

3. **High — Default import names are guessed from paths, bypassing libc classification.**  
   `internal/accept/integrity_out.go:164`

   Concrete input: construct the existing fixture’s unchanged `vendor/modernc.org/libc/sub/sub.go` as:

   ```go
   package shim

   func X_exit(int32) {}
   ```

   The unchanged tested package already contains:

   ```go
   import "modernc.org/libc/sub"

   func keep() { _ = shim.X_exit }
   ```

   Add `func quit() { shim.X_exit(0) }` to that file.

   This is a valid qualified package reference: an omitted import name comes from the imported package’s declaration, not its path basename. The layer registers `names["sub"]`, so both `shim.X_exit` references disappear from its analysis. The existing import also suppresses the edge warning. The candidate is therefore **silent and accepted**, despite adding a promised class-2 reference. [Go import declarations](https://go.dev/ref/spec#Import_declarations)

   Explicit renamed imports work; this ordinary default-name form does not. It is absent from the residual.

   **Fix:** obtain default names from already-loaded package metadata without changing main’s analysis. If resolution varies by module/version, include that context in the layer’s cache identity.

4. **High — Adding `Standard` can change main’s own findings at the listing byte boundary.**  
   `internal/accept/integrity_types.go:167`

   Concrete input: a pre-cached external dependency graph whose successful main-format listing occupies `maxList−1` bytes and includes a standard package such as `fmt`. Dependency import-path lengths can supply the padding; small dependency exports can remain below `maxExport`.

   Adding `"Standard": true` pushes that same listing beyond the unchanged 16 MiB `maxList`. `drain` returns `ErrTooLarge`; the loader supplies an import failure, and main’s `typedOn` produces a **non-Additive unverifiable block** where main previously loaded the imports successfully.

   This happens before the hook. Turning `outHook` off does not restore the old listing command, so every hook-on/off equality test misses this regression.

   **Fix:** acquire additive classification separately after main finishes, or account for the added metadata separately while preserving main’s original listing allowance. Include an actual-main comparison at the output boundary.

5. **Medium — Finding emission performs uncharged quadratic directory work.**  
   `internal/accept/integrity_out.go:281`; `internal/accept/integrity.go:244`

   Concrete input: a tested package has 20,000 unchanged non-Go files and its test file sorts last. Add one Go file containing 10,000 distinct ordinary functions calling `libc.X_Exit(nil, 0)`.

   Every new reference calls `r.tested(dir)`. Each call clones and concatenates both directory lists, then scans for a test. This entails roughly 200 million filename checks and at least **6.4 GB of string-descriptor copying**, while the layer charges only the comparatively small AST traversal. The comparison loop also has no cancellation checkpoint.

   Main does not generate these libc reference findings, so this added cost is not merely inherited work.

   **Fix:** compute `tested` once per directory and reuse it for libc and dot-import findings. Add cancellation checks during comparison/emission. Other uncharged passes include parsing/object resolution, free-tag collection, map aggregation/sorting, and import-ownership walks; the read-byte limit alone does not bound their amplification.

Successful main reads also leave the layer’s touched Go blobs cached. Those improvements do not eliminate findings 2 and 4’s verdict/main-stream regressions.
