### High

**H1. A change by types to the S use of an `init` or `TestMain` body is silent when the body's bytes do not change.**

- **Where:** `internal/accept/integrity_out3.go:445-449` and `:369`.
  - The body pass records only `tuses`, never `trefs`.
  - `outTypedSignals` then reports a body binding only when its fingerprint differs (`inB && inA && bp == ap` → `continue`).
  - Function bodies (`func f`) and `init literal` record `trefs` (`:434-438`), so the same change there gives a typed "references into flag … changed" entry. The body binding has no such route.
- **Why it is inside the promise:** the first acceptance criterion says a body "whose S use by types outside its function literals changes, or which is added, gives its own `Typed` entry".
- **Input:** package `ua`.
  - `st.go` (unchanged):
    - `import "flag"`;
    - `type T struct{}` with `func (*T) Parse([]string) error`;
    - `var safe = &T{}`;
    - `var fatal = flag.NewFlagSet("f", flag.ExitOnError)`;
    - `var parse func([]string) error`.
  - `a.go` (unchanged): `func init() { parse = x.Parse }`.
  - `v.go` changes `var x = safe` to `var x = fatal`. The file has no imports.
- **Results:**
  - **`init`:** accepted, with no blocks and no warnings at all, so the whole guard is silent.
  - **`TestMain`:** the same with `TestMain(m *testing.M) { parse = x.Parse; os.Exit(m.Run()) }` in `um/m_test.go`: accepted, silent.
  - **Controls at this head:**
    - the same change behind `func f() { parse = x.Parse }` gives a typed `uf/a.go references into flag … (1: f)`;
    - behind `init() { hook = func() { parse = x.Parse } }` it gives a typed `… (1: init literal)`.
  - It also happens with the change in the body's own file: `var y *FS` added, `var x = y`, where `type FS = flag.FlagSet` is declared in an unchanged file.
- **Fix:** in the body callback, count the body's typed references under its binding, as the literals' references are counted:

  ```go
  if r.chargeTypes(len(bind) + len(ref)) {
      counts[pkg+"\x00"+bind+"\x00"+ref]++
      of.tuses[bind+"\x00"+pkg] = true
  }
  ```

- **What the fix did in a throwaway copy:**
  - Every probe above gave a typed `references into flag … (1: init body)` or `(1: TestMain body)` entry.
  - `outSame` held in every run.
  - `TestDecisionAOut3` and `TestOutTypedEntries` passed.
  - `TestOutTypedBodies` failed only on the row "an init added", which now reads `references into flag … (1: init body)`: the body entry is deduplicated by `refs[fp]`. Update that row's expectation, or put the sorted typed references into the body fingerprint to keep the "changed bodies" wording.
  - Add these inputs as rows: `init` and `TestMain`, with the type changed in another file and in the same file.
