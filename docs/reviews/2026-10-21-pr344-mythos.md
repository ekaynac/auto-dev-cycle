### High

**H1. A branch a constant `switch` or `for` never takes keeps its cases.** `internal/accept/integrity_cases.go:232-238` (`markDead`, called only for `*ast.IfStmt` at `:261`, `:317`, `:621`).
- **Input (in `TestRunsFn`):** replace `t.Run(tc.name, tc.fn)` with `switch { case false: t.Run(tc.name, tc.fn) }`, or with `for false { t.Run(tc.name, tc.fn) }`. Also, in `TestSub`, wrap `t.Run("other", …)` the same way (the `switch` twin of `subDeadKeep`).
- **What happens:** `kinds` sees the `t.Run` call directly under the loop frame (a `CaseClause` or `ForStmt` pushes no frame and is not in `dead`), so the loop is still `runs`; `walk` records `row "a" @1 runs`, `row "b" @1 runs` (or `run outer/other`). No event, no exit, no row text changes. Silent here and on main, while no subtest runs.
- **Why in the promise:** the file comment rules "A branch a constant condition never takes names no case", and the PR blocks the `if false` form. This is the same effect as Astra #318 1: identities kept, nothing executed.
- **Fix:** extend `markDead` to a `*ast.ForStmt` whose `Cond` is constant false; to a tagless `*ast.SwitchStmt`'s clause whose every expression is constant false, and every clause after one that holds constant true; and, with a constant tag, a clause whose constants all differ from it (fail closed: when unsure, the clause names no case). Add the three inputs above as rows and a mutation for each dead form.
