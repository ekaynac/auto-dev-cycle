**High — H2: an absolute argument to `os.path.join` is accepted with the wrong meaning.**

File: `internal/accept/integrity_pyreach.go:190`.

Concrete base, with the gate checkout at `/work/repo`:

```python
# conftest.py
import os
import sys
sys.path.insert(0, os.path.join(
    os.path.dirname(os.path.abspath(__file__)),
    "/work/repo/vendor/lib",
))
```

A base test imports `yaml`; candidate adds `vendor/lib/yaml.py`.

Python discards the preceding components at the absolute argument and adds `/work/repo/vendor/lib`. The evaluator instead calls Go’s `path.Join(".", "/work/repo/vendor/lib")`, producing relative `work/repo/vendor/lib`. Its final absolute/outside-root check passes, and the added file’s modeled names miss `yaml`. These joining semantics differ explicitly in [Python](https://docs.python.org/3/library/os.path.html#os.path.join) and [Go](https://go.dev/src/path/path.go#L150).

An absolute argument naming a directory outside the checkout is likewise incorrectly accepted. Running pytest from the repository root does not repair this.

**Fix:** reject absolute join components before joining, or implement Python’s reset semantics and validate the resulting path against the actual checkout root.

**Low — H2 adjacent case: an unsupported expression followed by `.parent` panics.**
