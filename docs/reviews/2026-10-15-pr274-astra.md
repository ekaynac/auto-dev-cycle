**Medium — M1. The replacement writer rule permits mutations of an “inert” package’s variables that main blocks.**

**Where:** `internal/accept/integrity_go.go:849`, with `read()` at `:911` and `shared()` at `:881`.

**Concrete input:** add this file to an existing package:

```go
package pkg

import (
	"slices"
	"unicode"
)

func init() {
	slices.Reverse(unicode.CaseRanges)
}
```

`CaseRanges` is a mutable slice, and `Reverse` modifies its elements in place. This changes shared Unicode data before tests run. [Unicode documentation](https://pkg.go.dev/unicode#CaseRanges), [Reverse documentation](https://pkg.go.dev/slices#Reverse).

On **main**, `inPlace("slices.Reverse")` and the foreign-root argument produce `a write it cannot prove safe (unicode.CaseRanges)`.

At **head**, `read(unicode.CaseRanges)` returns true because `unicode` is classified as inert. Consequently, `!s.read(a)` disables the new write check. `shared(a)` also accepts the inert package’s variable, and the callee itself is inert. Neither the `os.Args` counter nor the testing-type facts catch this input.

This is an unintended relaxation: permission to read a package’s data is being treated as permission to mutate it. It blocks this review because it regresses against main, independently of severity.

**Fix:** remove `!s.read(a)` from the foreign-root/off-allowlist condition. If scalar exemptions are needed, positively prove a non-aliasing scalar value without inheriting `read()`’s inert-package exemption. Add the input above as a regression row; also cover `maps.DeleteFunc(unicode.Scripts, func(string, *unicode.RangeTable) bool { return true })`.
