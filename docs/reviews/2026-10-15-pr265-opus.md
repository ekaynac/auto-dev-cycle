**H1. A double pointer escapes the "laundered" fact. This is entry 82 (b) again, and nothing blocks it.**
- **Where:** `integrity_types.go:520-535` (`launders`, the `*types.Pointer` case calls `holds(u.Elem(), false, nil)`). The same gap is at `:492-497` (the conversion rule) and `:512` (type arguments).
- **Cause:** `holds(*testing.T, false)` is false, so `**testing.T` does not count. The text rule `ptrTo` (`integrity_go.go:352`) looks at one star only.
- **Input:** the lead's e3 with one more star:
  ```go
  func TestAdd(t *testing.T) { func(t *testing.T){ if Add(1,2)!=3 { t.Error("add") } }(*mk2(t).(**testing.T)) }
  func mk2(v any) any { p := reflect.New(reflect.TypeOf(v).Elem()); pp := reflect.New(p.Type()); pp.Elem().Set(p); return pp.Interface() }
  ```
- **Result:** accepted, 0 blocks. The only warnings are the class-1 `reflect.New`/`reflect.TypeOf` "review it" lines, the same outcome #226 called a failure for 82 (b). The forgery passes end to end.
- **Same result:** `case **testing.T:` in a type switch, and `as[**testing.T](mk2(t))`.
- **Fix:** add one helper that strips every pointer level, then calls `holds(elem, false)`. Use it in `launders`, in the conversion rule and for `Instances`. Add rows for `.(**testing.T)`, `case **testing.T` and `as[**testing.T]`.

**H2. Reflection can write a fresh T into a typed field, with no assertion and no testing-typed reflect argument (82 (b) class).**
- **Where:** `integrity_types.go:577-592` (`reflects` reads only `info.TypeOf(arg)`).
- **Input A2:**
  ```go
  type holder struct{ T *testing.T }
  h := &holder{}
  reflect.ValueOf(any(h)).Elem().Field(0).Set(reflect.New(reflect.TypeFor[holder]().Field(0).Type.Elem()))
  func(t *testing.T){ if Add(1,2)!=3 { t.Error("add") } }(h.T)
  ```
- **Input C2:** t goes through a `chan any`; then `reflect.New(reflect.ValueOf(&x).Elem().Elem().Type().Elem())` is `Set` into the holder the same way.
- **Result:** both are accepted with class-1 warnings only, and both pass end to end.
- **Why nothing fires:**
  - `any(h)` hides `*holder`.
  - `TypeFor[holder]` is a type argument that is never checked.
  - A holder value does not count (the "fixture holding t" control).
- **Fix (decision A, a known form):**
  - In a package with tests, block a new call to reflect's API that creates or writes values: `New`, `NewAt`, `Zero`, `Value.Set*`, `Value.Call`, `Value.Method`/`MethodByName`.
  - Also make `reflects` read the type arguments of reflect instances, and the operand of a conversion to an interface, both with `holds(…, true)`.

**H3. The count comparison lets a candidate trade a legitimate counted form for a forgery. Entry 79 then passes silently.**
- **Where:** `integrity.go` `compare` (`a.forged > b.forged`, one count per directory), fed by `made` at `integrity_types.go:470-515`.
- **Input:**
  - The base has `pkg/helper_test.go` with `func pick(a, b *testing.T) *testing.T { return cmp.Or(a, b) }`. The `Instances` rule counts it (`*testing.T` as a type argument).
  - The candidate rewrites `pick` without `cmp.Or`, and adds `fresh(zt())` in calc_test.go.
- **Result:** accepted with 0 blocks and 0 warnings, and the forgery passes end to end. The forgery alone, on the same base, is blocked.
- **Same with:** a base helper that does `tb.(*testing.T)`.
- **Scope:** the `cmp.Or` budget exists only because of the new type facts. The same applies to the per-file presence check for "reflection on a testing value": a second reflection in a file that is already flagged is not seen.
- **Fix:** compare the facts by identity, not by count. Key each one by (file, enclosing function, `types.ExprString`/the type), and block any key whose candidate count is higher than the base's. Do the same per call for the reflection flag.

**H4. The directory-replace refusal can be bypassed, so go list reads source outside the temporary directory.**
- **Where:** `integrity_types.go:167-179` (`dirReplace` is a line-and-text parse).
- **Input:** either of these go.mod lines:
  - `replace golang.org/x/sys => "\x2fabs/dir"` (modfile unquotes the escape to `/abs/dir`);
  - `replace golang.org/x/sys => "//abs/dir"` (the cut at `//` deletes the target before the check).
- **Result:** I called `LocalLister` with both forms. `dirReplace` returned false, and the export data go list returned came from my out-of-tree fake `golang.org/x/sys/unix` (it holds its marker constant).
- **Effects:**
  - The guard then reads its types from a directory on the controller that the attacker chooses.
  - The go list error texts in the block reasons become a way to learn which controller paths exist, and the module line of any go.mod there.
- **Fix:**
  - Parse with `golang.org/x/mod/modfile` (already in the graph, v0.41.0) and refuse any `Replace` with `New.Version == ""`.
  - Take `ty.mod` from `f.Module.Mod.Path`. Today `module (` blocks and quoted module paths are misread; that fails closed, but it is fragile.

**M2. On a timeout or cancel, only go itself is killed. Its child processes keep running.**
- **Where:** `integrity_types.go:143-149`. `exec.CommandContext` has the default `Cancel` (`Process.Kill`); drain kills the process group only on an output overflow.
- **Input:** a fake go that starts a background child, with a 300 ms timeout. The lister returned at 302 ms, and the child was still alive 4 s later.
- **Fix:** when the context is done, kill `-pgid` from inside drain, before `Wait`. That keeps drain's reaping order.
