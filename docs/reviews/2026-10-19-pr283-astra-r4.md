2. **Medium — The 256-node limit does not stop traversal of wide types.**

   `internal/accept/integrity_out3.go:525`, `internal/accept/integrity_out3.go:555`

   **Concrete input:** declare `Wide` as an alias of a struct containing 10,000 distinct integer fields, declare `var w Wide`, and use `_ = w` inside an `init` that also uses `fatal.Parse`.

   After the counter exceeds 256, the struct loop still visits every remaining field, formats its name, embedding flag and tag, and appends another `…deep` result. Tuples, interfaces, unions and named-type argument lists have the same continuation pattern. The complete string is allocated before its caller charges it.

   Hash accounting is correct, but the stated per-type work cap is not enforced. This concerns traversal and allocation, not the accepted equality of truncated fingerprints.

   **Fix:** stop sibling iteration when the shared node budget is exhausted, emit one marker for the remaining portion, and cover wide types with a deterministic bound assertion.
