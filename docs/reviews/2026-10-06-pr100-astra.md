1. **High — PR #100: a racing hard link bypasses the boundary.** [internal/adapterhost/ingest/ingest.go:231](/tmp/claude-1000/-home-mega/d7e41cde-3883-4e5c-8d98-04b890c5f4c4/scratchpad/wt-ah4/internal/adapterhost/ingest/ingest.go:231)

   Link count is checked only during initial inspection. Neither the reopened-file check nor the final check validates it. On sandbox tmpfs, creating an outside hard link at the `checked` hook published successfully with **`nlink=2`**, on both paths, on the first attempt. Unchanged ctime defeats detection; the digest cannot detect another link.

   **Fix:** require `Nlink == 1` on the reopened descriptor and final fstat. Add this race as a refusal test under both paths, asserting no blob or temporary file remains.

2. **High — PR #100: pathname reopening can open a substituted special file.** [internal/adapterhost/ingest/ingest.go:174](/tmp/claude-1000/-home-mega/d7e41cde-3883-4e5c-8d98-04b890c5f4c4/scratchpad/wt-ah4/internal/adapterhost/ingest/ingest.go:174)

   After checking the `O_PATH` descriptor, the code resolves the attacker-controlled name again with `O_RDONLY`. Replacing the inspected regular file with a FIFO produced an **`IN_OPEN` event before refusal**, under both paths. The subsequent inode comparison is too late to prevent opening it. A reachable device replacement similarly reaches device-open handling; `O_NONBLOCK` is not a general device safety boundary. [Linux open documentation](https://man7.org/linux/man-pages/man2/open.2.html)

   **Fix:** obtain the readable descriptor from the pinned, verified regular-file descriptor through a trusted mechanism, without resolving the attacker’s pathname again. Test substitutions for special files, including absence of I/O opens.

3. **High — PR #100: fallback does not enforce the same mount boundary.** [internal/adapterhost/ingest/ingest.go:118](/tmp/claude-1000/-home-mega/d7e41cde-3883-4e5c-8d98-04b890c5f4c4/scratchpad/wt-ah4/internal/adapterhost/ingest/ingest.go:118)

   Equal `st_dev` does not establish equal mounts. In a rootless test namespace, a same-filesystem bind-mounted outside file had link count one and passed the fallback, publishing successfully. Native `openat2` rejected it. Different-device mounts were rejected by both paths.

   This requires the mount to be visible in the ingester’s namespace; an adapter’s private mount alone does not establish that. Nevertheless, the advertised fallback equivalence fails: `RESOLVE_NO_XDEV` rejects bind mounts too. [Linux openat2 documentation](https://man7.org/linux/man-pages/man2/openat2.2.html)

   **Fix:** compare descriptor mount identities, including the reopened descriptor, and fail closed when equivalent verification is unavailable. Add same-device bind tests.

4. **Medium — PR #100: refusal categories misidentify two failures.** [internal/adapterhost/ingest/ingest.go:176](/tmp/claude-1000/-home-mega/d7e41cde-3883-4e5c-8d98-04b890c5f4c4/scratchpad/wt-ah4/internal/adapterhost/ingest/ingest.go:176), [ingest.go:194](/tmp/claude-1000/-home-mega/d7e41cde-3883-4e5c-8d98-04b890c5f4c4/scratchpad/wt-ah4/internal/adapterhost/ingest/ingest.go:194)

   An unchanged mode-000 file returns `replaced`, although it is merely unreadable. Separately, corruption of an existing stored blob becomes adapter `unsafe_output/digest`, because blobstore uses `ErrDigestMismatch` for both incoming and stored content. Both cases were reproduced.

   **Fix:** classify access/I/O failures as `unreadable` unless replacement is established. Distinguish incoming digest mismatch from stored-blob corruption and propagate the latter as a store error.

### Lead notes on round 1 (applied)

- High 1 (hard-link race): the link count must be 1 on the inspected O_PATH descriptor, on the reopened descriptor and in the final statx after the copy. A count of 0 (unlinked after inspection) is `replaced`, more than 1 is `hard_link`. New table cases create an outside hard link at the `checked` hook and during the copy, and unlink the file during the copy. All are refused under both paths, with no blob and no temp file left.
- High 2 (pathname reopen): the attacker's name is resolved exactly once, to the O_PATH descriptor. The readable descriptor comes from `/proc/self/fd/<n>` of that pinned, verified regular inode (`O_RDONLY|O_NOCTTY|O_CLOEXEC`, without `O_NOFOLLOW`), so whatever now sits at the name is never opened. Without /proc, Ingest fails closed (`unreadable`). `TestFIFOSubstitutionNeverOpened` replaces the checked file with a FIFO at the hook and watches it with inotify `IN_OPEN`. It sees no open under either path, and it confirms that the watch does catch a real open.
- High 3 (mount boundary): statx mount ids (`STATX_MNT_ID_UNIQUE`, else `STATX_MNT_ID`; the held descriptors pin their mounts, so a plain id cannot be reused) of out/, the O_PATH descriptor and the reopened descriptor must match. A mismatch is `special_file`, and a kernel that does not report the id fails closed (`unreadable`). `TestBindMountRefused` uses bwrap to bind an outside file over `out/res` on the same device in a rootless namespace. It runs both paths inside, and is skipped without bwrap. Switching off the mount comparison makes its fallback case ingest, which reproduces the finding (checked locally, then reverted). `TestSameMount` unit-tests the comparison.
- Medium 4 (categories): a reopen failure on the pinned inode (EACCES, EIO) is `unreadable`, so a mode-000 file is refused as `unreadable`. The blob store adds `ErrDeclaredDigest`, which Put wraps together with `ErrDigestMismatch` only when the incoming bytes miss the declared digest. Ingest maps only that error to `digest`. A corrupt stored blob stays a store `ErrDigestMismatch` (tested in blobstore and in ingest).
- The during-copy tests now use a payload of several copy buffers (about 205 KiB), so their mutations land between chunks. A same-size in-place overwrite during the copy is refused as `replaced` or `digest`. The Ingest doc comment states what the checks prove and what the digest does not: it covers the copied stream, but it is not a snapshot of the file's state between reads.
