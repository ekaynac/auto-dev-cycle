### Critical

**C1. A skip is forgotten as soon as the scan reads the next identifier.** `internal/accept/integrity_skips.go:115` (also `:110` and `:112`)
- **Cause:** The visitor assigns `found =` at every `Ident` and `Skip` selector. When a node returns false, `ast.Inspect` still visits the nodes beside it. So the identifier argument after a skip call resets `found` to false.
- **Inputs:** each base helper below is never "skipping", and adding its use to an existing test is accepted with no warning:
  - `func needEnv(t *testing.T) { name := "X"; t.Skipf("no %s", name) }`, used as `needEnv(t)`;
  - `func needErr(t *testing.T, err error) { if err != nil { t.Skip(err) } }`;
  - helper to helper: `func needAll(t *testing.T) { requireDocker(t) }`, where the `t` argument resets it;
  - a literal variable: `var needVarLit = func(t *testing.T) { requireDocker(t) }`.
- **The worst variant:** edit an existing asserting helper `check`, used by `TestChecked`, to start with `requireDocker(t)`. It is accepted with no warning, and main also accepts it.
- **Why the rows pass:** every row's skip has a literal argument (`t.Skip("unavailable")`), and no row has one helper calling another.
- **Fix:** start the visitor with `if found { return false }`. In a copy, this alone makes all five forms above and the `check` edit block, and `TestIntegritySkips` and `TestIntegritySkipsBound` still pass.
  - Add rows for `Skipf` with an identifier argument, a helper calling a helper with `t`, and a literal variable calling a helper.
  - Add a mutation: `found =` instead of OR.

### High

**H1. The skip reading uses up the run-wide work bound. This is a new false block against main, not stated.** `internal/accept/integrity_skips.go:96`, `:181-196`
- **Cause:** every function body in a touched package is charged to `maxWork` (16 MiB). That bound is shared with build-constraint evaluation. Each body is charged again on every iteration, for each platform and each version, so one package costs 2 platforms × 2 versions × (iterations ≥ 1) × its body bytes.
- **Measured on this repository:**

| Change touching | Work used (of 16.8 MB) |
|---|---|
| `internal/accept` alone | 6.2 MB (8.8 MB with C1's fix) |
| accept, graph, authority, daemon, fixtures, cli | 14.7 MB |

- **Input:** a change touching those six plus `internal/sandbox`, `internal/gate`, `internal/harness` and `internal/eventstore`.
  - All 13 Go files of `internal/eventstore` become "unverifiable: skipping helpers past the guard's bound".
  - Every later directory finds the bound already spent: its files fail as "its build constraints are over the guard's work bound", a block blamed on another layer.
  - Main's work for the same change is close to zero.
- **Not stated:** the residual lists only alias chains deeper than 32 and uses never run. The replay touches one or two packages per run, so it never reaches this.
- **Fix:**
  - Read each body once per scan, recording whether it skips directly and which package functions and variables it references.
  - Propagate over the reverse references with a worklist. Nothing is re-read, and the 32-iteration depth limit is no longer needed.
  - Charge the skip layer to a bound of its own, as the out layer has (`r.out`), so it cannot use up later directories' build-constraint work.
  - Add a row touching about 10 packages.

**H2. A package variable that holds a skipping helper inside a slice, map or struct is never skipping.** `internal/accept/integrity_skips.go:64-77`
- **Cause:** `assign` records only a bare function, a bare variable or a literal. Opus #292's `skipSlice` and `skipField` rows are closed only when the slice or struct is written inside the test.
- **Inputs:** each base declaration below is accepted when a test adds the use shown:
  - `var needs = []func(*testing.T){requireDocker}`, used as `needs[0](t)`;
  - `var byName = map[string]func(*testing.T){"docker": requireDocker}`, used as `byName["docker"](t)`;
  - `var cfg = struct{ need func(*testing.T) }{requireDocker}`, used as `cfg.need(t)`;
  - `var holder struct{ f func(*testing.T) }` with `func init() { holder.f = requireDocker }`, used as `holder.f(t)`.
- **Why it is inside the promise:** the promise says "a package variable is skipping when it holds a skipping function".
- **Fix:**
  - Record each value assigned to a package variable, including through `x.f =` and `x[i] =`, under the root variable.
  - A package variable is skipping when any assigned value contains a skipping use (`ast.Inspect` with `skipUse`). Charge each value read to the bound.

**H3. Quadratic work the bound does not charge.** `internal/accept/integrity_skips.go:59`, `:68`, `:71`
- **Cause:** `varSkips` scans `funcVals[o]` for every identifier that uses `o`, in `count` and in every `skipsIn`. `assign` removes duplicates with `slices.Contains`. Neither is charged; only body bytes are.
- **Input:** a package variable `v`, an `init` assigning it N distinct package functions, and a test with N calls `v(t)`. One skipping helper must exist anywhere in the package (it switches off `skipUse`'s fast path).
- **Measured:** time for one version (both platforms):

| N | File size | Head | Main |
|---|---|---|---|
| 10k | 428 KB | 12.8 s | 0.8 s |
| 20k | 878 KB | 52.9 s | 2.2 s |
| 40k | 1.78 MB | 227 s | 6.8 s |

- **Effect:** four times the cost per doubling. The bound charged only 3.2 MB at 40k. With `maxFile` at 4 MiB, one file runs for about 20 minutes per version, and `ctx` is not checked inside one `count` or `skipsIn`.
- **Fix:**
  - At the end of each iteration, fold `funcVals` into `skipVars`, so `varSkips` is a single map lookup.
  - Keep `funcVals` and `varSrcs` as sets.
  - The H1 worklist removes the repeated scans as well.

### Medium

**M1. Testing values reached through a field or a range variable are missed, and the residual does not name them.** `internal/accept/integrity_skips.go:124-127`, `:143-157`
- **Inputs:** both are accepted when a test adds the use shown:
  - `type env struct{ t *testing.T }; func (e env) need() { e.t.Skip("x") }`, used as `env{t}.need()`;
  - `func needRange(t *testing.T) { for _, u := range []*testing.T{t} { u.Skip("x") } }`, used as `needRange(t)`.
- **Why it matters:** the residual names only "a testing value obtained through a call". A field or an element is not a call.
- **Fix:** either:
  - state "through a field, an element or a range variable" in the residual; or
  - treat a struct field whose declared type resolves to a testing type (`qual` on the field's AST) as a testing receiver.

### Low

**L1. Cyclic copies give a no that depends on order.** `internal/accept/integrity_skips.go:137`
- **Cause:** the inner visit's "being read" answer is stored as final.
- **Inputs:**
  - `func needCyc(t *testing.T) { u := t; u = u; u.Skip("x") }`, used as `needCyc(t)`, is accepted;
  - `a := t; b := a; a = b; a.Skip("x")` is missed the same way.
- **Fix:** compute "not direct" as reachability from indirect or non-testing variables over the copy edges, so cycles resolve to yes.

**L2. The residual's false-block list is incomplete.** `internal/accept/integrity.go:359-360`; `internal/accept/integrity_go.go:716`
- **(a) A base chain also blocks.** The base's `bad` is merged in, so a base that is already past the bound blocks every later change to that directory, not only the change that adds the chain.
  - **Input:** after C1's fix, a base chain `h1(t) → h0(t) → requireDocker(t)` 40 deep, plus a comment-only change to `pkg/calc.go`. Every test file of `pkg` becomes unverifiable.
- **(b) Helper chains count too.** Once C1 is fixed, helper call chains also count toward the 32 iterations, not only alias chains.
- **(c) Interface method names.** A call of any same-package interface method that has a skipping method's name counts. This is stated under "What it does" but not in the false-block list.
- **Fix:** restate the residual, or make the limit disappear with H1's worklist.

### Judged as sound
- **Astra r2 1:** main's direct comparison is separate. Replacing `_ = requireDocker` with `t.Skip`, and the reverse, both block. K3 is caught.
- **Astra r2 4 and M7:** `skipElement(t)` and `skipDecoder(d *xml.Decoder)` are accepted. So are their variants:
  - `d2 := d` then `d2.Skip()`;
  - `var d *xml.Decoder = xml.NewDecoder(…t…)`;
  - a `t` shadowed by a decoder.
- **The deviation:** it adds no false-block class. A receiver is a skip only when it is a testing parameter or a plain copy, so a value a call returned (`wrap(t).Skip()`) is a miss, never a block. That miss is stated in the residual.
- **Astra r2 6:** each body is charged before it is read, and the bound is checked between helpers. The 32-iteration fixed point is bounded, and exhaustion fails closed. The unbounded cost is per identifier (H3), not per traversal.
- **Blocking as promised:**
  - a method value, in a test or in a package variable (`var methodVal = mv{}.need`);
  - a literal in a package variable that skips with a literal argument;
  - `tb.SkipNow()` through `testing.TB`;
  - a generic helper with a `*testing.T` parameter;
  - a nested literal;
  - `f := t.Skip; f("x")`.
- **Blocked by another layer:** a helper generic over `T testing.TB`, and a wrapper embedding `*testing.T`. The types layer blocks both ("a testing value not the runner's").
