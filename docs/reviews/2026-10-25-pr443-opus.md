### 3. The shared prelude
- **Ordering:** both drivers run `set +o xtrace +o verbose`, then two assignments, a `[[ ]]`, and `. "$adc_here/lib/clean-shell.sh"`, before any helper. The prelude itself uses only `$(<…)`, `[[ ]]`, `exec` and `printf` (the fd-3 writer) before the re-exec. That matches the stated boundary (`.`, `set`, `exec`, `printf`).
- **Not stated (L1):** `adc_here` (and later `here`) come from `${BASH_SOURCE[0]}`, and **bash imports `BASH_SOURCE` from the environment**. Probe: `env BASH_SOURCE=/evil/x bash script` gives `${BASH_SOURCE[0]}` = `/evil/x`. So one inherited variable chooses which `clean-shell.sh`, `secrets.sh`, `sandbox-root.sh` and `base-remote.sh` run.
  - **With no such files** it fails closed. A missing directory fails `cd` under errexit, exit 1. An older prefix's libraries lack `clean_shell_credentials`, so 127 is read as "malformed", exit 2.
  - **To fail open** it needs operator-provided files: the same class as `BASH_ENV`, but unstated.
  - **Also:** a `.` of a missing file only returns 1 in bash, so the driver continues without the prelude. It then fails closed on fd 3, but by accident.

### Findings
- **H1** (BLOCKING under entry 202: data loss outside the run's own directories, and a false "unchanged"). The issue predates this PR (since #435), but it is inside its promise to audit "the whole of both drivers and the libraries they source" for exactly this class.
  - **(a) The sweep reads a live run as stale.**
    - `owner_of` (`scripts/lib/sandbox-root.sh:79-84`) returns `echo`'s status, so a dying `cut` writes `"PID "` with status 0. That is the run's own `.owner` (`scripts/installed-cycle.sh:186`; `sandbox_root`, `:90`).
    - `stale` (`:128-133`) treats any `owner_of` output that differs from the record as "gone", including an empty one: an unreadable `/proc/PID/stat` from a killed `cat`, EMFILE or ENOMEM, or another PID namespace.
    - So a concurrent run's `work_dirs_stale`/`sandbox_roots_stale` (`scripts/installed-cycle.sh:183-184`, `scripts/installed-cycle-set.sh:81`) `rm -rf`s a **live** run's work directory (its store) or resets its sandbox root.
    - Shown above with a live owner.
    
    **Fix:**
    - `owner_of`: `start=$(cut …) || return 1; [[ $start =~ ^[0-9]+$ ]] || return 1`.
    - `stale`: true only when the record is well-formed (`^[0-9]+ [0-9]+$`) **and** either `/proc/PID` is absent (`[[ ! -e /proc/$pid ]]`, a test with no producer) or the start time was read and differs. An unreadable start time is "keep".
    - **Rows:** the `cut`/`cat` stand-ins above, a malformed `.owner`, and a live owner's directory surviving `work_dirs_stale`.
  - **(b) `snapshot`** (`scripts/installed-cycle.sh:151-158`) returns only its second pipeline's status. A metadata `find` that dies in both snapshots hides a metadata-only change to the real `~/.config/adc` (probe above). This needs two failures, but it is the same class and the same commit. **Fix:** check each pipeline (`… || return 1`).
  - **Also:** consider `shopt -s inherit_errexit` in both drivers, and extend the static row to flag a `$(…)` in a `[[ ]]`, `case` or `echo` argument on a check path, or list each such use with its reason as the 18 are listed.
- **L1** (OBLIGATION, Low): take the prelude's and the libraries' directory from `$0`, which bash never imports, not from `BASH_SOURCE`, which it does. Or refuse when `BASH_SOURCE` is in `/proc/$$/environ`. Make the prelude's `.` fatal (`. … || exit 2`), and add `BASH_SOURCE` to the stated boundary if it stays.
- **L2** (OBLIGATION, Low): document the closed-but-lost statuses in the audit, so the next reader does not re-derive them:
  - the one-line `task=… scenario=… want=…` (only the last substitution counts);
  - the `/dev/shm` `stat` comparison, closed only by adcd's own check;
  - `forms`' intermediates, closed only because an empty pattern matches everything.

  Better, split the multi-assignment and check the `stat`s.
- **L3** (OBLIGATION, Low): `installed-cycle-set.sh run PREFIX` with no case (an empty `STUB_CASES`) prints an empty table and exits 0. Require at least one case.
- **L4** (OBLIGATION, Low): correct `record_pid`'s allowlist reason. After a SIGKILL the run's own cleanup never runs, and an unrecorded pid leaves its adcd running while the next sweep removes that run's directory. H1's validated `owner_of` makes the record reliable; keep the `|| true` only for the write itself.
