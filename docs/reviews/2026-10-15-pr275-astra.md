**High H3 — Setuptools interpolation is accepted as a literal directory.**

Location: `internal/accept/integrity_pyreach.go:85`.

Concrete `setup.cfg` for an editable installation:

```ini
[DEFAULT]
root = lib

[metadata]
name = example
version = 0.0.0

[options]
package_dir = =%(root)s
py_modules = flags
```

Base `lib/flags.py` contains `from cfg import PV as SKIP`; root `cfg.py` contains `PV = False`. A test imports `flags` and uses `skipif(flags.SKIP, reason='r')`. Candidate changes only `cfg.PV` to `True`.

Setuptools interpolates the directory to `lib`. [Setuptools interpolation documentation](https://setuptools.pypa.io/en/latest/userguide/declarative_config.html#interpolation).

The guard accepts the literal directory `%(root)s`, so neither module map names `flags`. Its third-party fallback searches for a binding named `SKIP`; `lib/flags.py` imports that name rather than defining a local binder, and the changed name is `PV`. The dependency is missed. Main marks this configuration unread.

**Fix:** reject interpolation-bearing directory values under the literal allowlist, or implement setuptools-compatible interpolation before validating and naming roots. Apply this to `where` too.

**High H6 — `pyPlain` accepts import-time execution that redirects package resolution.**

Location: `internal/accept/integrity_pyreach.go:232`, with the skipped body at `internal/accept/integrity_pyshadow.go:257`.

Concrete base:

```python
# feature/__init__.py
class Redirect:
    __path__.insert(0, "feature/impl")

# feature/flags.py
SKIP = False

# feature/impl/flags.py
from cfg import SKIP

# cfg.py
SKIP = False
```

A test explicitly imports `feature.flags` and uses `skipif(feature.flags.SKIP, reason='r')`. Candidate changes only `cfg.SKIP` to `True`.

`pyStatic` accepts the class header. Its body is appended to a unit without updating `f.dynamic` or module-level bindings, so `pyPlain` returns true. Python executes that body immediately and imports `feature/impl/flags.py`; the guard selects `feature/flags.py`. [Python class-definition semantics](https://docs.python.org/3/reference/compound_stmts.html#class-definitions).

“No call” also does not establish safety: `X = redirect[0]` can execute a `__getitem__` that performs the same mutation. Attribute access and overloaded operators have equivalent problems. Top-level decorators are rejected, but function default expressions and executable class bodies remain admitted.

**Fix:** give package plainness a dedicated conservative predicate covering all import-time evaluation. Reject unproved attribute/subscript/operator evaluation, executable class bodies, and non-inert function headers.

This bypass predates the PR on main, but violates the new `pyPlain` guarantee and reopens behavior round 2’s `__path__` scan rejected.

The structural split itself holds: added roots do not populate `pb.mods` or `binding`’s entries. Exact backend checks, absolute-join rejection, and the `.parent` failure check are present. The explicit P15 cwd contract remains acceptable. Those fixes do not close the missing blocks above.
