- **The cause:** names relative to `sys.path` entries are only as complete as `pyEntries`, which has the root, `pythonpath` and test basedirs. A base can add other entries: a conftest's `sys.path.insert`, an editable install with `package_dir`, or `setenv = PYTHONPATH=…` in tox.
- **Probe S1.**
  - Base: a `conftest.py` that inserts `app` into `sys.path`; `app/utils.py`; `app/money2.py` with `import utils`; `tests/test_total.py` with `from money2 import total`.
  - Candidate: adds `tests/utils.py`.
  - Main blocks, and the PR passes.
- **Probe S2.** The same layout through `setup.cfg` with `package_dir = =lib`. Main blocks, and the PR passes.
- **Fix:** keep main's rule as a floor for judged added files. An added file's `pySuffixes` matched against each base module's last component in another directory blocks. The control "a module beside an unrelated one" then blocks again, a false block that Mythos #266 r2 L5 accepted.

**H2. `pyReach` misses five common shapes, one step from r2 H3.**

- **Probes.** Each base test holds a condition, and the candidate changes only the module named. None of them blocks or warns:

  - **R10, a re-export with a rename:** `from .conf import REAL as PSLOW2`.

- **Fix:**
