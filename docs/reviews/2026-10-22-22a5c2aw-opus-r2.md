### High

**H1 (open). An `--adapter` path apart from the state directory can still bring the controller user's credentials, or the state directory, into the jail.** `internal/daemon/config.go:138-160`

`--adapter /adapter` is now refused ("must exist"), and so are `/etc`, a symlink to `/etc`, and an existing state directory reached through a symlink. These are accepted (probed with `LoadConfig`):

1. **An adapter in the home**, e.g. `~/.bashrc` (any file there) with the state directory elsewhere.
   - The jail then binds `$HOME`. Inside it, the probe found `~/.ssh`, `~/.config` and `~/.bashrc`.
   - That exposes the controller user's SSH keys and its `gh` or `git` tokens.
2. **An adapter in `/run/user/<uid>`.**
   - The jail binds the runtime directory. From inside, the probe connected to the `systemd --user` session bus (`/run/user/1000/bus`).
   - That bus can start a transient unit, which runs outside the jail as the controller user: a full escape.
   - The same directory also holds the rootless Podman API socket, which `controllerPaths` (`config.go:171`) already lists as a path no sandbox may see.
3. **A state directory not made yet, reached through a symlinked parent.**
   - **Input:** `--state-dir <base>/link/new-state`, where `link` points to `<base>/real`, with `--adapter <base>/real/adapter`.
   - `EvalSymlinks` fails on the missing directory, so the unresolved path is compared. `Start` then creates the state directory inside the adapter's directory, which the jail binds.
   - Nothing checks again later: `runnerOf` resolves the adapter but does not rerun the check.

It also accepts an adapter that is a directory. That case fails closed at exec, so it is not part of this finding.

**Fix:**
- Build the list of paths to keep apart from `controllerPaths()` plus the home (`home()`), `/run`, `/var/run`, `/sys`, `/etc`, `/proc`, `/dev` and `/tmp`, refused in either direction. Or invert the rule: allow only a directory under `/opt` or `/usr/local`, or an operator-named install root.
- Resolve the state path by its longest existing prefix. Or call `adapterApart` again in `runnerOf`, after `Start` has made the state directory.
- Require a regular, executable file.
- Better still, once #373 lands, bind exactly `sandbox.AdapterClosure` rather than a directory.
