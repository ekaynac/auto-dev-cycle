### High

**H1. The layer's type check has no deadline, ignores ctx, and checks a file set that main never checks: one 60-byte file can stall the guard for as long as it likes.**
- **Where:** `integrity_out2.go:117-121` groups the files of every gate platform under one package name. `integrity_out2.go:141-142` calls `conf.Check` directly, not `r.typeCheck`.
- **Main's rule is different.** Main type-checks each platform's files apart ("a name split by platform (x_amd64.go) is that platform's", `integrity_go.go:289`), and it ends every check by `listEnd`.
- **Work charge:** only file bytes are charged (`:136`). The real cost of the check is not bounded at all.
- **Probe** (`slow/` is untested):
  - The base has `slow/a.go`, an alias chain `A0 = struct{ v int }`, `Ai = struct{ a, b A(i-1) }`.
  - The base also has `slow/b_amd64.go`: the same chain `B…`, and `type Q = Bn`.
  - The candidate adds `slow/g_arm64.go`: `type Q = An; var _ = An(Q{})`.
  - Each platform alone is cheap and type-correct. In the union, `Q` is `Bn`, and the conversion runs a type identity check that grows as 2^n.
- **Results:**
  - main: n=27 accepted in 70 ms; n=29 in 70 ms.
  - head: n=27 accepted in 4.22 s; n=29 in 16.14 s, so each added line doubles the time. Extrapolated, n=40 takes about 9 h.
  - With a 3 s ctx: main returns in 60 ms; the head returns after 16.5 s.
  - `Accept` calls the guard synchronously, so the controller stalls with it.
- **Smaller case:** even without the union, the re-check runs after main with no time bound. The guard's 5-minute invariant (`listEnd`) no longer holds.
- **Fix:**
  - Type-check each platform's own file set with that platform's typer, as main does, and merge the counts per key (max).
  - Also run the check under a deadline. Past it, give the stop warning.

**H2. The re-check loads packages into main's typer that main never loaded on that platform. A check that passes the deadline poisons later guard runs.**
- **Where:** `integrity_out2.go:126` (the `platforms[0]` typer) and `:141` (`Importer: ty`). `ty.Import` calls `r.typeCheck`, which abandons the check at `listEnd` and raises the global `abandoned` count (`integrity_types.go:531-578`).
- **Probe** (`maxListTime` set to 40 s on both trees):
  - The base has `only/a.go` (two 40-level chains) and `only/s_amd64.go` (`var _ = A40(B40{})`).
  - The candidate adds `zzz/z_arm64.go`, which imports `example.com/m/only`.
  - On main, `only` is imported only by the arm64 typer, where it is cheap. The amd64 typer never loads it.
  - Run 2 is an ordinary new file, `tool2/x.go` (`func F() {}`).
- **Results:**
  - main: run 1 accepted in 70 ms; run 2 accepted in 50 ms.
  - head, run 1: 40.04 s (it waited until `listEnd`), then only the stop warning ("stopped at its work bound", which is not the cause).
  - head, run 2: **blocked** by main's stream: "unverifiable: the guard failed (1 type check(s) abandoned by an earlier guard run … still running)". This stays true while the abandoned check spins, for hours at n=40.
- **Why it matters:** this is a later run in which main accepts and the head blocks. The layer changes main's verdict outside its own run.
- **Fix:**
  - The per-platform sets of H1 import only what main already imported on that platform.
  - In addition, wrap the importer: a package that is not in `ty.pkgs` or `ty.listed` gives an import error and marks the directory incomplete (the stop warning). It never starts a new load.

**M2. An external test package is checked without its package's test files, so values from `export_test.go` are silent.**

- **Probe:**

**M3. A var spec whose binding changes escapes both signals.**
- **Where:** `integrity_out2.go:59`. A var spec's references are keyed `"package level"`, so a new binding moves no reference. `outBodies` (`:232`) compares only bindings that both versions have.
- **Probe:**
  - Change `var parse7 = func(){ fs := flag.NewFlagSet(…ExitOnError); _ = fs.Parse(nil) }` to `var parse7, _ = func(){ … Parse([]string{"-h"}) }, 0`.
  - The same with `fmt`: `var hello = func(){ fmt.Println("a") }` becomes `var hello, _ = func(){ fmt.Println("b") }, 0`.
- **Results:** silent on both trees. The control row (the same change without the blank name) warns at the head ("var parse7").
- **Note:** renaming the var has the same effect.
- **Fix:** key a var spec's text and typed references by its binding (`where = bind`), as functions are keyed. Then a reshaped spec moves its references, and the reference warning fires.

**M4. A method value rebound inside `init` is silent (r3 #7 in r3 #4's place).**
