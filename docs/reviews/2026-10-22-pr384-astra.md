2. **Medium — Repeated namespace copying adds uncharged superlinear work.** `internal/accept/integrity_helpers.go:63`

   **Input:** A test file has a 100,000-character valid package identifier and 10,000 small, uniquely named empty helpers. Compare a comment-only change.

   Each helper key copies the entire package name. The retained keys alone therefore approach 1 GB per platform scan, despite a source file of only a few hundred kilobytes. Charging AST nodes does not charge these copied bytes or the repeated long-key hashing. An identifier of length *n* with *n* declarations produces Θ(n²) key bytes.

   Results remain deterministic, but the added work is not generally linear or fully charged.

   **Fix:** Store the package/platform namespace once and key declarations within it by their short identities. Charge materialized key and diagnostic bytes, with cancellation and bound checks.
