### 2. Is 12c-3 unreachable? Yes.
For a gate's input to carry an attempt, there would have to be a tree-kind result recorded under an attempt on the gate's producer. Three things rule that out:
- `graph.Candidate` wires the gate only on accept's tree, and `wiring.go:173` lets a gate take only `ResultKindTree`.
- An accept node's only result kind is a tree (`internal/graph/lifecycle.go:51`).
- Accept is a `ControllerRun` kind, recorded with no attempt. Only `reconcile.Placed` (build) and review nodes are placed; `placer` refuses any other kind (`internal/daemon/place.go:175`). So no lease, and hence no attempt, exists on an accept node.

No M1 template creates the integration or rebase nodes that also produce trees. The check is defence in depth, and the PR states it as such.
