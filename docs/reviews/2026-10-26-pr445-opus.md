### 2. Can a credential, the canary or an acceptance path escape? Only O2 (a path, on a refusal, to the operator’s own stderr).
- **Credentials:**
  - They travel only fd 3 → `caller_cred` → `live_cred` → `clean_exec` (exported by builtins, environment checked).
  - `known` and `scan` get them on stdin. `root_secret_scan` passes them on stdin through `podman unshare`.
  - `credential-env`’s output holds names only.
- **The canary:**
  - It is read from the 0600 file by builtins. `out/canary` is 0600 under `umask 077`.
  - `adc dev scan` takes it as `--canary FILE`, a path, and `grep` gets it as `-f -`, on stdin.
  - Every `--print-forms` form is passed to `known_text`, so `die` and `excerpt` redact it before they cut.
  - Hit lists are paths, redacted by adc.
- **Acceptance store paths:**
  - They appear only in the driver’s own argv. A child sees only `$work/acceptance/N`: through `cat <`, `sha256sum <` and `/dev/fd/3`.
  - **Exception (O2):** given `--acceptance FILE` without `=`, `name="${a%%=*}"` is the whole path, and the refusal prints it. Probe: `could_not_run: --acceptance /tmp/…/STORE-PATH-acc.go: REPO_PATH=FILE, FILE a readable file`.
- **`--own-digests`:**
  - `ownDigest` is consulted only on a hit. It opens the file the walk’s `Lstat` saw (`regularfile.Check`).
  - A captured request that carries the acceptance is wrapped JSON, so its digest differs and it is never exempt.

### 3. The closure-chain checker and the rehearsal’s confinement: sound
- **The chain rule:** the closing review is `bench.closure.node`, of kind review, its closure a go. Its round must be the last build round, every round 1..r must have a build, and the expect is checked on round r only.
- **The test rows:**
  - "a repaired candidate, two rounds" passes.
  - These fail: no closure; a closure naming a non-review; a closure that is not a go; round r’s gate found; a closure of an earlier round; a missing build round; an uncaptured reviewer call; no reviewer call.
  - A closing review with no `round` fails on `chain !== last`.
- **The card’s gate rule:** a repaired run’s round-1 gate stays `completed` (supersession retires reviews, `graph/supersede.go`), so `gates.every(completed)` does not fail a repaired candidate.
- **Confinement:**
  - `ADC_QUALIFY_OUT` is the scratch prefix’s `records/` (`internal/qualify/live_test.go:87`). Rehearsal mode needs `lib/adc/rehearsal` in the prefix and forces `--bench work`.

  - `untouched()` compared the repository’s qualification fixtures and `dist/*/lib/adc`; they were unchanged after my run.

### Findings
- **B1** (BLOCKING, fail-closed; checkpoint (a) cannot run): the live route reads `$lib/fixtures/m1/issues/$N/task.json`, and `adc dev bench record --root "$lib" --fixture fixtures/m1/issues/$N` reads the same directory (`installed-cycle.sh:199-200`, `cycle-live.sh:173`). Neither file comes with the release.
  - **Why it is missing:** `scripts/dist-adapters.sh`’s `committed` list never packages `fixtures/m1/issues`, and `test/installcheck/dist_test.go:603` asserts that it is absent (a #307-era stub-only rule).
  - **Probe:** `make dist`’s `dist/linux-arm64/lib/adc/fixtures/m1/` holds no `issues/`. On a prefix installed by `scripts/install-check.sh`, `installed-cycle.sh $P --routes live --project repo --issue 170 …` printed `could_not_run: no issue 170 in …/lib/adc/fixtures/m1/issues, or no auto-dev-cycle profile` with exit 2.
  - **Why the rehearsal misses it:** it writes `fixtures/m1/issues/999` into the scratch prefix itself.
  - **Fix:**
    - Add `fixtures/m1/issues` to `committed` (the whole directory: the bench digests it).
    - Move it in `dist_test.go` from the "not packaged" list to the packaged checks, and add `fixtures/m1/issues/170/task.json` to `install-check.sh`’s required files.
    - Optionally, have the rehearsal assert that the release already carries `fixtures/m1/issues/170/task.json` before it adds 999.
- **O1** (OBLIGATION, Medium; an operator environment that fails closed): `scripts/installed-cycle-rehearsal.sh:132` runs bare `go test`. The Makefile builds with `$(GO)` (`$(GOROOT_PIN)/bin/go`, the `make toolchain` layout), so on a host without Go on PATH (this one) the rehearsal dies with "qualification run 1: … go: command not found" after a full dist build.
  - **Fix:** in the recipe, pass `GO="$(GO)"` and use `"${GO:?}" test …` in the script, or prepend `$(GOROOT_PIN)/bin` to PATH in the recipe.
- **O2** (OBLIGATION, Low): `cycle-live.sh` `live_acceptance`, for an `--acceptance` argument without `=`. `name="${a%%=*}"` is then the store path, and the refusal prints it to stderr (probe above). This contradicts the header’s "no output names them".
  - **Fix:** check `[[ "$a" == *=* ]]` first, with a message that names no part of `$a`.
