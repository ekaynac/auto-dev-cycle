### High

**H1. The decoder route is closed only when the holder's address is the call's own argument. One interface-typed variable between them reopens it: 0 blocks, 0 warnings, and TestAdd passes end to end exactly as the builder's `json.Unmarshal` row did at 35b37c3.** Outside P14e-1's promise (entry 82 (b) is the candidate's own reflection; this form has none), so not blocking; record it.
- **Where:** `internal/accept/integrity_types.go:598` (the rule fires on `reaches(info, x, id, carries)`, which reads the static type of each argument and of an `any(…)` operand only); `:641-649` (`carries` is false for every interface type).
- **Input** (`pkg/calc_test.go`, the builder's row with one line added):
  ```go
  func TestAdd(t *testing.T) {
  	var h struct{ T *testing.T }
  	var a any = &h
  	_ = json.Unmarshal([]byte(`{"T":{}}`), a)
  	if Add(1, 2) != 3 {
  		h.T.Error("add")
  	}
  }
  ```
  `a` is `any`, so `carries` is false; `h`, `&h` and the type `struct{ T *testing.T }` hold nothing by value; `encoding/json` is not in S. Same result for `args := []any{&h}; json.Unmarshal(d, args[0])`, for `fmt.Sscan`-style spreads (`xs...` of `[]any`), for an own `func target() any { var h holder; return &h }`, and for `var p *testing.T; var a any = &p; json.Unmarshal([]byte("{}"), a); p.Error(…)` (json allocates the T behind a nil `*testing.T` too). `gob.Decoder.Decode`, `xml.Unmarshal` take the same path; `binary.Read` and `fmt.Sscan` cannot fill a struct pointer, so they are not viable.
- **Why the rule cannot be widened as is:** counting every outside call with an interface-typed argument would fire on `t.Errorf`, `fmt.Println` and `errors.Is`.
- **Fix (P14e-2, or here if the size allows):** move the fact to the value, not the call. Define `fillable(t)`: a data path to a testing struct through pointers, arrays, slices, maps, chans and **exported** struct fields only, no signatures, excluding `*testing.T` itself (the decoders of std set exported fields only, and a func field cannot be decoded). Then the existing rule at `:611` fires on any value or unstarred type expression that is `fillable`, as it already does for `holds(t, false)`. That catches `struct{ T *testing.T }` at its declaration, `&h`, `&p` (`**testing.T`), `[]*testing.T`, `new([]*testing.T)`, and exempts `fixture{t}` and `&fixture{t: t}` (unexported `t`: every one of this repository's 14 fixtures). Residual to record: a holder with an exported `*testing.T` field that already exists in the base, reached without a new declaration or `&`.
- **Rows:** the input above; the `**testing.T` variant; the `[]any` spread.
