### Medium

**M1. A plain-data call still counts its arguments: a new false block against main, not stated.** `internal/accept/integrity_skips.go:206-227`
- **Cause:** when a held call's result is plain data, the callee is dropped (round 2's M1), but the arguments (`:224`) and the receiver (`:220`) are still walked as held values. A plain result cannot hold a function, whatever its arguments were.
- **Inputs:** each base declaration below, with the test edit shown, blocks with "a test skipped (a skipping helper used)". Main accepts both.
  - `func register(f func(*testing.T)) bool { return f != nil }` and `var registered = register(requireDocker)`; the test adds `if !registered { t.Fatal("r") }`. This registration-flag pattern is common.
  - `var count = len([]func(*testing.T){requireDocker})`; the test adds `t.Log(count)`.
- **Why it is not stated:** the residual's false-block line covers a call whose result "can hold a function". These results are a `bool` and an `int`.
- **Fix:** when `plainData(TypeOf(call))` holds, return false without walking the callee, the receiver or the arguments. A function the call stores elsewhere is M2's stated class either way. Add both inputs as clean rows, and a mutation (arguments walked).

### Low

**L1. The count rows catch only quadratic work that charges itself.** `internal/accept/integrity_skips_test.go:312-320`
- **Cause:** a counter cannot see a loop that does not call `charge`, so a regression that adds such a loop passes both rows. The real round 1 and round 2 shapes pass, as shown above.
- **No deterministic count catches an uncharged loop.** That guarantee has to come from the rule "every loop over references, values or copies charges", checked in review.
- **Fix:**
  - Say so in the rows' comment.
  - Optionally keep one coarse timing backstop beside the count: round 2's same-run ratio, with a loose threshold such as 20×, logged rather than failed. The count stays the assertion.

**L2. The stated false block for a held call result covers the common case.** `internal/accept/integrity_skips.go:207`
- **Cause:** the scan resolves no imports, so a result type like `*httptest.Server`, `*sql.DB` or `*exec.Cmd` is invalid. Every such held result therefore counts its callee.
- **Effect:** M1's original pattern still blocks when the server type is imported, as it usually is (probe: `srv = requireHTTP(t)`, the test reads `srv.URL`). The residual states this ("a type the scan cannot resolve"), so it does not block review.
- **Fix:** none needed for this PR. If it shows up in practice, check the callee's declared result syntax: a `*pkg.Name` from another package cannot hold a same-package `func(*testing.T)` except through an interface field.

**L3. `maxSkipWork` can be passed within `maxRead`, and the residual says it cannot.** `internal/accept/integrity_skips.go:40-45`
- **Cause:** the comment's arithmetic ("a run's reading stays under len(platforms) × maxRead") leaves out two things:
  - both versions are scanned on each platform, while a blob unchanged between them is charged to `maxRead` only once;
  - a value assigned inside `init` is read twice: as part of the `init` body, and again as the variable's value.
- **Input:** scaled down, with `maxRead` = 256 KiB and `maxSkipWork` = 4 × 2 × 256 KiB = 2 MiB. A base test file of 253 KB holds `var v func()` and `func init() { v = func() { a0 := 0; a1 := a0; … a14500 := a14499; _ = a14500 } }`. The candidate is a comment-only change to `pkg/calc.go`.
  - **Head:** charges 2,259,148, and every test file of `pkg` is "unverifiable: skipping helpers past the guard's bound".
  - **Main:** accepts.
  - The skip layer's work here is about 8.9× the package's bytes, against the 8× the bound allows.
- **Full scale:** [INFERENCE] this needs about 60 MiB in one package (16 files at `maxFile`), which other limits may stop first.
- **Fix:** do one of these:
  - set the bound to `16 * len(platforms) * int(maxRead)`, and correct the comment: two versions, a value read twice, and copy steps of at most about one per source byte;
  - stop charging a value whose source range lies inside an already-charged body.

  Then drop "maxRead binds first" from the residual, or keep it only with the corrected arithmetic.

**L4. M2's residual omits a plain local copy.** The PR body, round 3 "Residual"
- **Input:** `var holder5 struct{ f func(*testing.T) }` and `func init() { f := requireDocker; holder5.f = f }`; the test adds `holder5.f(t)`. It is accepted on head (main accepts too), so this is a stated miss, not a regression.
- **Fix:** reword the residual: "a helper reaching a package variable through a local variable (a copy, a pointer or a range variable) or a parameter".
