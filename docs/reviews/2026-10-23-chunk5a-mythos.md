### High

**H1. `end` never tries to end a lease-only open entry, so an attempt sealed with its lease still active is stuck admitted at runtime, with a card that promises a retry.** `internal/daemon/sweep.go:241` (the guard `still && !before.Lease`), `:257` (the same entry re-read as `errNothingEnded`); `internal/lease/wiring.go:88-90` (the open index drops an attempt's key at `sealed`/`completed`, keeps a lease's until `settled`/`released`).
- **Cause.** `endOne` is two steps: seal, then `endAttempt` (attempt `completed`, then `endActive` on the lease). The open index drops the `att_` key as soon as the attempt is sealed, so once step one lands and step two fails, the unit's open index holds only `lea_…`. `lease.Unended` then returns the lease (`Lease: true`), and `end` skips `leftAt`/`endOne` entirely for a lease. The re-read finds the same entry, counts a failed try, backs off and logs once. Every later try does the same: no command is ever issued, so "once the fault clears" nothing changes.
- **Input.** `candidateRun`, then the review's own run: `sealWith` succeeds, and `endAttempt`'s `lease.completed` command fails once (a busy store, a full disk; or make `endActive` fail once in a test as `unsealedReview` makes the seal fail). State: review node `completed` go, attempt `completed`, lease `active`. Observe: `CandidateGo` true, `EndingOf` returns `ErrEnding{Lease: true}`, `Ending` decided. Every due try: zero commands, `errNothingEnded`, the card `ending_blocked {unit, "the lease did not end"}`, column `done_candidate`, task still admitted, the next task never admitted. Only a restart's `endLeft` ends it: `leftAt` does cover "sealed or completed with its lease active or settling", but at runtime `end` only reaches `leftAt` by an attempt id. The same shape is reached from `End`'s own first try when the seal lands and the lease end fails inside `endOne`.
- **Why High.** A task left stuck with no hold is at least High under the floor. The card is visible, but its text ("the controller retries its end with backoff") and the promise ("the runner ends the named open entry") are both false for this entry: there is no retry, only a counter. The promise's own fixture for "the seal never lands, then does" passes only because the attempt stays `finishing`, so its key stays `att_`.
- **Fix.** Reuse what exists; add no third rule. In `end`, when `before.Lease`: `lease.LeaseOf(before.Entry)`; if `l.Attempt != nil`, `leftAt(*l.Attempt)` then `endOne` (its `Completed` branch is already `endActive`; its `sealed` branch `endAttempt`); if `l.Attempt == nil` (a granted lease that never started, e.g. a revoked task whose launch was never decided), `endActive(ctx, l.ID, lease.LeaseEvent{Kind: lease.Revoked, Reason: "no_result"})`, the end `endAttempt` already uses. Add two rows beside `TestADecidedCandidateEndsAtRuntime`: the seal lands and the lease end fails once (the task ends at runtime on the next due try); and a revoked task with a granted lease and no attempt (ends, then abandoned).

### Judged

1. **`task.done` while something runs, or without a go.** No, by the loop: `Done` is decided only when `Endable` passed in the snapshot, and `DoneTask` reruns `endable` in its own transaction (claimed or held first, then every unit's open index). A moved task version is `ErrStaleExpectedState` from the store and decided again (`TestTheLoopEndsADecidedCandidate`). Without a go: not by the loop; by a direct caller, yes (L1), with no reachable input today. `Abandon` wins over `Done` in `Decide`.
2. **Stuck with no log, no card state, no retry; spin; faster than backoff.** H1 is logged and carded but its retry is empty, so the task is stuck until a restart. No spin: `End` returns true only when it started a try, the pass nudges once, and the next pass finds the node live or its `next` set, so `errNothing` and no nudge. Not faster than backoff: `next` is set under the lock before the try's goroutine releases `live[node]`. `ErrNotEndable` refusals are logged once per action and subject with a stable message (node and attempt ids).
3. **Reads.** `ending_blocked` is a `UnitID` and a two-value enum, pinned by `TestEndingCausesAreTheSchemas`, `schemas/api_test.go`'s "an ending blocked by an error text" and the row that plants `/var/lib/adc/blobs`. `ErrEnding.What` and `errNothingEnded`'s text reach the daemon log only. `noLeak` now reads every CLI read, the stream included, and the red-canary gate case.
4. **Second implementations.** M1 (the backoff), L2 (the decided argument), L3 (the id alphabet). `leftAt` is a true extraction of `endLeft`; `Repairable` and the board both read `OfLastRound`/`CandidateGo`.
5. **Regression.** None found. `Decide` puts `Ending` before `Abandon`: for a revoked task with an attempt the runner is still running, `End` returns false (`start` sees the node live), the same silence main had with its stale `Abandon`. `CandidateGo` equals main's board rule except for 6d's repair rounds, which main showed wrong. `Repairable`'s new `OfLastRound` is the old `round[src.Producer] == lastBuild` with the same map.
