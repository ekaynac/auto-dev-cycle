## Review of #121 (Astra, 2026-10-06)

Verdict: GO with changes

No Critical/High findings. Reviewed `408102b`, the PR description, and the approved plan on `origin/main`.

1. **Private socket — PASS, with a concurrency caveat.** Creation is 0600 without chmod; binding uses the checked, held directory descriptor after startup checks. A directory-swap test passed. The mutex serializes binds, **not other goroutines’ file creation**. This is acceptable for the current startup sequence, but not a generally safe concurrent binding API. The shared bind can temporarily widen an inherited restrictive umask. [Linux umask documentation](https://man7.org/linux/man-pages/man2/umask.2.html).
2. **Shared socket — CHANGES RECOMMENDED.** Default-off configuration, descriptor checks, 0660 creation and group assignment before listening are correct. Inherited ACLs can bypass the intended group restriction; see M2. Omitting ancestor checks is acceptable for credential protection once PR 4a checks kernel peer credentials against an independently expected daemon UID before sending credentials. Ancestor replacement can still cause unavailability.
3. **Stale sockets and removal — CHANGES RECOMMENDED.** Type/owner checks and descriptor-relative operations are sound, but arbitrary dial failures do not establish staleness; see M1. Shutdown preserved a replacement file in my additional test. Check-and-unlink is not atomic against same-UID/root writers, which remain trusted under this posture.
4. **Peer credentials — PASS.** Private connections require the daemon UID before request processing; listener kind and kernel UID reach the request context. Shared connections retain bearer authentication for state access.
5. **Limits, version and shutdown — PASS with a header-bound correction.** Timeouts, known-length upfront 413, `MaxBytesReader`, authentication-slot lifetime and SSE deadline handling are wired correctly. Unknown-length bodies are limited when read. Version also exposes binary name, Go version and platform, but no state, paths or credentials. Shutdown cancels streams, drains, force-closes when necessary, removes sockets, then closes the store. The effective header ceiling exceeds 16 KiB; see L1.
6. **Configuration errors — PASS.** Fixed-text `ErrConfig` and exit 64 are acceptable for invalid startup configuration; these are usage/configuration failures rather than command outcomes requiring registered reasons.
7. **Per-listener/per-UID quotas — PASS.** Each bind creates independent connection and verification pools with the stated defaults. Streams retain connection slots; verification slots are released after authentication; excess connections receive 503 before request reads. One listener cannot consume another’s slots, although CPU and memory remain shared. Nil `Slots` is used by tests/fixtures and is **unreachable through current production daemon construction**; changing it to fail closed is optional defensive hardening, not a merge requirement.
8. **Size — ACCEPTABLE under the cohesive-package exception.** The actual final diff contains **609**, not 689, non-test added-plus-deleted lines. Admission, quotas and server lifecycle form a reviewable unit; no split is required. Correct the PR’s count.
9. **Tests — PASS, with a guard-coverage gap.** CI and race tests passed. Removing either the private admission predicate or its call-site check turned tests red. Removing the stale-owner predicate turned its unit assertion red, but bypassing ownership at the cleanup call site survived; see M3.

## Review of #121, round 2 (Astra, 2026-10-06)

Verdict: GO with changes

No Critical/High findings. Reviewed `693a834` and the full PR diff; the **661 non-test lines** are justified under the cohesive-package rule.

- **M1 — Fixed.** Only `ECONNREFUSED` permits cleanup; type, owner, device and inode are rechecked. Full-backlog and datagram regressions pass and fail when the guard is removed.
- **M2 — Fixed for POSIX ACLs; portability gap remains.** Descriptor-based default-ACL checks and the socket access-ACL check work. Both guard-removal mutations fail their tests.
- **M3 — Fixed.** The ownership regression exercises `clearStale`, preserves the foreign-owner path, and removes the same socket with the correct expected UID.
- **L1 — Partially fixed.** Fresh-connection tests pass, but pipelined requests can exceed 16 KiB.
- **Optional nil Slots — Fixed.** Nil denies admission; removing that guard fails its regression. `Unlimited()` has no daemon-listener call path.

**Remaining findings, by severity**

1. **Medium — Unsupported POSIX ACL attributes do not establish absence of ACL enforcement.**  
   `internal/daemon/socket.go:152` treats `ENOTSUP` as no ACL. NFSv4 can enforce native ACLs while POSIX ACL queries return `EOPNOTSUPP`; some kernel versions returned `ENODATA`. Consequently, these checks do not establish the claimed group-only policy across arbitrary filesystems. This is a portability finding; I did not reproduce an NFS-mounted exploit. [Linux NFS discussion](https://lkml.indiana.edu/hypermail/linux/kernel/2309.1/00398.html), [NFSv4 ACL/mode requirements](https://www.rfc-editor.org/rfc/rfc8881.html#section-6.4.1.1).

   **Fix:** enforce a supported-filesystem/ACL policy on the held descriptors. Refuse unknown ACL semantics; accept `ENOTSUP` only where mode-only enforcement is established. Add unsupported-ACL regression coverage.

2. **Low — L1 still permits oversized pipelined headers.**  
   `internal/daemon/server.go:89`: I sent a normal version request followed immediately by a **16,964-byte** request on the same connection. Both returned **200**. Go resets its underlying read budget while bytes for the next request can already be buffered. The subtraction therefore does not provide an exact per-request bound.

   **Fix:** enforce the bound accounting for buffered carry-over, and add a raw pipelined regression. The existing test at `internal/daemon/server_test.go:249` detects removal of the subtraction but misses this case.

3. **Low — Run-directory `g+x` can describe the ACL mask rather than the configured group’s access.**  
   `internal/daemon/server.go:76`: a real access ACL with owning-group permissions `---`, a named-user entry `r-x`, and mask `r-x` produces mode `0750` and passes startup. Ordinary configured-group members cannot traverse it.

   **Fix:** reject extended run-directory access ACLs, or validate their effective group-search permissions. Add this configuration case. This is an availability/configuration issue, not wider socket admission.

4. **Low — Two guards lack independent regression coverage.**  
   `internal/daemon/socket.go:125` and `internal/daemon/socket_test.go:334`: the **entire daemon suite remains green** when either the final stale-path recheck is disabled or default ACLs are allowed specifically on the state directory.

   **Fix:** add a deterministic replacement between dial and recheck, plus a state-directory default-ACL case. A minimal default ACL would avoid the socket’s extended-ACL check masking the latter regression.

**Other requested checks**

- A POSIX **access ACL on the run directory cannot silently grant directory write access** past the current mode check: named-user/group permissions are bounded by the ACL mask represented in the group bits. Likewise, state-directory mode `0700` masks non-owner access. Ordinary unrelated extended attributes do not grant POSIX access. [ACL semantics](https://man7.org/linux/man-pages/man5/acl.5.html).
- **ACL changes after validation remain possible for the owner or a privileged process.** An inherited extended socket ACL is caught before listen; changes after that check are not monitored. Unprivileged group members cannot perform those ACL changes. This is the existing trusted-owner boundary, not an additional group-peer bypass. [ACL modification permissions](https://man7.org/linux/man-pages/man1/setfacl.1.html).
- **Normal crash/restart remains supported:** a leftover stream socket without a listener returns `ECONNREFUSED`; the stale-replacement test passes. Permission errors, resource exhaustion, timeouts, or a still-live listener can prevent startup, appropriately preserving an uncertain path. Correct the underlying condition and retry rather than widening deletion.
- **`api.Unlimited()` is reachable in a shipped executable:** `adc dev fixtures --contract` reaches `internal/fixtures/stream.go:137`, which starts the temporary loopback fixture server. Production daemon listeners always construct bounded pools. Calling it “test-only” would be inaccurate.

**Verification:** `make ci` passed; shellcheck was unavailable and skipped by the Makefile. The requested CGO race tests passed for daemon, API and fixtures using the pinned Go executable. The real ACL test ran without skipping. All six stated red-proofs were independently reproduced using memory-only overlays. Repository files remain unchanged.
