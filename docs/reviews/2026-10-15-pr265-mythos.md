**H1. A container of `*testing.T` escapes "laundered", and the value-making reflect list misses `MakeSlice`, `Append` and `Copy`. Entry 82 (b) passes in a package with tests, with no block.**
- **Where:** `internal/accept/integrity_types.go:574-598` (`launders` and `ptrHolds` strip pointers, then call `holds(elem, false)`: a slice, array, map, chan, struct field or func result holding `*testing.T` is not reached); `:537-540` (the `factMakes` list).
- **Input** (`pkg/calc_test.go`, a package with tests):
  ```go
  package pkg

  import (
  	"reflect"
  	"testing"
  )

  func TestAdd(t *testing.T) {
  	c := make(chan any, 1)
  	c <- t
  	v := <-c
  	p := reflect.MakeSlice(reflect.SliceOf(reflect.TypeOf(v).Elem()), 1, 1).Index(0).Addr()
  	s := reflect.Append(reflect.MakeSlice(reflect.SliceOf(reflect.TypeOf(v)), 0, 1), p).Interface().([]*testing.T)
  	func(t *testing.T) {
  		if Add(1, 2) != 3 {
  			t.Error("add")
  		}
  	}(s[0])
  }
  ```
- **Why nothing fires:** `MakeSlice` makes a zero `testing.T` and `Append` places its address in a `[]*testing.T`; neither is in the `factMakes` list. The assertion target `[]*testing.T` is not a pointer, so `ptrHolds` is false, and `holds([]*testing.T, false)` stops at the pointer element. The type expression `[]*testing.T` is not held either (`:544`). `v` comes out of a `chan any`, so `reaches` sees `any`, and the text rule's taint (`tvals`) is not carried through a send. The old `ptrTo` wants a star. The only output is the class-1 "reference into S" warnings for the reflect calls, the outcome #226 called a failure for 82 (b).
- **Same result:** `.(map[int]*testing.T)`, `.(struct{ T *testing.T })`, `.(*holder)` with a pointer field, `case []*testing.T:`, `as[[]*testing.T](x)`, and `*(*[]*testing.T)(unsafe.Pointer(…))` in an untested package (the conversion rule at `:523-527` has the same gap, and the unsafe import only warns there).
- **Fix:**
  1. In `launders` and in the conversion rule, replace `ptrHolds(t)` with `holds(t, true, nil)`: the asserted, switched, converted or instantiated type reaches a testing struct at any depth, through pointers and containers. Keep the interface check. `reaches` already uses this predicate.
  2. Add to `factMakes`: `reflect.MakeSlice`, `MakeMap`, `MakeMapWithSize`, `MakeChan`, `MakeFunc`, `Append`, `AppendSlice`, `Copy`, and `(reflect.Value).Convert`, `Grow`, `Slice`, `Slice3`.
  3. Rows: the input above; `.(struct{ T *testing.T })`; `as[[]*testing.T]`; a `MakeSlice`-only source. Mutations: "launders without containers" and "MakeSlice not listed". Rerun the replay: `holds(t, true)` in `launders` may block a legitimate `.(*fixture)` in it.

**H2. The guard panics on a type assertion whose operand is not an interface. One line of candidate source crashes the process instead of blocking.**
- **Where:** `internal/accept/integrity_types.go:502` (`launders(info.TypeOf(x.Type))`) and `:594` (`types.Unalias(t).Underlying()` on a nil `types.Type`).
- **Cause:** `go/types` leaves `e.Type` of a `TypeAssertExpr` unvisited when the operand is invalid, a type parameter or not an interface: it reports the error and jumps to `Error` before `varType(e.Type)`. The `Error` handler in `typed` (`:436`) swallows the error, `info.TypeOf` returns nil, `launders(nil)` reaches `ptrHolds(nil)`, and the method call on the nil interface panics. Nothing in `Accept` or the guard recovers (`recover` appears only in `integrity_py.go`).
- **Input** (`pkg/x_test.go`):
  ```go
  package pkg

  import "testing"

  func keep(t *testing.T) { _ = t.(*testing.T) }
  ```
  The gate would refuse to compile it, but the guard runs first. In the test harness this crashes the `go test` process; wired into `adcd` it crashes the controller on every retry of that candidate.
- **Fix:** `launders` and `ptrHolds` return false for a nil type. Consider, in `typed`, recording the first error that is not a redeclaration (`redeclared`, `other declaration of`, `already declared`) as `untyped`: a package the gate cannot compile is then unverifiable, which removes the "facts from a partially typed package" class as a whole. Row: the input above, expected a block or `unverifiable`, never a panic.

**H3. A root module path that is a standard-library path blinds the type facts. The guard types the candidate's root package as `testing`; the gate uses GOROOT's.**
- **Where:** `internal/accept/integrity_types.go:247-259` (`local` treats every path under `ty.mod` as own), `:228-235` (the module path is taken from `go.mod` with no check).
- **Input:** `go.mod` is `module testing`, plus the root file `testing.go`:
  ```go
  package testing

  type T = tee

  type tee struct{}

  func (*tee) Error(...any) {}
  func (*tee) Fatal(...any) {}
  func (*tee) Helper()      {}
  ```
  Every test file's `import "testing"` is then own to the guard: `local("testing")` gives the root directory, and `typed` checks the test against this package. `*t` is a `tee`, so `c := *t; use(&c)` has no fact, and `holds` never sees a `T`. The go command resolves a standard-library import to GOROOT before the main module, so the gate compiles the tests against the real `testing`. Only the old text rules decide.
- **Status:** the Go profile protects `go.mod` in production, so this needs a base whose module path is dotless already. The brief's premise is that the candidate controls `go.mod`, and the PR promises "real types or unverifiable" without relying on the profile. The lead may downgrade this to Medium if the profile is part of the guard's boundary.
- **Fix:** in `local`, a path whose first element has no dot is never own (the go command's rule for the standard library), so it goes to `go list` and resolves as the gate does. Or fail closed in `typer`: a module path without a dot in its first element sets `why`. Row: the input above, expected a block.
