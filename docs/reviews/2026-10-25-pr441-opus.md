### 5. The stub route: H1
**The probe** ran `--setup-only` on a fake prefix (the path `make ci`'s `installed-cycle-setup` runs), with `root=$P/victim private=1` exported and a file `victim/precious.txt`. The run exited 0 and **the victim directory was removed**.

**Why:** the driver initialises `stub`, `adcd` and `events` before `trap cleanup EXIT` (`scripts/installed-cycle.sh:164`, `:186`), but `root` and `private` only at `:253`, after `--setup-only`'s `exit 0` (`:244`) and every setup `die`. So `cleanup` reads the caller's values, and `sandbox_root_remove` runs `podman system reset` (when a `storage/` exists) and `rm -rf` on the caller's path.

**History:** this is pre-existing since D1 (#435, #438), and I missed it in both rounds. It is the same class as the Astra H1 this PR closes for the process handles.

### Findings
- **H1** (BLOCKING, High: data loss; the caller's directory removed by a run that exits 0):
  - **Fix:** initialise every variable `cleanup` reads (`root=""`, `private=0`, beside `stub`, `adcd` and `events`) before `trap cleanup EXIT` (`scripts/installed-cycle.sh:164-186`).
  - **Row:** run `--setup-only` and a setup `die` with `root` and `private` exported over a marker directory, and require the marker to survive.
  - **Audit:** check the rest of `cleanup`'s and the end-of-run reads for other inheritable names. `stub_cred` is only scanned, which is harmless.
- **M1** (OBLIGATION, Medium; the promise "refuses if anything outside the allowlist remains" fails open): `clean_exec` computes the remaining environment from bash's own view (`compgen -e`, `declare -Fx`; `scripts/lib/secrets.sh:97`). Bash cannot unset an inherited entry whose name is not an identifier (`ADC-SECRET=…`, a malformed `BASH_FUNC_x%%=…`), nor see it, but it passes such entries to the exec'd command, as my `env -0` probe showed.
  - **Fix:** check the environment the exec will get. Run a child (`env -0`, or `node -e` printing `Object.keys(process.env)`) in the cleaned subshell, compare its names with the allowlist, and refuse on any extra name.
  - Bash will still add `SHLVL`, so either allow it by name or `exec -c` is out. Keep the probe's cases as rows.
- **M2** (OBLIGATION, Medium; the process of review): H1 shows that "every process handle is initialised" was checked handle by handle, not by what `cleanup` reads. List `cleanup`'s inputs in its comment and pin them in a row, so the next variable `cleanup` gains is caught.
- **L1** (OBLIGATION, Low; for PR 2): `known_text` registers the raw text only, so an excerpt of a JSON output (`show.json`, an adapter's stderr) prints a JSON-escaped canary. When the live route registers its canary, register `cycle-expect.mjs --canary-forms`' forms, all of them, through `known_text`.
- **L2** (OBLIGATION, Low): the stub's `answers` check accepts an array (`typeof [] === "object"`, and an empty `Object.entries`), and answers any model's first user message, the builder's included. Require a plain object, and restrict the mode to the reviewer's model, so that a rehearsal map cannot steer a build.
