### Low

**L1. A sandbox layout main accepted can now be refused at start. OBLIGATION (state it).** `internal/daemon/config.go:134`, with `internal/sandbox/sandbox.go:95-97` and `ownDisk`
- **Cause:** with `lib/adc` among the forbidden paths, `Host.Validate` now refuses a configuration in two layouts:
  - a sandbox root that contains the release's `lib/adc`, or lies inside it;
  - a release whose `lib/adc` shares a device with `<root>/runs`.
- **How likely:** both layouts are unlikely, since runs must be on a filesystem of their own. But it is a start refusal that main did not have.
- **Fix:** state it in the body or the operator notes. The refusal's text should say that the release's `lib/adc` counts as a controller path.

**L2. A qualification derived at the start holds until the next start. OBLIGATION (state it).** `internal/daemon/config.go:267`
- **Effect:** records removed, or made stale by a reinstall, while adcd runs leave review as derived at its start. This matches how the registry and the adapter digest are read once per start, but it is not stated.
- **Fix:** state it in `reviewsAtStart`'s comment. Or state that a reinstall implies a restart, as the adapter-digest check already requires.

**L3. The start's qualification read is synchronous, with no context and no bound beyond `Check`'s. OBLIGATION.** `internal/qualify/qualify.go:166-216`, `:466`
- **Cause:**
  - `Load` reads `suite.json` unbounded and digests the whole suite directory.
  - `Check` re-reads every record (up to 1 GiB) once per registered reviewer.
- **Why it is only Low:** these are release files the operator installed, so this is not an attack surface, and today they are small.
- **Fix:** read the records once and check every route against them. Or bound `Load`'s reads as `Check`'s are.

**L4. The records directory's location is spelled in two places. OBLIGATION.** `internal/daemon/config.go:236` (`filepath.Join(lib, qualify.Dir, "records")`) and `qualify`'s `suiteDigest` skip (`"records"`)
- **Fix:** export the location from `qualify` (for example, `qualify.RecordsDir(root)`) and use it in both.
