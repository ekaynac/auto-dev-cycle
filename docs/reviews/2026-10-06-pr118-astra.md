## Review of #118, round 3 (Astra, 2026-10-06)

Verdict: GO with changes

No Critical/High findings. Both round-2 blockers are resolved; one non-blocking test gap remains.

- **Item 1 — PASS on data flow; coverage gap below.** The handler captures `Issued`, but returns only its public token record and hash. No reviewed path passes plaintext into persistence, logs, or errors. Submit failures return a zero `Committed`; replayed, refused, proposed, and invalidated outcomes suppress delivery. The file walker reads every state-directory file, including the live WAL before cleanup, and fails on read errors. Its exact-byte check is sound for those files at that moment—not proof against historical writes or encoded copies. The hash-only data flow supplies that protection.
- **Item 2 — PASS.** Generated ids/hashes are server-generated output, so excluding them from the request digest preserves N1. Action, input, and expectations remain covered. Serialized lookup returns a replay before invoking the replacement handler, preventing a second token; `Deliver` rejects that replay. `Deliver` checks disposition/replay flags only: callers must pair it with the successful Submit that recorded that same `Issued`.
- **Item 3 — PASS for ordinary printing, serialization, and reflection.** Reflection cannot traverse function captures; the new traversal test would expose the former `*string` representation. Formatting remains redacted, JSON marshaling `Secret` fails, and marshaling `Issued` excludes its private secret. Explicit `Reveal`, unsafe memory inspection, or a debugger accessing process memory remain outside this guarantee.
- **Item 4 — PASS.** N1/N2 behavior and tests remain intact, including committed-refusal prevention of adapter launch. The PR 2b insertion point remains before idempotency lookup; replay authentication itself is still deferred. Confirmed **342 non-test code lines + 22 documentation lines**, additions plus deletions.
- **Round-2 finding: scan-based non-persistence — RESOLVED.** Removing plaintext from store data eliminates reliance on scanning WAL writes, selected columns, or encoded copies.
- **Round-2 finding: reflection disclosure — RESOLVED.** The closure representation removes the reflectively reachable string.

**New finding — Medium, non-blocking:** [internal/identity/issued_test.go:79](/tmp/claude-1000/-home-mega/d7e41cde-3883-4e5c-8d98-04b890c5f4c4/scratchpad/wt-s9-2a/internal/identity/issued_test.go:79) scans only the first applied mint’s plaintext. Assert no delivery, no committed token on failure, and no plaintext in returned errors. Explicitly assert WAL presence so that coverage cannot silently disappear.
