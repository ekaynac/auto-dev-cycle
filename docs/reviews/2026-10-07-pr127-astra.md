**Medium findings**

- **#129 — Malformed credential responses expose bearer material in stderr.**  
  [internal/client/client.go:130](/tmp/claude-1000/-home-mega/d7e41cde-3883-4e5c-8d98-04b890c5f4c4/scratchpad/wt-s9-4b/internal/client/client.go:130) passes raw schema-validation errors through `answer`; [internal/cli/bootstrap.go:82](/tmp/claude-1000/-home-mega/d7e41cde-3883-4e5c-8d98-04b890c5f4c4/scratchpad/wt-s9-4b/internal/cli/bootstrap.go:82) prints them. A local test server returning a dummy bearer followed by `!` reproduced the entire credential value in stderr.  
  **Fix:** replace bootstrap response-validation errors with fixed text before returning them. Add a malformed-response test asserting that neither the credential nor its secret component appears in output.

- **#128 — Expiry uses a timestamp captured before the transaction.**  
  [internal/daemon/bootstrap.go:207](/tmp/claude-1000/-home-mega/d7e41cde-3883-4e5c-8d98-04b890c5f4c4/scratchpad/wt-s9-4b/internal/daemon/bootstrap.go:207) captures `now` before Argon2 minting and writer acquisition; line 218 supplies that stale time to consumption. A request arriving just before expiry can therefore apply after expiry following hashing or writer delay.  
  **Fix:** evaluate `b.now()` inside the transaction for the live-secret check. Add a deterministic test that advances the clock past expiry while the request waits for the writer.

- **#129 — Opening a FIFO blocks before the regular-file check.**  
  [internal/cli/bootstrap.go:118](/tmp/claude-1000/-home-mega/d7e41cde-3883-4e5c-8d98-04b890c5f4c4/scratchpad/wt-s9-4b/internal/cli/bootstrap.go:118) opens with blocking `O_RDONLY`; `f.Stat()` comes afterward. A temporary `bootstrap.secret` FIFO with no writer reproduced the hang.  
  **Fix:** add `O_NONBLOCK|O_NOCTTY`, retaining `O_NOFOLLOW` and descriptor-based regular-file validation, as the token reader already does. Test prompt refusal of FIFOs.

## Lead note (2026-10-07)

All five findings are fixed: `491c17b` (#127), `53380cd` (#128) and `9e81548` (#129), later re-applied when the stack was rebuilt onto main.

- **#128 expiry:** expiry is checked inside the writer transaction. A deterministic test covers a secret that expires while the request waits for the writer.
- **#129 malformed responses:** these now produce fixed text, so no bearer reaches stderr.
- **#129 secret file:** it is opened with O_NONBLOCK, O_NOCTTY and O_NOFOLLOW and checked on its descriptor, so a FIFO, a symlink or a directory is refused promptly.
- **#127 regression tests:** a leftover file or a symlink at the secret path is replaced, and the link target is never touched.
- **Documentation:** the system-only action exceptions are documented, and the `confirmation_refused` description is widened.

Each guard's mutation, run on a copy of the tree, turned its test red. The lead checked the fixes against the findings, and the PRs merged on green CI. The stack was rebuilt onto main twice using diffs only; the server-side merge `225ea5c` is gone.
